GETTING STARTED / 使用指南

从一道题，到一条清晰的建模路径。

AI 帮你理解题目、讨论方法和编写代码。你负责确认条件、选择思路，以及检查结果是否回答了原问题。

开始读题 →请在电脑浏览器中使用工作台。
按需阅读

01

先把题目放进来

  1. 进入读题工作台，粘贴题目正文，点击使用此题目；也可以用上传题干导入 PDF、Markdown 或 TXT。
  2. 表格与数据文件通过上传附件添加。题干说明要解决什么，附件提供分析需要的数据。
  3. 检查题目与附件是否完整。连接模型后，可点击AI 整体解读；用鼠标选中一段题目，再点浮动工具栏中的AI 解读，逐段确认目标与条件。
还没有题目？打开「建模范例」，查看并下载一个例题，再将题干和附件导入工作区。查看范例不会自动导入题目。
02

需要 AI 时，连接自己的模型

  1. 从左侧栏打开模型设置（齿轮图标），选择服务商，填写 API Key、接口地址和模型名。
  2. 测试当前配置的连接是否正常，再点击保存设置。测试成功不会自动保存。
  3. 回到工作台，使用 AI 解读、对话或代码生成。
未配置模型也可以导入题目、手动整理拆解块和编辑代码。使用 AI 功能才需要有效的模型配置；调用费用由所选模型服务商计收。
03

把想法整理成可执行的拆解块

打开建模思路梳理。一个拆解块代表一个要完成的任务：说明要解决什么、采用什么思路、按什么步骤执行。

  1. 点击新建拆解块，再点编辑，直接在块头部填写标题和一句话思路。
  2. 题目依据和步骤按需展开；每次编辑一个步骤，点击添加步骤会直接进入新增输入。点击保存拆解块后才应用编辑草稿。
  3. AI 帮我写思路会提供待采用建议；只有点击使用AI建议才替换思路，点击忽略建议保留当前输入。也可以先在右侧与 AI 讨论。
  4. 检查 AI 给出的拆解预览，点击确认新建或确认写入后才应用；点击取消会保留原内容，并回到对话输入继续讨论。需要的数据附件可以关联到相应块。
  5. 不熟悉某种方法时，切换到知识卡片，查看适用条件与演示，再决定是否采用。
一个拆解块可以这样写

标题：在预算内选择项目组合

思路：每个项目设为选或不选，以总收益最大为目标，总成本不超过预算。

步骤：读取项目成本与收益 → 检查缺失值 → 求可行组合 → 输出入选项目及总成本、总收益。

进入编程前，确认拆解块有明确的输入、方法和预期输出。只有标题的空块通常不足以生成可靠代码。
04

生成、运行，再核对结果

代码区与产出区首次默认各占一半；可用分隔手柄拖动或按方向键调宽，已有宽度偏好会保留。

  1. 点击梳理台的去编程台，或从左侧导航进入编程工作台。
  2. 点击AI生成，选择要解决的拆解块，说明希望得到的结果，再提交生成。没有拆解块时，先回梳理台创建。
  3. 检查生成代码中的文件、字段与参数，点击运行。Python 在浏览器中运行，首次加载运行环境可能需要等待。
  4. 查看输出与图表，核对约束是否满足、数值是否合理、结果是否回答了题目。代码有可调参数时才显示调参看板，修改后重新运行。只输出文字的代码没有图表也可以是正常结果。
运行成功说明代码执行完成，不能代替模型与结果检查。代码报错时，结合错误信息修正代码或使用 AI 改进。

遇到问题时

AI 无法使用？
打开模型设置，检查服务商、接口地址、模型名和 Key；测试连接后记得保存。如果提示额度或网络问题，按错误信息处理。
Python 环境加载失败？
查看编辑器底部状态与右侧错误。先导出代码留备份，检查网络是否能访问运行环境 CDN，再刷新工作台重试。
不想让 AI 一直提问？
模型设置中的「引导模式」控制建模对话方式；它与这份使用指南是两件事。可以按学习需要调整。
如何切换题目、保存一份备份？
展开左侧工作区列表，切换或新建工作区。使用工作区备份导出 JSON；导入备份会创建新工作区。API Key 不包含在备份中。
如何再次查看这份指南？
打开随发布提供的 guide.html。这是一份独立文档，不会占用工作台的操作空间。
