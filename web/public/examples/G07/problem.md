# 红葡萄酒质量二分类

附件“红酒质量分类.csv”改编自 UCI Wine Quality 红葡萄酒数据。目标 `high_quality` 定义为原始感官评分不低于 6 时取 1，否则取 0。

`source_quality` 直接决定目标，只用于追溯和审计，严禁作为特征；`sample_id` 只是行标识，也不得作为特征。可用特征仅为 11 项理化检测指标。

请按 `high_quality` 分层，并在每一类按 `sample_id` 升序排列后，把第 1、6、11……条记录划入测试集，其余划入训练集。所有标准化参数和模型参数只能从训练集估计。

请建立一个透明、可复现的分类基线，报告训练/测试类分布、混淆矩阵、准确率、精确率、召回率、F1 和平衡准确率。必须说明类别不平衡、评分阈值和感官标签带来的限制，不得把预测解释为健康、安全或价格结论。

可以补充其他分类器，但必须保持相同划分并明确排除泄漏字段。请用表格和至少一张图展示结果。
