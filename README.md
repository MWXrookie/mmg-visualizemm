# MMG_VisualizeMM · 数模 AI 辅导

**面向数学建模新手的「AI 辅助读题 + 自主建模」辅导工具**（开源 · 自托管 · BYOK）

> **AI 帮你看懂题，建模始终由你主导。**
> 划词精读、苏格拉底引导、知识卡片交互演示、获奖论文知识库 RAG、浏览器内 Python 编程——把「读懂题目」这件新手最容易卡住的事，拆成可见、可交互、可回退的每一步。

---

## ✨ 功能亮点

### 🧭 三台工作流：读题 → 建模思路 → 编程出图

| 工作台 | 做什么 |
|---|---|
| **读题工作台** | 粘贴/上传题目（Excel/CSV/PDF/TXT）→ AI 整体解读 → 划词精读判定角色（约束/目标/已知/假设/背景） |
| **建模思路台** | 拆解块管理（标题/思路/步骤）+ 苏格拉底对话引导 + 知识卡片面板 + 思路一键沉淀为拆解块 |
| **编程工作台** | 浏览器内 Python（Pyodide）+ matplotlib 出图内嵌 + 调参滑块 + 运行结果可视化 |

### 🎓 划词精读（M2）
- 选中题目任意一段文字 → AI 判定它属于**约束条件 / 目标 / 已知条件 / 假设 / 背景信息**
- 带**置信度 + 结构化角色卡**，可质疑重新论证、连续深挖
- **双向引用**：点选角色卡即可定位原文高亮

### 🧠 苏格拉底引导（防代做 · 用户主导）
- **引导模式**（设置可开关）：AI 以建模专家口吻提问，**先指出题目信号 → 反问 → 等你回答 → 再给对应方法**，绝不一次性抛"方法列表"
- **专家核心**：主动点名难点与数据陷阱、给专业倾向与理由、讲方法失效边界、对标评委评分
- **停止短语规则**：你说"可以写代码了"之前，AI 只引导不代做
- **思路沉淀**：引导出的思路可一键整理成拆解块

### 🃏 知识卡片（M4 · 59 张，41 张含交互演示）
- AI 回答提到建模概念时，**卡片就地浮现**：决策树逐层生长、K-means 拖拽迭代、遗传算法种群进化、PSO 粒子聚拢、蒙特卡洛撒点估 π、卡方检验实时算 p 值……
- 另有 18 张纯内容卡片覆盖细分知识点（灰色关联、模糊综合评价、SVM、因子分析、排队论、博弈论、力电比拟等），无演示也照常出卡
- 可展开演示、可收藏持久化——**理解，不止于一句定义**

### 📚 获奖论文知识库 RAG（M6）
- **三源知识库**：方法库（43 种结构化方法）+ 知识卡片库（59 张概念）+ 获奖论文全文（**23 篇历年国赛优秀论文**）
- **语义向量检索**：通义 text-embedding-v3 将 1251 个知识块向量化，AI 回答前自动检索最相关片段注入上下文，**回答可注明论文来源**
- 方法库每条含：适用场景 / 使用步骤 / 失效边界 / 评委视角 / 来源论文

### ⚙️ BYOK · 自带密钥
- 通义百炼 / DeepSeek / OpenAI / 自定义端点预设，**Key 经 AES-GCM 加密只存浏览器本地**，数据不出浏览器

### 🎨 体验细节
- 深色模式一键切换、SSE 流式打字机、👍/👎/重新生成、会话自动保存/恢复/导出 Markdown
- 门户页：`/ai-portal.html`（产品介绍落地页）

## 🚀 快速开始（安装指引）

### 环境要求
- **Node.js ≥ 23.4**（后端使用 Node 内置 SQLite `node:sqlite`，低版本无法启动）
- 浏览器（推荐 Edge / Chrome）
- 一个大模型 API Key（通义百炼 / DeepSeek / OpenAI 均可）

### 步骤

```bash
# 1. 克隆仓库
git clone https://github.com/MWXrookie/mmg-visualizemm.git
cd mmg-visualizemm

# 2. 安装依赖
npm install

# 3. 构建前端
npm run build

# 4. 启动服务
npm start
```

### 访问地址（本机 vs 局域网，注意 IP 不同）

服务器监听所有网卡（`0.0.0.0:3088`），**不同人访问用不同的地址**：

| 场景 | 访问地址 | 说明 |
|---|---|---|
| 部署者本机 | `http://127.0.0.1:3088` | 自己电脑上打开 |
| **局域网内其他人** | `http://<你的局域网IP>:3088` | 同一 WiFi/网线内的人，用你的 IP（**不是 127.0.0.1**） |
| 公网/远程 | 需端口映射或内网穿透 | 默认仅局域网可达 |

查自己的局域网 IP（Windows）：
```bash
ipconfig    # 找"以太网"或"WLAN"的 IPv4 地址，如 192.168.x.x
```

> ⚠️ **127.0.0.1 永远指向"访问者自己的电脑"**——别人电脑上用 127.0.0.1 打不开你的服务，必须用你的局域网 IP。

### 开发模式（热更新）

```bash
npm run dev    # Vite(5173) + 后端(3088)，改代码自动刷新
```

### 首次使用配置

1. 打开 `http://127.0.0.1:3088`（或门户页 `/ai-portal.html` → 进入应用）
2. 左侧「**模型设置**」→ 选择服务商、填入 API Key → 「测试连接」→ 「保存设置」
3. 「**读题工作台**」粘贴题目（或上传附件）→ 点「AI 整体解读」开始

### 知识库（RAG）可选配置

默认知识库用**本地哈希向量**（离线可用）。若配置通义千问 embedding 可升级为**语义向量检索**（更准）：

```bash
# 在 server/.env.local 中填入（文件已 gitignore，不会提交）
EMBED_API_KEY=你的千问key
EMBED_MODEL=text-embedding-v3
EMBED_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

配置后重启服务，知识库自动用千问语义向量重建（约 1238 块）。

## 🔑 技术栈

- **前端**：React 18 + Vite 6（JavaScript）+ marked（Markdown 渲染）+ SSE 流式
- **后端**：Node.js + Express + `node:sqlite`（单进程，静态托管前端产物）
- **代码执行**：Pyodide（浏览器内 Python，预装 numpy/pandas/matplotlib/scipy/sklearn）
- **知识库**：RAG（切块 → embedding → 余弦+关键词混合检索 → 上下文注入）
- **安全**：API Key AES-GCM 加密存 localStorage；`server/.env.local` 已 gitignore
