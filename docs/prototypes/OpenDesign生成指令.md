# OpenDesign 原型生成指令

> 用法：在 OpenDesign 中先加载设计系统 `design-systems/mmg_visualizemm/DESIGN.md`，然后选择「Web Prototype」，粘贴下方对应页面的 prompt 生成。
> 每个 prompt 已引用 DESIGN.md 章节与 UI-UX 设计文档页码，生成后对照检查。
> 生成产物归档至本目录（`docs/prototypes/`）。

## 页面 1：读题工作台（核心，优先生成）

```
生成一个「数学建模 AI 辅导工具」的读题工作台页面（桌面端，1440 宽优先）。

布局：顶部导航（56px，左 Logo + 会话名，右侧图标按钮）→ 步骤指示器（①读题理解 → ②精读深挖 → ③建模方向）→ 主区双栏（左 60% 题目区 / 右 40% AI 解读区，gutter 24px）。

【左栏·题目区】
- 标题区：题名「2026 国赛 C 题」H3 + 附件行（标签「表1.xlsx ✓」「表2.pdf ✓」，胶囊小标）
- 题干正文：16px/1.8 行高，段落间距 8px
- 展示三种角色高亮：蓝色底（约束条件）+ 胶囊标签、琥珀底（已知条件）+ 胶囊标签、绿色底（目标）+ 胶囊标签（标签=语义色圆点+文字，见 DESIGN.md §2 角色语义色）
- 选中交互态：一段文字带蓝色选区高亮，选区上方 8px 处有浮动工具栏（圆角 8 卡片：[AI解读 主色实心按钮] [提问] [复制] ghost 小按钮）
- 下方表格预览卡片（内边距 16）：「附件：表1.xlsx」表头 13/600 灰底粘性，单元格 13px，数字列右对齐 tabular-nums，列「年份/需求量(吨)/单价(元)」

【右栏·AI 解读区】
- Tab 切换（解读 / 对话 / 卡片，高 40，激活项主色下划线）
- 「整体解读」内容：小节标题 H4（题目在问什么 / 已知条件 / 数据清单 / 输出要求），正文 14px
- 「角色判定卡」（划词触发结果）：卡片内边距 16，顶部胶囊标签「已知条件」+ 置信度「92%」+ 质疑链接，正文说明「这段给出：需求量随时间变化…对建模的影响：…」，底部脚注 [1][2] 主色可点击
- 对话区：用户气泡右对齐（主色底白字，最大宽 85%，圆角 10）+ AI 气泡左对齐（白底，左上小折角，带 👍/👎/重新生成）+ AI 反问示例「先想清楚：你觉得哪个变量是决策变量？」带左侧 3px 主色边（引导模式提示样式）
- 底部输入框（高 44，圆角 6）+ 发送按钮（主色圆角 8）

配色与字体严格按 DESIGN.md §2/§3（背景 #F8FAFC，卡片 #FFFFFF，主文字 #1E293B）。不要用 emoji 当图标，用线性 SVG 图标。
```

## 页面 2：BYOK 设置页

```
生成「模型设置」页面（与页面 1 同风格）。
- 标题 H1「设置」+ 说明文字
- 卡片（内边距 24，圆角 10）：
  1. 「模型接入」：Provider 下拉（DeepSeek/通义/Kimi/自定义端点）+「添加自定义端点」ghost 按钮；API Key 输入框（高 36，带显示/隐藏切换按钮）+「测试连接」主色按钮；测试结果提示条（成功=绿色左边框 / 失败=红色左边框+人话错误原因）
  2. 「隐私说明」：信息提示条（主色左边框）：「🔒 Key 只存本浏览器，不会上传服务器」+「查看 3 分钟申请指引」链接
  3. 「偏好」：模型选择下拉 + 主题切换（浅色/深色）+ 防代做开关（switch，默认开）
- 新手指引：底部卡片「还没有 Key？」带步骤（1 注册平台 → 2 创建 Key → 3 粘贴测试）
配色按 DESIGN.md §2，表单组件按 §5 输入框/按钮规格。
```

## 页面 3：知识卡片（决策树示例）

```
生成「知识卡片·决策树」展示（可嵌入对话流的卡片形态，宽 100% 卡片）。
- 卡片头部：胶囊标签「模型概念」+ 标题 H3「决策树」
- 一句话概念：「按条件逐层划分数据的分类方法」正文 14px
- 交互演示区（高约 240px，圆角 8，muted 背景）：
  - 左侧参数面板：滑块「最大深度」（默认 3，范围 1-6）+ 播放按钮（▶ 逐层生长动画）
  - 右侧画布：一棵决策树（3 层，节点=条件矩形，叶节点=分类标签，连接线），当前层高亮
- 「试一试」区：问题「为什么这道题适合决策树？」+ 提示 ghost 按钮
- 底部操作：⭐ 收藏（主色 ghost）+ 相关概念链接（随机森林 / 回归树）
- 图标用线性 SVG，不用 emoji 作结构图标。
```

## 页面 4：对话深挖（引导模式）

```
生成「对话深挖」视图（读题工作台右栏的对话 tab 全宽态，或独立页）。
- 顶部：步骤指示器高亮「②精读深挖」
- 消息流（气泡规格同页面 1）：
  1. 用户：「目标函数应该怎么设？」
  2. AI 引导回复（左侧 3px 主色边提示样式）：「先别急着写公式。反问：你觉得题目里哪个量是你要'决策'的？——想清楚再往下，我帮你验证。」
  3. 用户：「应该是采购量？」
  4. AI 普通回复：「对。现在看约束：表1 的需求量是硬约束还是软约束？给出你的判断。」+ 引用脚注 [1] 指向题干「未来5年需求量」
- 底部：输入框 + 发送按钮；输入框上方提示条「🔒 引导模式已开启：AI 只引导思路，不直接给答案」（主色左边框）
- 可在对话气泡间插入「知识卡片入口」横条：「💡 相关概念：线性规划 → [查看卡片]」。
```
