# OpenDesign 原型生成指令 v2（覆盖当前产品功能集）

> 用法：在 OpenDesign 中先加载设计系统 `design-systems/mmg_visualizemm/DESIGN.md`，选择「Web Prototype」，粘贴对应页面 prompt 生成。
> 产物归档至 `docs/prototypes/`；本版指令覆盖 2026-08-29 验收后新增功能（SSE 流式/会话列表/导出/收藏/深色模式）。
>
> **通用要求（所有页面）**：
> 1. **双主题变体**：每个页面输出「浅色 + 深色」两版（深色参考：背景 #0F172A / 卡片 #1E293B / 前景 #E2E8F0 / 主色 #3B82F6 / 强调 #FB923C / 边框 #334155）
> 2. **图标**：一律用 Phosphor 风格**线性 SVG**（stroke 1.5-2px，16/20/24），**禁止 emoji 当结构图标**
> 3. 组件规格严格按 DESIGN.md §5（按钮 S32/M36/L40、输入框高36 圆角6、标签胶囊高22、气泡圆角10 最大宽85%）
> 4. 间距 4px 节奏（DESIGN.md §4）；阴影卡片/浮层按 token

## 页面 1：读题工作台（双栏 + 右栏 Tab + 流式状态）

```
生成「数学建模 AI 辅导工具」读题工作台（桌面 1440 优先，浅色+深色两版）。

布局：顶部导航(56px：左 Logo+会话名，右 主题切换🌓图标按钮 + Key 状态胶囊) → 步骤指示器(①读题理解→②精读深挖→③建模方向) → 主区双栏(左 60% 题目 / 右 40% AI 区，gutter 24)。

【左栏·题目区】
- 题名 H3 + 操作行：附件胶囊「表1.xlsx ✓」「表2.pdf ✓」+ ghost 按钮「编辑题干」「换一道题」「📁 保存会话」「💾 导出 MD」（线性 SVG 图标）
- 题干正文 16px/1.8：展示三种角色高亮（约束=蓝底+胶囊标签、已知=琥珀、目标=绿，标签=语义色圆点6px+12/600 文字）
- 选中交互态：文字蓝色选区高亮，上方 8px 浮动工具栏（圆角8：[AI解读 主色实心] [提问] [复制] ghost，150ms 淡入）
- 表格预览卡片：表头 13/600 灰底粘性，数字列右对齐 tabular-nums，横向滚动时首列冻结（sticky left）

【右栏·AI 区】
- Tab 切换（解读 / 对话 / 卡片，高 40，激活项主色下划线）
- 「解读」：整体解读 5 小节（题目在问什么/已知条件/数据清单/目标/输出要求）+「角色判定卡」（胶囊标签+置信度+质疑链接+「📍 点击定位原文」引用行）
- 「对话」：消息流（用户蓝右 / AI 白左，圆角10，AI 左上4px折角）
  - 流式输出态：AI 气泡内文字 + 尾部**橙色闪烁光标「▍」**（打字机效果），未结束时无 👍/👎
  - 完成态：👍/👎/重新生成 小按钮 + 引导模式提示样式（左 3px 主色边）
  - 概念触发横条：「💡 相关概念：线性规划 → [查看卡片]」（主色描边胶囊）
- 「卡片」：知识卡片嵌入形态（见页面 3）
- 底部输入框（高40 圆角6）+ 发送按钮（主色圆角8）

配色按 DESIGN.md §2；两版主题都出。
```

## 页面 2：对话深挖独立页（双形态② + 过程面板）

```
生成「对话深挖」独立页（引导模式，浅色+深色两版）。

- 顶部：步骤指示器高亮「②精读深挖」+ 返回工作台 ghost 按钮
- 主区双栏：左 60% 对话流 / 右 40% 过程面板
  - 对话流：同页面 1 气泡规格；含流式光标态与完成态两种；
    引导模式提示条（主色左边框）：「🔒 引导模式已开启：AI 只引导思路，不直接给答案」
  - 过程面板（右侧三卡片）：「当前追问」（AI 待回问题列表）/「上下文判定」（已确认的角色/条件清单，带语义色标签）/「相关概念」（知识卡片入口）
- 底部：输入框+发送；输入框上方可插概念入口横条
```

## 页面 3：知识卡片（含收藏态与动画态）

```
生成「知识卡片」页（决策树示例，浅色+深色两版）。

- 页头：H1「知识卡片」+ 说明
- 顶部卡片 Tab（决策树/线性回归/K-means，激活=主色下划线；已收藏的 Tab 前缀 ⭐）
- 卡片主体：
  - 头部：胶囊标签「分类 / 回归」+ 标题 H3
  - 一句话概念 14px
  - 交互演示区（圆角8 muted 底）：左侧参数面板（滑块「最大深度」+ ▶播放/⏸暂停按钮），右侧决策树 SVG（节点=白底蓝描边矩形，叶=蓝/橙圆角胶囊，连线），演示**播放中**显示当前生长层高亮 + 其他层 40% 透明度
  - 「试一试」提示区（橙色左边框）
  - 底部：⭐ 已收藏（主色 ghost 实心态）+ 相关概念链接
```

## 页面 4：BYOK 设置页（加密 + 主题切换）

```
生成「模型设置」页（浅色+深色两版，同风格）。

- 标题 H1「模型设置」+ 说明「Key 只保存在本浏览器（AES-GCM 加密），不会上传服务器」
- 卡片：
  1. 「模型接入」：Provider 下拉（通义百炼/DeepSeek/OpenAI/自定义）+ API Key 输入框（高36，显示/隐藏切换）+「测试连接」主色按钮；结果提示条（成功=绿左边框 / 失败=红左边框+人话原因，三分类：Key无效/额度/网络）
  2. 「偏好」：**主题切换（浅色/深色，switch 或分段控件）**+ 引导模式开关（switch，默认开，说明「AI 只给思路与反问」）
- 底部新手指引卡片：「还没有 API Key？」步骤 1-2-3（注册→创建→粘贴测试）
```

## 页面 5（新增）：启动页 / 新建会话 + 历史会话（空态）

```
生成「启动页/新建会话」视图（浅色+深色两版）。

- 居中卡片：H1「新建读题会话」+ 三步说明（①粘贴题目或上传 PDF ②上传 Excel/PDF 附件 ③点「开始读题」）+ 大按钮「开始读题」（橙色 CTA，L 尺寸）
- 上传区：拖拽 dropzone（虚线上传区：📎 图标 +「点击选择或拖拽数据附件」+ 支持格式提示 xlsx/csv/pdf/txt）
- 题干输入：textarea 占位 +「上传题干文件（PDF/MD/TXT）」ghost 按钮
- 附件列表：解析中（进度指示）/已解析（✓ 胶囊：列数·行数预览）/失败（红色原因+重试）
- 下方「历史会话」列表：条目=标题 + 保存时间 +「继续」主色小按钮 + 删除 ✕；空态显示「还没有历史会话」
- 右下「第一次用？看 3 分钟教程」链接（主色）
```
