## 3. 偏差清单（3 项，均为小偏差）

| # | 偏差 | 规范要求 | 建议 |
|---|------|---------|------|
| D1 | 未见橙色强调色 `#EA580C` | DESIGN.md §2：Accent 用于 CTA/重点引导 | 将「发送」或「AI 解读」按钮改为橙色 CTA，或保持克制（见 §4 决策点 2） |
| D2 | 隐私提示条粉色背景 | DESIGN.md §5 提示条：info = 主色左边框 + 浅蓝底 | 改为主色系（`rgba(37,99,235,.06)` 底 + 左蓝边） |
| D3 | workbench 右侧对话区为空 | UI-UX §4.1：对话在右栏 tab 内 | 取决于 §4 决策点 1 |

---

## 4. 产品决策（已确认 2026-08-29）✅

1. **对话区位置 → 双形态**（采纳建议）：
   - 工作台右栏对话 tab = 轻量问答（读题+问答同屏）
   - 深挖模式独立页（guided-chat 形态）= 步骤②进入，右侧过程面板，用于深度建模引导
   - 已同步更新 `docs/UI-UX设计.md` §3 与 `DESIGN.md`
2. **橙色 CTA → 使用**：主按钮保持主色蓝；橙色 `#EA580C` 仅用于最高优先级引导（"开始读题"等页面级大 CTA）
   - D1 偏差由此解决：M0 实现时按此规则落地
