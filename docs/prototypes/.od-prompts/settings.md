为一个「数学建模 AI 辅导工具」生成「模型设置」高保真网页原型：输出单个自包含 HTML 文件，内置浅色与深色两套主题（html[data-theme] 切换，默认浅色）。

【设计 token】
- 浅色：背景 #F8FAFC、卡片 #FFFFFF、主文字 #1E293B、次要文字 #475569、边框 #E2E8F0、主色 #2563EB、强调橙 #EA580C、圆角 sm 6 / md 10
- 深色（data-theme=dark）：背景 #0F172A、卡片 #1E293B、主文字 #E2E8F0、次要 #94A3B8、边框 #334155、主色 #3B82F6、强调 #FB923C
- 表单：输入框高 36 圆角 6、label 13/500；按钮 S32/M36 圆角 8

【布局】
顶部导航（同全站：读题工作台/编程工作台/模型设置(激活) + 主题切换 + Key 状态胶囊）→ 页面内容居中窄栏（max-width 720）。

【页面内容】
1. 标题 H1「模型设置」+ 说明文字：「Key 只保存在本浏览器（AES-GCM 加密），不会上传服务器」
2. 卡片「模型接入」：
   - Provider 下拉（通义百炼/DeepSeek/OpenAI/自定义）
   - API Key 输入框（高 36，右侧「显示/隐藏」切换按钮，密码态）
   - Base URL 输入框（占位 https://api.deepseek.com/v1）
   - 模型名输入框（占位 qwen-plus / deepseek-chat）
   - 「测试连接」主色按钮 → 结果提示条（成功=绿左边框「连接成功（模型 xxx）」/ 失败=红左边框+人话原因，三分类：Key 无效/额度不足/网络错误）
   - 「保存设置」ghost 按钮
3. 卡片「偏好」：
   - 主题切换：浅色/深色 分段控件（激活态主色底）
   - 引导模式开关（switch，默认开）：说明「开启后 AI 只给思路与反问，不直接给出完整成品答案」
4. 底部新手指引卡片：「还没有 API Key？3 分钟搞定」步骤 1-2-3（注册平台→创建 Key→粘贴测试）+ 提示「国内平台充值 10 元即可用很久」

【硬性规范】
- 图标一律线性 SVG（stroke 1.5-2px），禁止 emoji 当结构图标（显示/隐藏眼睛、锁、箭头都用 SVG）
- 间距 4px 节奏；内容全中文；移动端不横向滚动
- 每个 section 与主要控件加 data-od-id
- 交互状态完整（hover/focus/disabled 成对定义，对比度不下降），视觉完成度高，像顶级产品团队交付的可演示原型
