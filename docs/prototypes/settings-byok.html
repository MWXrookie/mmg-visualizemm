还没有 API Key？

3 分钟搞定
1 注册平台

在通义百炼或 DeepSeek 官网注册账号，进入「API-KEY」管理页面。

2 创建 Key

点击「创建 API Key」，复制生成的密钥字符，妥善保存。

3 粘贴测试

把 Key 粘贴到上方输入框，点击「测试连接」即可开始使用。

国内平台充值 10 元即可用很久，日常题目用量几乎可以忽略不计。
