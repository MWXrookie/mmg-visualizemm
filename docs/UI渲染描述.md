## 0. 背景与目标

- 产品：面向数学建模新手的 AI 辅导工具（帮新手入门理解，**不代做**）
- 架构：三台流水线 = 读题工作台 → 建模思路梳理台（问题拆解）→ 编程工作台（AI 编程+可视化）
- 本次渲染目的：**确认 UI 布局与视觉方案**（架构已定稿，UI 待定）

## 1. 风格基调（已锁定）

| 维度 | 定稿 |
|---|---|
| 参考对象 | Codex（OpenAI）/ Linear / Claude（Anthropic） |
| 主题 | **浅色 + 深色双主题**（可切换） |
| 主色 | **蓝色** |
| 视觉特征 | **渐变蓝** + **不对称构图**（不追求严格对称，有错落层次） |
| 圆角 | 参考大型科技公司：**适中**（8-14px，卡片/弹窗略大） |
| 字体 | **圆润但保留一点锋利**（介于圆体与黑体之间，如系统栈 + 适当字重对比） |
| 装饰程度 | **低**，绝不要花哨；不用大光晕/重渐变堆叠 |
| 信息密度 / 留白 | **留白中等**（有呼吸感但不空旷） |
| 绝对避免 | AI 聊天软件式：聊天框上方一堆插件按钮、广告横幅、花哨的侧边组件堆叠 |

## 2. 设计规范（内联，渲染时无需再查其他文档）

### 2.1 颜色 tokens

```css
:root { /* 浅色 */
  --bg: #f6f8fb;  --surface: #ffffff;  --fg: #0f172a;
  --muted: #5b6b83;  --border: #e4e9f2;
  --primary: #2563eb;  --primary-strong: #1d4ed8;  --accent: #ea580c;
  --primary-grad: linear-gradient(135deg, #3b82f6, #2563eb);
  --radius-sm: 8px;  --radius-md: 12px;  --radius-lg: 16px;
}
:root[data-theme='dark'] { /* 深色 */
  --bg: #0a0e1a;  --surface: #111827;  --fg: #e8ecf4;
  --muted: #8b9bb4;  --border: #1f2937;
  --primary: #3b82f6;  --primary-strong: #60a5fa;  --accent: #fb923c;
  --primary-grad: linear-gradient(135deg, #60a5fa, #3b82f6);
}
```

- 主操作按钮/选中态用**渐变蓝**（`--primary-grad`）；强调 CTA 可用橙色（全页 ≤1 处）
- 文字分三级：主 `--fg` / 次 `--muted` / 占位禁用（更浅一档）

### 2.2 字体与排版

- 字体族：系统栈（`-apple-system / Segoe UI / PingFang SC / Microsoft YaHei`），圆润观感可加 `font-weight: 500-700` 对比、标题 `letter-spacing: -0.01em`
- 正文 ≥14px、行高 ≥1.6；标题字重分层（H1 28-32/800、H2 22-24/700、H3 16-18/600）
- 数字/表格用 `tabular-nums`；代码等宽字体 `JetBrains Mono / Consolas`

### 2.3 布局与间距

- 间距 4px 节奏（4/8/12/16/20/24/32/48）；**留白中等**
- 圆角：小控件 8 / 卡片 12 / 弹窗 16
- 阴影克制：卡片 `0 1px 2px rgba(15,23,42,.05)` + 浮层 `0 12px 32px rgba(15,23,42,.12)`
- 不对称构图：允许错落（如 AI 栏略宽于书签栏、标题区与内容区非严格居中对齐）

## 3. 通用硬性要求（所有页面）

1. **双主题**：每页输出浅色 + 深色两版（`html[data-theme]` 切换，默认浅色）
2. **图标**：一律线性 SVG（stroke 1.5-2px），禁止 emoji 当结构图标
3. **无插件堆叠 / 无广告横幅**（产品是工具，不是聊天软件）
4. 每个 section 与主要控件加 `data-od-id`
5. 响应式：移动端不横向滚动；留白中等
6. 交互状态完整：hover / focus / disabled 成对定义，对比度不下降
