## 0. 产品画像速览（调研基准）

**一句话定位**：面向数学建模新手的「AI 辅助读题 + 用户自主建模」**个人辅导工具**（开源自托管 + BYOK 自带 Key）

- **形态**：开源自托管 Web 应用，用户 GitHub 下载部署，填入自己的 API Key 自由选模型；纯个人工具
- **核心流程**：上传数模题+附件(Excel/PDF) → AI 读题（划词精读）→ 对话深挖（AI 反问引导）→ 知识卡片 → AI 辅助编程+结果可视化 → 会话保存/卡片收藏
- **差异化**：① 自主性（AI 是教练不是代笔）② AI 辅助读题理解（选段精读为特色）③ BYOK 自带 Key
- **范围**：不做论文写作

### 2.2 市场规则警示
- 知乎软文印证行业规则：「承诺保奖/未获奖退费均属骗局」——代做保奖灰产的官方警示

### 2.3 关键洞察
1. **「读题理解」是全网空白**——没有平台做"上传题目+附件→划词精读→AI 反问引导"的交互式读题，现有 AI 工具只做一次性"题意解析"输出 ✅ 差异化空位验证
2. **自主建模市场两极**：灌输式课程 vs AI 全自动代做；中间地带的"AI 教练"无人占据
3. **可视化与教学割裂**：SPSSPRO 可视化最强但只做统计分析；代做工具只出图表不解释——无「代码运行→交互可视化→知识点卡片」的教学闭环 ✅ 机会点

### 3.2 关键结论

**「划词→AI 单独解读」已是 5 家标配**（ChatPDF/AskYourPDF/ChatDOC/通义智文/SciSpace）——不是我们独有；**真正的差异在交互深度与沉淀层**。

**四个共同空白（= 我们的机会）**：
1. **无人做「按数模语境判定题干段落角色」**（这段是约束？目标？已知条件？假设？）
2. **无人做「题干文本 ↔ Excel 附件联动解读」**——做精读的不收 Excel（NotebookLM/通义智文/ChatDOC），收 Excel 的不做题干解读（Kimi/豆包/ChatGPT）
3. **无人把「整体解读 → 段级精读 → 建模导向多轮引导」三步漏斗产品化**（Kimi 反问只在 Deep Research）
4. **主流工具全部无 BYOK/本地部署**（仅开源 Documino）——BYOK 是差异化卖点

**引用溯源做成「双向」**：答案→原文高亮（NotebookLM 式，92.4% 精度基准）+ 原文划词→发问（通义智文/SciSpace 式）。

## 5. 维度 D：数模新手用户痛点

### 5.1 痛点验证结论

**假设 ✅ 强验证**："上手难/读不懂题/不知道从哪开始"是新手最大痛点。一手证据：
- 豆瓣美赛入门帖：「啥都搞不来的状态…看给的数据很头大…建模也没有思路」
- 教育部中国大学生在线（矿大）21 条痛点清单：「拿到题目之后不知应该如何下手」「题目方向把握不精准」
- LINUX DO：「看了下去年的题，思路和算法基本看不懂」
- B站专栏：「提取出题人的问题确实需要很强的信息分析能力」

### 5.2 "读不懂题"的 4 种具体表现（对应产品设计）
1. **信息太多抓不住重点**（"数据很头大（太多了）"、审题不清方向跑偏）
2. **分不清目标/约束/因素**（"什么是问题的内容…约束条件…希望你回答的方向"）
3. **术语与背景不懂**（审题第一式=弄清未知概念）
4. **数据表格看不懂**（"数据看起来是否规整"）

### 5.3 现有辅导评价（分化）
- 免费/低价入门课口碑尚可（清风"最有良心…让我一个新手入门"）
- 付费保奖班普遍被骂圈钱（¥12000 保奖班"老师是真不行""都是圈钱"；黑猫投诉拒退款）
- 灌输式教材「全是最严格的数学定义和推导，根本看不懂」

### 5.4 AI 使用现状（三大问题）
1. **认知牢笼**：「你问得越外行它答得越外行/不知道自己不知道」（知乎高赞长文）
2. **答案趋同无创新**（"答案趋向于一致化"）
3. **AI 数学推理不稳定**：同题正确率波动 40-60%、越长越错、自我纠错率 <12%

### 5.5 需求信号与付费意愿
- **显性需求是"求带/求思路/求速成/保奖"**，直接喊"要引导式工具"的少；但「看懂题、看懂别人思路」需求极其普遍（小红书博主卖逐题"思路分享"是付费内容生意）；"建模论文某种意义上就是一本正经的胡说八道，而有时 ChatGPT 就是干这个的"（知乎）——AI 代做态度最直白的表达
- 🔧 AI 依赖真实案例：2024 国一选手因前队友"非常依赖 GPT、只截图给我、用我的账号"赛后换人——**单向依赖 AI 破坏协作，"自主建模+AI 辅助"有真实受众**
- **⚠️ 付费意愿导向"结果"**：保奖班 99 元起、代做 5000 元、挂名万元、国奖第二作者 3 万元；清风课程 56 元/整套、论文写作免费——**为"学习过程"付费意愿弱**，**付费点必须挂钩"拿奖/效率/比赛陪跑"，"引导式工具"需以结果/效率为价值锚点包装**

- **通道 A（默认）**：matplotlib → PNG/SVG → base64 → 页面内嵌（Open WebUI 现成管线）
- **通道 B（交互）**：Plotly/ECharts → HTML/JS → iframe 内嵌（LibreChat Artifacts 模式）
- **数学渲染**：KaTeX 公式 + Mermaio 流程图 + function-plot/Rough.js（Sparks 白板家教参考）

### 6.4 数模开源生态（可作知识卡片素材）
- zhanwen/MathModel（11.4k⭐）、personqianduixue/Math_Model（5k⭐）——资料+模板
- **jihe520/MathModelAgent（3.9k⭐）= 直接竞品**：数模 Agent（Jupyter+E2B 代码解释器、多 Agent 多模型、RAG、人机审批）——验证需求，但偏"自动出论文"
- math-mooeling-skill（934⭐）三阶段工作流、oatawhalechina/intro-mathmooel（918⭐）教程

## 7. 综合结论与机会点

### 7.1 市场验证总结

| 产品假设 | 验证结果 | 证据 |
|---------|---------|------|
| 新手上手难、读不懂题 | ✅ 强验证 | 豆瓣/LINUX DO/教育部 21 条痛点清单 |
| 「读题理解」是市场空白 | ✅ 强验证 | 维度 A 全网无交互式读题；维度 B 无数模语境解读 |
| 「自主建模」中间地带无人占据 | ✅ 验证 | 市场两极：灌输课程 vs AI 代做；美赛新规利好合规教练定位 |
| 题干+Excel 联动解读是空白 | ✅ 强验证 | 维度 B：精读派不收 Excel，收 Excel 派不做精读 |
| 可视化+教学闭环是空白 | ✅ 验证 | SPSSPRO 只统计不教学；代做只出图不解释 |
| BYOK/本地部署是差异化 | ✅ 验证 | 主流 AI 工具全无 BYOK；仅开源 Documino 本地 |
| 为"学习过程"付费意愿 | ⚠️ 弱 | 付费导向结果（拿奖/代做），需挂钩"拿奖/效率/陪跑" |
| "引导式工具"需求表达 | ⚠️ 中等 | 直接喊的少，但"看懂题/看懂思路"需求普遍，需用户教育 |

### 7.2 核心机会点（按优先级）

1. **「数模语境划词精读」独占价值**：划词→AI 判定段落角色（约束/目标/已知条件/假设）+ 解释作用——全球无人做，交互范式现成（通义智文/SciSpace），加上角色分类即独占
2. **「题干 ↔ Excel 附件联动」硬需求空白**：读题时同步解析 Excel、把数据列名与题干术语自动关联（如"附件表 1 的'需求量'对应题干'未来 5 年需求'"）
3. **「三步引导漏斗」产品化**：整体解读 → 段级精读 → 建模导向问题链（Socratic 引导：目标函数怎么设？约束够不够？该用什么模型？）——Kimi 只在 Deep Research 里反问
4. **「锚点连续深挖」交互**：选中题干一段→以该段为锚点连续追问（豆包证明会话内引用是高需求，但无人做透）
5. **「AI 教练」合规定位**：美赛新规限制 LLM 直接产出，代做型有合规风险；教练定位天然合规且有政策红利
6. **「代码运行→交互可视化→知识卡片」教学闭环**：可视化对标矩阵见 4.3，赛道内无人做完整闭环
7. **BYOK + 隐私卖点**：Key 只存浏览器（ai.diy 架构），自托管+本地优先

### 7.3 主要风险
- **付费意愿偏"结果"导向**：学习工具变现难，需设计"拿奖/效率"挂钩的付费点（如赛前冲刺包、真题陪跑）
- **AI 数学推理不稳**（正确率 40-60%、纠错率 <12%）：必须做"AI 输出防呆"（沙箱执行、答案验证、引用溯源 92% 精度基准）
- **免费替代品极多**：B站 274 万播放免费课、Datawhale 开源教程——产品价值必须超出"免费资料+通用 AI"
- **许可证风险**：商用化只能参考 MIT 系组件（开源形态层）；**可视化组件层同样有坑——GeoGebra 商用须签约（EUPL v1.2）、Desmos 组织商用 $100/月**，若产品收费需提前走合规或改用 Plotly/ECharts 等 MIT/Apache 系自建交互

## 8. 对本产品的建议

### 8.1 功能优先级（结合调研）
| 优先级 | 功能 | 依据 |
|--------|------|------|
| P0 | 上传+解析（题目+Excel/PDF） | 全部流程地基；Excel 支持是相对 NotebookLM/通义智文的硬优势 |
| P0 | **数模语境划词精读**（角色判定+双向引用） | 独占空白，差异化核心 |
| P0 | 对话深挖（建模导向问题链） | Kimi 只在 Deep Research 有，普通流程是空白 |
| P0 | BYOK 设置（多模型+自定义端点） | 形态基础；全行业空白 |
| P1 | 知识卡片（GeoGebra/Desmos 嵌入演示） | 学习闭环；Seeing Theory 模式 |
| P1 | AI 辅助编程+沙箱运行+可视化 | Plotly/ECharts 双通道 |
| P1 | 会话保存+卡片收藏 | 沉淀层差异化 |
| P2 | 真题题库/赛前冲刺包 | 付费挂钩"拿奖/效率" |

### 8.2 技术选型（已调研确认，详见 `docs/01-产品/技术框架与架构.md` v0.1）
- 前端 React+TS+Vite；后端 Node.js；SQLite
- BYOK：浏览器持 Key（ai.diy 架构）+ LibreChat 双轨端点
- 代码执行：Pyodide 默认 + Docker 沙箱生产推荐
- 可视化：matplotlib→base64 + Plotly/ECharts iframe + KaTeX
- 许可证：自研壳，参考 MIT 系

### 8.3 产品化要点
- 免费额度设计：对标 ChatPDF（2 PDF/天）/ NotebookLM（50 问/天）——免费覆盖"一道题+一个附件"的完整读题流程
- 引用正确率评测：以 NotebookLM 92.4% 为基线内置评测
- 用户教育：中文社区直接喊"引导工具"的少，产品内要内置引导价值展示（"授人以渔"话术）
