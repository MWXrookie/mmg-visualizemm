# 维度 D 调研报告：数学建模新手用户痛点

> 项目：可视化的数学建模辅导网站（面向数学建模新手）
> 核心假设：数模新手最大的痛点是「上手难，尤其是读不懂题、不知道从哪开始」；现有解决方案（课程、AI 代做、灌输式教学）没有真正帮助新手建立自主建模能力。
> 调研方式：内置 web_search（中文主力）+ Exa 语义搜索（`exa-search.ps1`）+ Jina Reader（`jina-read.ps1`，走本地代理 127.0.0.1:7890）读取知乎/豆瓣/澎湃/LINUX DO/B站专栏等正文 + B站搜索 API（标题/简介形态分析，仅第一轮，后因 412 风控弃用）。共两轮调研，以下为合并完整版。
> 平台限制说明：贴吧被 Jina 风控拦截（403）、小红书正文需登录、抖音 403、CSDN 部分页面需安全验证——以上平台结论基于搜索快照 + 跨平台交叉验证。

## 2. AI 使用现状与「AI 代做 vs 自主建模」的用户态度

### 2.1 使用现状

- **普遍在用，已成默认工具**："算法和思路交给ai了"（[LINUX DO](https://linux.do/t/topic/956110/25)）；"有人说自己一点没学，全靠AI，第一次参赛就国奖"（[知乎·北海](https://www.zhihu.com/question/1941292350967121894)）；B站已有"codex 装数学建模自主工作环境，上传题目自动生成最终论文"的 demo 视频（[B站 BV1NRtw6HEKt](https://www.bilibili.com/video/BV1NRtw6HEKt)）。

### 2.2 三大核心问题

| 问题 | 具体表现 | 证据 |
|---|---|---|
| **① AI 直接给答案导致不会（认知牢笼）** | "你问得越外行，它答得越外行"；"AI替代不了认知门槛，它只替代执行门槛"；"你不知道TSP → 你问不出TSP → AI不给TSP方案 → 你以为问题已经解决 → 你永远不会知道TSP存在"；"自身不掌握知识点，你连问都问不出来，也就是'不知道自己不知道'" | [知乎·北海](https://www.zhihu.com/question/1941292350967121894) |
| **② 答案趋同、限制思维** | "不要一上来就依赖AI，上来就用会限制自己的思维…答案趋向于一致化，缺少了你自己的思考"；"AI给的方案一般是标准方案，要拿大奖都得有点创新" | [知乎专栏](https://zhuanlan.zhihu.com/p/1907533263024661802)；[LINUX DO](https://linux.do/t/topic/956110/25) |
| **③ AI 胡说/数学推理不稳定** | 同题多次提问正确率波动 40-60%；"AI生成的回答越长，答对的概率反而越低"；"让LLM自己检查自己的答案，自我纠错成功率不足12%"；"答案正确、过程荒谬" | [AI大模型数学推理不稳定性](https://intelliparadigm.com/article/weixin_32495691/2245163)；[Capital One 答案漂移](https://www.techwalker.com/2026/0812/3196074.shtml)；[LLM数学推理失效瓶颈](http://www.jsqmd.com/news/966819/) |
| **④ AI 依赖破坏团队协作（案例）** | 国一选手自述前队友"非常依赖 GPT，每次遇到问题只会直接截图给我而不说明转述…还用我的 GPT 账号因为他没充钱，比赛结束后我毫不犹豫换了队友" | [2024国一经验分享](https://jishuzhan.net/article/1864885729914523650) |

### 2.3 用户态度总结

- **主流理性观点：AI 能做执行，做不了创新，拿大奖必须自主**——"AI能帮你把问题中规中矩地解出来，但是得分不会很高"（[LINUX DO](https://linux.do/t/topic/956110/25)）；"完成是基本要有，得国奖要有自己出彩的地方"（[知乎专栏](https://zhuanlan.zhihu.com/p/1907533263024661802)）。
- **"全靠 AI 拿国奖"存在但被质疑**："如果AI真那么强，幼儿园小孩用AI也能拿奖"——AI 产出质量取决于使用者认知基线（[知乎·北海](https://www.zhihu.com/question/1941292350967121894)）。
- **最直白的"代做合理论"（认知错位警示）**："建模论文某种意义上就是一本正经的胡说八道，而有时ChatGPT就是干这个的"（[知乎评论](https://zhuanlan.zhihu.com/p/678854949)）——部分用户把数模论文当作"叙事产物"而非"严谨科研"。
- **功利化压倒一切**："现在的赛事30%靠纸面实力，70%靠包装和关系"；编造数据、小tricks是"公开的秘密"，"小白们不懂这个潜规则，也没人公开去说"（[红星新闻](http://www.cqnews.net/web/content_1516937333266776064.html)、[知乎·个人体会](https://www.zhihu.com/question/425833164)）。
- **结论：产品若主打"不作弊的自主能力"，需要把价值讲成"保奖路径"而不是"学习美德"。**

## 3. 需求信号

### 显性需求（用户自己喊出来的）

- "求带/求思路/求速成"：B站头部机构（数学建模老哥、数模加油站、清风）的"速通""保奖班""读题定型+数据诊断"课程播放量数十万到百万级——用户为**"有人带着走、直接告诉我这题怎么下手"**付费，这是"引导"需求的最强付费表达（[B站·数学建模老哥](https://www.bilibili.com/video/BV1bE7G68Err)）。
- 小红书头部博主"小马数学建模工作室"（中科院在读、国一+F奖背书）的变现方式就是**逐题卖"美赛/国赛思路分享"**（[小红书主页](https://www.xiaohongshu.com/user/profile/63566312000000001802e7f2)）——"这题怎么做"可商品化已被市场验证，是"AI 辅助读题"最接近的付费对标物。
- "看懂题/看懂思路"被反复提及："看了下去年的题，思路和算法基本看不懂"（[LINUX DO](https://linux.do/t/topic/956110/25)）。

### 隐性需求（间接信号）

- "买了课一定要保质保量地学习，别半途而废"（[知乎网课推荐](https://www.zhihu.com/question/594624766/answer/2977498216)）——**用户买了课学不完、缺督促**，"陪跑/引导"有真实落点。
- "希望官方评价更体系化…让参赛选手对自身水平认识更清楚"（[美赛失利总结](https://leezeeyee.com/?p=935)）——用户想要**过程反馈/诊断**而非只给结果。
- 教育界方向：电子科大数模课"把'句号课堂'变成'问号课堂'"、天津师大课程直接叫"授人以渔"（[电子科大新闻](https://www.new1.uestc.edu.cn/?n=UestcNews.Front.DocumentV2.ArticlePage&Id=70722)）——引导式/探究式教学在数模领域是被官方认可的方向。
- 工具界已有同类形态：ChatTutor（可视化可交互 AI 教师）、Umath（大学数学自适应学习系统）、DeepTutor、苏格拉底式学习引导器（[GitHub deep-learning-coach](https://github.com/Wenjunyun123/deep-learning-coach)、[ChatTutor V2EX](https://global.v2ex.co/t/1173847)）——**"引导式 AI 辅导"赛道有人在做，但都不是数模垂类、没有把"读题"作为入口**。

### 判断

明确喊"要一个引导我自己建模的工具"的用户少（中文社区主流诉求是结果导向），但"读不懂题、不知道从哪开始、看了思路也看不懂"的底层需求极强；"逐题思路付费"+"买了学不完"+"要过程反馈"三个信号拼起来，指向**"比赛场景下的实时引导+进度督促"是比"系统学习课程"更稀缺的付费价值**。

## 4. 对我们产品定位（AI 辅助读题 + 自主建模 + 可视化）的验证结论

| 假设 | 结论 |
|---|---|
| ✅ **数模新手最大痛点是"上手难、读不懂题、不知道从哪开始"** | **成立，且被多平台一手证据强验证**（豆瓣、知乎、LINUX DO、教育部平台、B站头部机构课程卖点）。"读题"甚至已被商业机构单独立课（数学建模老哥"读题定型+数据诊断"课），侧面证明需求真实。 |
| ✅ **"读不懂题"可拆解为：信息多抓不住重点 / 分不清目标约束因素 / 术语背景不懂 / 数据表格看不懂** | **成立**。每个子项都有原话证据（见痛点清单②③④）。B站专栏"影响vs生态"案例是"目标识别失败"的绝佳教材案例，可直接做成产品内引导样例。 |
| ✅ **现有解决方案（课程/AI 代做/灌输式教学）没帮新手建立自主建模能力** | **成立**。培训班"听了一天课一句没懂"、教材"全是严格数学定义根本看不懂"、"老师讲的很精彩，我听的很激动，下来还是不会用"（[youcans](https://www.cnblogs.com/youcans/p/14824415.html)）、AI"问得越外行答得越外行"——四类方案各自失败，且失败原因恰好互相补位：课程缺实操、代做缺过程、AI 缺认知门槛。 |
| ⚠️ **用户想要"引导式自主建模工具"（显性需求）** | **需修正**：显性需求是"求带/求速成/保奖"，不是"自主建模"。"一本正经胡说八道"论说明部分用户不认为建模需要"自主严谨"。**建议产品话术走"AI 教练陪你把题读明白、把模型搭出来"，价值锚点挂在"参赛结果与效率"上**；引导式/苏格拉底式作为方法内嵌，不要作为卖点外显。 |
| ⚠️ **可视化是用户主动要的** | 间接成立：教程反复强调"重视可视化，一图胜千言""思路框图/流程图能帮你理清逻辑"（[CSDN 解题全流程](https://blog.csdn.net/weixin_29054195/article/details/163741719)）；美赛失利总结明确"美赛论文评审很快，摘要与排版作图很重要"，"提前准备作图模板"是选手的主动行为（[leezeeyee](https://leezeeyee.com/?p=935)）——**可视化既是学习手段也是拿奖刚需**，可作为产品差异化支撑，但用户不会主动说"我要可视化"，需靠产品演示打动。 |
| ⚠️ **"AI 直接给答案导致不会"是普遍现象** | 成立（北海"认知牢笼"论证 + 知乎专栏"答案趋向一致化" + 国一选手 GPT 队友案例 + LLM 数学推理不稳定的技术证据）。**产品应把"防幻觉/可验证"做成信任点：计算交给求解器/符号引擎，LLM 只做解释。** |

### 5.2 观察结论

- **结果导向付费意愿强、价格锚点高**（5000 元~3 万元产业链成熟）；**学习导向付费意愿弱、价格锚点很低**（56 元）。
- **免费替代品极多**：B站 274 万播放免费入门课（[数学建模BOOM](https://www.bilibili.com/video/BV1Rq4y1S7S8)）、Datawhale 开源《数学建模导论》（[GitHub](https://github.com/datawhalechina/intro-mathmodel)）、数模加油站 1849 分钟喂饭级教程——**免费内容已经把"知识讲解"做满了，付费空间只在"过程陪伴/结果保障/个性化引导"上**。
- **投诉侧面印证付费风险**：数学建模老哥"未完成服务拒退款"（[黑猫投诉](https://tousu.sina.com.cn/complaint/view/17398900632)）、淘宝代做"未得奖不退款"（[黑猫投诉](https://tousu.sina.com.cn/complaint/view/17374481341)）——用户被割过韭菜，对"保奖"话术有警惕心，定价与承诺要避开"保奖"雷区，转向"可验证的过程价值"。
- **定价建议**：取中间带（百元级"比赛陪跑/逐题引导/过程反馈"），以"可验证的过程价值"对抗 56 元低价课和"保奖"灰色承诺。

## 附：核心结论速览

1. **"上手难/读不懂题/不知道从哪开始"是新手最大痛点——强验证**，且"读不懂题"可拆为四个子表现（抓不住重点、分不清目标约束、术语不懂、数据看不懂），均有原话证据。
2. **AI 代做 vs 自主建模**：主流理性观点是"AI 能做执行、做不了创新"，但功利化声量大；"一本正经胡说八道"论提示部分用户认知错位，产品叙事要挂钩结果而非学习美德。
3. **需求信号**：显性 = 求带/求速成/逐题思路付费；隐性 = 陪跑督促、过程反馈、引导式教学（教育界与工具界均有方向，但无比我们更贴数模读题场景的产品）。
4. **付费**：结果类付费强（5000~3万），学习类锚点极低（56元），产品取百元级"比赛陪跑/引导"中间带，以可验证的过程价值立身。
5. **产品架构启示**：防幻觉（计算交求解器/符号引擎、LLM 只做解释）、可视化（学习手段+拿奖刚需）、读题引导（商业机构已单独立课证明付费需求）。
