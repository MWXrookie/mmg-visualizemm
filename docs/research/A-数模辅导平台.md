## 二、各竞品详细调研

### 1. 赛氪 saikr.com（环球赛乐（北京）科技有限公司）

- **定位**：自称"成就未来精英的成长引擎"，大学生全品类赛事平台——竞赛报名是入口，业务横跨竞赛、活动、社区、题库、图书、竞赛辅导、论文发表、保研业务、科研项目、实训就业。**数模只是 32 个大类之一**，非垂直深耕。2014 年成立（原"环球竞赛网"），清华/中科院博士+原百度腾讯项目负责人创立，合作 2000+ 高校。
- **核心功能**：5 万+ 赛事免费报名系统（一键导出报名信息）、问答社区、在线考试题库、**竞赛专属课程（报名即赠**：MathorCup/长三角赛/APMCM/华数杯等报名送课）、在线科研项目（AI 方向 199 元，论文发表另付费）、论文发表/保研/留学背景提升服务。
- **如何解决"新手入门难"**："报名→赠课"模式——MathorCup 专属课程含数学建模基础、Matlab、Python，宣称 0 基础可跟，报名账号绑定课程。**无读题引导、无答疑闭环**，赠课质量存疑（知乎有专门提问"赛氪报名美赛配套课程质量高吗"）。
- **收费**：报名系统免费；增值服务付费——科研项目 199 元起、论文发表另付费、保研/竞赛辅导按项目报价。
- **可视化**：无建模可视化，只有题库/考试系统。
- **AI 使用**：页脚出现"赛乐云AI"，未落地到数模用户流程。
- **与本产品差异**：赛氪是"赛事+流量+增值服务"平台，学习体验是赠品；我们要做的是"学习体验即产品"。
- **优点与槽点**：优点=渠道/流量/报名刚需，生态（数学中国、校苑数模、MathorCup 都曾是/是其合作方）；槽点=赠课质量被质疑、数模不垂直、学习体验浅。

### 2. 数学中国 madio.net

- **定位**：2003 年创立的老牌数模社区（百度百科有词条），论坛+培训+自办赛事一体。
- **核心功能**：数模论坛（资料/经验帖）、在线培训（2018"跟着大象学建模"等）、自办赛事——"认证杯"数学中国数学建模网络挑战赛（TZMCM，tzmcm.cn）与"数学中国数学建模国际赛"（小美赛）、会员体系（《会员帮助手册》）。
- **新手入门**：论坛答疑+培训，传统模式，无读题引导。
- **收费**：会员+课程付费（未明码标价）。
- **可视化 / AI**：无 / 未见。
- **⚠️ 重要新证据**：**官网 http://www.madio.net/ 经代理直读返回 HTTP 500（服务器内部错误）**——平台实际运维状态堪忧。结合其近年活动以"认证杯/小美赛"报名与资料下载为主，判断其已从"活跃社区"退化为"历史资料库+赛事运营"，产品交互形态与活跃度均大幅落后。
- **差异**：传统论坛形态已不适合新生代用户；但其历史资料（历年真题/获奖论文/培训讲义）是全网最大的免费资源池之一，可作内容合作/数据来源。

### 3. 校苑数模 / 极值学院（edu.mathor.com）

- **定位**：数模"学习+交流"平台品牌（知识分享、经验总结、竞赛交流），现由 MathorCup/极值职业教育生态承接运营。
- **关键历史事实（已从课程页取证）**：《2017 年数学建模基础培训》页面写明"本课程是**校苑数模在百度传课平台直播的课程**""**赛氪与校苑数模网联合开展**"——讲师**肖华勇**（西北工业大学数模主教练、2008 年国赛 C 题命题人、1997 年起带队获美赛特等奖 1 项/国一 9 项），课程含 Matlab/Lingo 编程、优化模型（TSP/最大流/层次分析法）等。可见其巅峰期（2016-2017）与赛氪深度绑定，办过暑期夏令营（2016）、美赛冬令营（2017）。
- **现状**：课程托管在极值学院（数学建模基础班/实践班，副教授讲师，录播，近一年学员活跃度一般）；极值学院另有 **"精品 1V1"** 栏目与 **VIP 会员** 体系——存在一对一辅导产品。
- **收费**：录播课售卖 + VIP 会员 + 1V1 按需报价。
- **可视化 / AI**：无 / 无。
- **差异**：无独立产品能力，"校苑"更多是资料/课程品牌资产。

### 4. 数模乐园 / 数维杯（nmmcm.org.cn）

- **定位**：数模竞赛主办方+培训服务商，同时是**美赛辅助报名国内头号渠道**（自称"国内指定官方报名平台"）。
- **核心功能**：
  - 数维杯全国大学生数学建模挑战赛（春季+秋季赛，冠名奖 1000 元/创新奖 500 元；指导单位中国软件行业协会，主办中国仿真学会、辽宁科技大学）；
  - **美赛 MCM/ICM 辅助报名**：一站式报名+防错保障+纸质证书印制邮寄+真题解析+备赛大礼包+赛题中文翻译+免费赛前指导；自称十余年服务 **25 万+ 同学**、2025 年报名的团队中 **10 支获 O 奖**（⚠️ 均为自营宣传口径，"整体获奖率高达 99.8%"是典型营销话术——指报名成功/获任意奖的比例，不能解读为实力背书）；
  - **数维杯夏令营/冬令营**：2025 年第十届夏令营=9 天线下集训（8 月 4-12 日，西安欧亚学院），**限招 6-18 人小班**，课程=基础理论强化+模型精讲+算法编程+论文写作+真题剖析，**最后 3 天全仿真模拟训练赛**；冬令营在成都信息工程大学；
  - 国赛线下实地培训班（2025 年多期招募）。
- **新手入门**：线下营（集训+模拟赛）是其核心教学形态，真实体验好但成本高、规模受限；线上仅提供报名配套资料/免费课程（美赛套餐内含赛前培训课程）。
- **收费**：美赛辅助报名**最低套餐 790 元/队**（含官方 100 美元报名费+证书邮寄+翻译+培训资料/课程；套餐二以上叠加系统性专家培训课程）；夏令营/冬令营数千元级（报名链接内报价）。
- **可视化 / AI**：无 / 无。
- **差异**：竞赛主办方身份带来天然流量，营销（知乎软文、QQ 群、公众号）能力极强；但学习交付仍停留在传统授课，无软件化、无个性化。
- **优点与槽点**：优点=赛事权威+报名刚需+线下营真实感；槽点=价格不透明（营地费在链接内）、线上能力弱、宣传数据需打折看；其软文同时警示"承诺保奖/未获奖退费的机构都是骗局"——侧面印证行业乱象。

### 5. 美赛网 mcmicm.org.cn

- **定位**：自述"MCM/ICM 美国大学生数学建模竞赛官网"（WordPress 内容站，沪ICP备2023003166号），实为**美赛信息聚合 + 机构导流页**——页面内嵌在线客服"翰林老师"，推荐"MCM/ICM 金牌冲奖课程、竞赛报名/课程试听"，指向留学机构翰林（hanlin.com/jingsailian.com）。
- **核心功能**：赛事规则（含 25 页限制、96 小时赛程、六道题分类）、2026 赛程（报名截止 2026-1-29 美东 15:00）、获奖论文集/历年真题/备赛资料下载、**COMAP 生成式 AI 使用规则**（允许 LLM 但必须披露）、报名通道。
- **新手入门**：免费干货+付费"金牌冲奖课程"（机构一对一/小班），无软件化学习。
- **收费**：内容免费；课程/报名机构询价（数千元级）。
- **可视化 / AI**：无 / 无。
- **差异**：纯信息站+导流，无产品能力。
- **槽点**：SEO 打"官网"擦边球易混淆用户；内容质量高于产品能力。

### 6. 中国大学 MOOC《数学建模》（中国计量大学，icourse163.org）

- **定位**：国家高等教育智慧教育平台收录高校公开课，零基础到竞赛全层次。
- **完整 12 章大纲**：绪论（建模概念/意义/竞赛）→ 数学规划模型（线性/整数/0-1/多目标+Lingo+Matlab）→ 统计回归（一元/多元/非线性）→ 统计分析基础（参数估计/假设检验）→ 数据拟合与插值 → 时间序列分析（ARMA/ARIMA）→ 主成分分析 → 聚类分析（K-means/层次）→ 判别分析（Bayes/Fisher）→ 微分方程模型 → 网络优化模型（最短路/最小生成树/染色/遍历）→ **论文写作与备战竞赛**。配套 Matlab、Lingo、SPSS 实操。
- **师资与战绩**：王义康、刘学艺、蒋伟峰、李有梅；2015 年国赛"满额奖"（5 国一+5 国二），研究生数模赛获奖率近 70%。教材：姜启源《数学建模》第五版（行业标准）。
- **收费**：免费；电子认证证书（2021 秋起取消纸质）。
- **可视化**：软件演示级，无交互。
- **AI**：无。
- **差异**：最系统的"灌输式"课程天花板；痛点=单向视频、无读题/答疑/练手闭环——正是我们产品的切入场景（"看完课，做这道题"）。

### 8. SPSSPRO（众言科技，上海）

- **定位**：免费专业在线数据分析平台，**全国大学生数学建模竞赛官方赞助合作伙伴**（数模国赛组委会副秘书长张文博公开背书）；150 万+ 个人用户、2 万+ 企业用户。
- **核心功能**：360+ 算法一键建模（描述统计/问卷分析/综合评价 AHP、DEA、TOPSIS/差异性/相关性/预测模型回归、GM(1,1)、K-Means/PCA/ARIMA、GARCH/机器学习决策树、随机森林、XGBoost/规划求解/研究模型可视化/市场研究 Kano 等）；一键生成智能分析报告（AI 大模型自动解读）；PRO 绘图 43 种图表；AI 自动求解（识别数据结构推荐算法）；教育版/工业版。
- **新手入门**：零门槛"小白 5 分钟上手"，拖拽即分析——解决"不会编程怎么做统计"，但**不教为什么选这个模型、不教建模决策**。
- **收费**：个人免费；会员+教育版/工业版付费（企业/高校采购）。
- **可视化**：国内同赛道最强（43 种图表+自动报告）。
- **AI**：有（识别数据结构/推荐算法/生成结论解读）。

## 三、关键洞察：三个差异化点的空白与机会

### ① 读题理解（划词精读 + 附件解析 + AI 反问）——全网空白，最锋利的差异化
- **现状**：所有平台都是"老师/视频讲解某道题"（MOOC、B站、线下营）或"AI 一次性输出题意解析"（MathModelAgent 审题报告、mathmodel-pro 审题阶段）。**没有一家做"用户上传自己的题+Excel/PDF 附件 → AI 逐句陪读 → 划词选中文字、AI 解释其在题目中的地位与信息 → AI 反问引导"的交互式读题**。
- **空白点**：①"划词精读"交互无人做；②附件（Excel/PDF 数据）并入读题无人做（现有 AI 工具读题不碰附件）；③读题阶段苏格拉底式反问无人产品化。
- **机会**：新手"拿到题不知从何下手"是第一痛点（澎湃报道中选手"连轴转 20 多小时调参数"是反面证据）；且该功能与竞赛合规完全兼容（是"理解"不是"代做"）。

### ② 自主建模（AI 教练 vs 代笔）——理念有人喊，产品没人做
- **现状**：市场两极——灌输式课程（看完不会做）与 AI 全自动代做（做完不会说）；中间地带只有"老哥"式真人一对一（贵、靠人力、有履约投诉）与寄生于 Claude/Codex 的开源 Skill（mathmodel-pro 双模式是雏形，但无 Web 产品、无交互界面）。
- **空白点**：把"AI 反问→用户作答→AI 点评→知识卡片补概念"结构化、产品化、Web 化的"教练"没有竞品。
- **机会**：①老哥 30 万学员与"人机协同"官方口径证明理念已被市场接受；②美赛/国赛对 LLM 直接产出的限制（美赛需披露 AI 使用）让"代做型"工具在正式竞赛站不住脚——**"教练"定位是合规红利**；③定价可参考 MathModelAgent（¥99 买断/积分制）做低门槛，对比代做黑市 5000 元，性价比叙事极强。

### ③ 可视化（模型 / 数据分析 / 代码结果可视化）——工具强、教学弱
- **现状**：SPSSPRO 可视化最强（43 种图表、AI 报告、拖拽生成），但只做"统计分析"，**不解释模型为什么这么选、图表怎么读**；MathModelAgent 等能生成论文图表，但图表是"交付物"不是"教学工具"；MOOC/B站是视频演示。
- **空白点**：①"代码运行结果可视化+教学绑定"——用户改参数→图变化→AI 解释为什么，此交互闭环无人做；②"知识卡片"式概念可视化（如决策树/层次分析法图解）无人做；③可视化结果直接沉淀为"解题过程记录/论文素材"无人做。
- **机会**：SPSSPRO 证明了"免费+可视化+AI"的获客力（150 万用户、国赛官方赞助）；我们在"可视化解释教学"上与其互补——它给工具，我们给"为什么"。

### 附加洞察（客群 / 定价 / 渠道）
- **客群**：大一到大三、保研/综测加分驱动（功利动机主导），"快速入门+能出活"是第一诉求；知乎付费咨询（数模类 100-500 元/次）证明个体付费意愿真实存在。
- **价格锚点**：免费课（B站/MOOC/赠课）→ 199-1000 元课（赛氪科研项目/极值学院/老哥）→ 数千元一对一/代做（5000 元黑市价）；**99 元买断 + BYOK 的 MathModelAgent 模式已被验证，是我们定价的现成参照**。
- **渠道**：B站+公众号+QQ 竞赛群是获客主阵地；赛氪/数模乐园验证过的"报名即赠课"转化钩子可借鉴为"上传题目即送 AI 读题体验"。
- **竞合**：SPSSPRO（工具互补）、B站/MOOC（引流上游）、数模乐园/赛氪（渠道合作可能）、MathModelAgent（正面竞争，需以"教练 vs 代做"叙事区隔）。
