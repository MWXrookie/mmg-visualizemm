为什么是它

不是"AI 替你写论文"，而是"AI 帮你读懂题"——新手最痛的第一步，被拆解成可学习的动作。

划词精读

选中任意一句题干，AI 判定它是约束、目标、已知条件还是假设，并解释对建模的影响，置信度可质疑。

Excel 数据联动

上传 xlsx/csv/PDF，表格列名自动关联题干术语——"表 1 的需求量"对应"未来 5 年需求"。

引导式对话

AI 只给思路和反问："哪个量是你要决策的？"——引导你独立说出模型选型与理由，不代做。

知识卡片随题出现

AI 方案里提到"线性规划/回归/聚类"，交互式知识卡片就地展开，动动手就懂。

3 分钟上手

部署在自己的电脑上，全程不经过任何第三方服务器。

1

下载部署

npm install && npm start，浏览器打开即用。

2

配置 Key

填你自己的 DeepSeek/通义 API Key，测试连接，Key 只存本机（AES-GCM 加密）。

3

开始读题

粘贴题目、上传附件，30 秒内获得整体解读与划词精读。
