# G5：G08 来源与再分发边界核验

> 核验日期：2026-09-28
> 状态：来源边界与本地引用入口已核验；G08 确定性基线未完成

## 证据

- [竞赛官网的 2022 年赛题页面](https://www.mcm.edu.cn/html_cn/node/388239ded4b057d37b7b8e51e33fe903.html)提供 `CUMCM2022Problems.rar` 下载，页面底部标示 `All Rights Reserved`，页面没有给出允许第三方复制、改编及再分发的许可。
- 仓库已有 `docs/06-素材/C题.pdf`、`附件.xlsx` 和题干 Markdown；这些文件已存在，不代表取得对外再分发授权。本轮没有复制它们到金标准目录。
- 官方可下载只证明官方允许访问；不能据此把 `source.redistributable` 设为 `true`。这是一项保守的项目发布政策，不构成对权利归属的法律结论。

## 本轮决定

1. 未获得明确授权前，G08 的兼容来源只能标记 `redistributable: false`，不得把真题 PDF、附件或大段题干再复制到 `tests/fixtures/golden/cases/G08/`。
2. `manifest.schema.json` 增加防错约束：如果现有兼容题被标记为可再分发，则必须填写许可证、许可证链接和署名。Schema 只检查字段存在，正式发布前仍须人工核验许可的真实性和适用范围。
3. G08 暂不计入可公开再分发的金标准样本，也不把 9/10 写作 10/10。现有仓库素材是否适合公开保留，需要发布前由项目作者单独处理。

## 本地引用入口

`tests/fixtures/golden/compatibility/G08.sources.json` 只记录现有 PDF、XLSX 的仓库内相对路径和 SHA-256，不保存原题副本。`tests/support/golden-compatibility.js` 仅接受 `local-only`、`redistributable: false` 的 G08 清单，并检查路径与解析后的真实路径均位于 `docs/06-素材/`，随后验证文件类型及内容哈希。文件缺失返回明确的 `missing` 状态；路径越界、版本变化或错误的再分发标记则失败。独立测试覆盖上述边界。该入口不计入正式样本数量，也不证明赛题可再分发。

## 后续切片：本地解析与数据边界基线

- 来源哈希通过后，离线测试实际读取 2 页 PDF 的四问、三张工作表和 85%–105% 有效成分和规则；检查 58 条基本信息、69 个已分类采样点、8 个未知类别样本，已分类样本中编号 15、17 的成分和低于有效区间。空白成分按未检出处理为 0，非空成分必须是 0–100 的数值。
- 已分类采样点以文物编号前两位关联表单 1；未知样本保持独立且不注入已知类型标签。分类参考特征限定为两张成分表共有的 14 个化学成分列，不含编号、类型标签或风化状态。这里仅建立输入和防直接泄漏边界，尚未给出分类器、未知类别判定或敏感性参考结果。
- API 回归进一步核对 PDF 规则与三表内容，发现 XLSX 解析结果按 ZIP 条目顺序返回；已按 `workbook.xml` 中的工作表显示顺序修复，并保持首表兼容字段与第一张显示表一致。
- 在 Windows `core.autocrlf=true` 检出中，37 个受 SHA-256 保护的夹具文本被转换为 CRLF。逐一验证 LF 规范化后哈希与原清单完全一致，未发现内容差异；`.gitattributes` 将金标准夹具设为字节保真检出，避免同类误报。

本地素材缺失时兼容测试显式 `skip`，不能计为通过；发布集仍为 9/10，G08 不取得再分发许可。

## 后续切片：分组分类参考基线

使用现有 XLSX 的有效成分数据建立离线 3 近邻参考模型。每行先将 14 种成分按该行总和闭合到 100%；只使用化学成分，不使用文物编号、类型标签或风化状态作为特征。验证时逐件留出文物，同一文物的多个采样点绝不同时进入训练与验证；每一轮标准化仅在训练采样点上拟合。这个边界参考 [scikit-learn 的 LeaveOneGroupOut](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.LeaveOneGroupOut.html)、[数据泄漏说明](https://scikit-learn.org/1.8/common_pitfalls.html)和[近邻分类示例](https://scikit-learn.org/stable/auto_examples/neighbors/plot_classification.html)。实现为仓库内轻量、确定性的 JavaScript 参考计算，不引入在线模型或新的运行时依赖。

67 个有效已知采样点来自 56 件文物；逐文物留出后的混淆计数为铅钡正确 48、误判高钾 1，高钾正确 15、误判铅钡 3。采样点准确率为 0.940298507，平衡准确率为 0.906462585；这是这份小型兼容样本的内部参考结果，不是 MMG 的模型表现，也没有独立外部验证。8 个未知类别样本仅得到参考预测，绝不计入验证分母或当作已知真值；逐项去掉一种成分以及将近邻数改为 1/5 时，8 个参考预测均未改变。稳定性只覆盖这些有限扰动，不能推出分类正确率或置信概率。尤其 A1 的主要类别指示成分并不明显，仍需人工结合题意复核。

G5 的本地解析、分类、未知样本判定和敏感性参考基线已具备；正式样本第 10 题的再分发路径仍未解决，不能宣称 G5 完整退出。下一项是明确授权或确定原创替代题，并据此完成正式样本的独立加载与验收。
