# 标题字体恢复与轻动效

日期：2026-09-30。用户明确偏好视觉改版前的标题字体，并要求增加小动效提升 UI/UX 流畅感。

## 改动

- 恢复全局标题 Songti SC / SimSun / STSong 衬线栈，以及梳理台原有标题栈。读题大标题使用 600 字重与 0.01em 字距。正文、按钮、代码字体保留各自用途。
- 页面与移动菜单 200ms 透明度淡入；页面容器不添加位移，以免影响选区、定位或内部浮层。
- 鼠标悬停按钮轻抬 1px、上传卡片轻抬 2px，反馈 140ms；禁用按钮不移动。弹窗进入使用 200ms、5px 的轻微上移。
- 既有拆解块展开和箭头旋转统一为 220ms，立即响应，无额外等待。
- 减少动态效果模式下，动画/过渡缩短至 0.01ms、循环次数限制为一次，取消新增悬停位移与平滑滚动。

## 验证

- `npm run check`：31 项 Node 测试、服务端语法、资产生成与生产构建通过。
- `npm run test:browser`：6/6 默认 Chromium 用例通过；当前工作树新增 G03 显式用例，因此本轮共 4 个真实 Pyodide 用例按设计跳过。
- 隔离 Chromium 实际操作：桌面切换工作台、创建拆解块、收起/展开，375px 的菜单与 Esc、深色主题均可用。
- 通过浏览器 Animation API 核对页面动画：0ms 透明度 0.72、100ms 为 0.9117、200ms 为 1；无进入延迟。
- 浏览器模拟减少动态效果：动画/过渡计算时长均为 `1e-05s`，根元素滚动行为为 `auto`。
- 标题计算字体含 SimSun，截图抽查桌面读题/建模、窄屏深色读题/设置，窄屏无横向溢出。
- 一次性核验用内联命令完成；临时服务和数据库清理，不使用真实模型 Key。
- `git diff --check` 通过。
