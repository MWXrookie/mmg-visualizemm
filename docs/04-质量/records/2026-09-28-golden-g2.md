# 金标准评测 G2 五小时包验收记录

- 日期：2026-09-28
- 范围：评测夹具基础设施，以及 G02、G04 两道原创题
- 结论：通过；可以进入 G3 原创题扩充

## 已交付

- 使用 JSON Schema + Ajv 校验样本清单、期望结果、量规锚点和运行记录。
- 加载器校验文件路径边界、SHA-256、题干原文角色引用和附件证据映射。
- G02 覆盖 XLSX 多工作表、缺失值填补、指标方向、综合评价和权重敏感性。
- G04 覆盖 CSV 时间序列、无泄漏留出验证和确定性预测。
- 二进制夹具由可复用生成器维护；默认保留已有 XLSX，避免 ZIP 时间戳产生无意义差异。

## 发现并修复的问题

G02 基线最初把空单元格 `null` 经 `Number(null)` 误判为数值 0，导致未执行题目规定的中位数填补。现改为先显式判定 `null`、`undefined` 和空字符串，再转换为数字；回归断言固定填充值 89 及两个权重场景的前两名。
