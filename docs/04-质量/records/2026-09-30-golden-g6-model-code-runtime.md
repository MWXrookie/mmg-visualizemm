## 实施与实测

- 在逐题导入和解析证据检查之后，经真实浏览器手工填写题干依据、思路和步骤。后端逐题确认拆解块持久化。
- 经编程台生成入口检查请求包含当前题的原文依据、拆解思路及全部附件名；模型响应使用确定性本地替身。生成的代码按题号标识，后端逐题确认保存，刷新后在编辑器恢复。
- Pyodide 由本地替身模拟文件系统和输出，逐题确认浏览器把当前代码传入运行入口、文本回显携带题号、图表可见。替身图像是一像素 PNG，不是模型结果图。
- 发现并修复梳理台拆解块保存计时器被父组件重渲染反复重置的问题；修复仅收窄 effect 依赖，不改变工作区格式、数据流或信任边界。
