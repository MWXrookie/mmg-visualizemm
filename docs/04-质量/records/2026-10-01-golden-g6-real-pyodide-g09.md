# G6 真实 Pyodide 浏览器验收：G09（2026-10-01）

## 范围与来源

- 在隔离 Chromium 和临时数据目录中上传原创展厅信标二维定位题干、坐标约定 PDF 与四信标 CSV。页面和持久化工作区核对 PDF 的欧氏距离模型、米单位及 `0 ≤ x ≤ 6`、`0 ≤ y ≤ 8` 边界；刷新后两附件仍可见。
- 测试拦截模型 API，不读取模型 Key。人工粘贴的 Python 代码在真实 Pyodide 中读取浏览器挂载的 `/data/attachment_2_sheet_1.csv`，计算并输出表格与图表；本切片不评价真实模型能否自行生成代码。

## 数学与流程核对

- 四个固定信标分别位于 (0,0)、(6,0)、(0,8)、(6,8) 米，测距均为 5 米。通过相对于首信标的平方距离差构造线性方程，法方程行列式大于零，信标布局不共线；解为讲解器位置 (3,4) 米。
- 逐信标回算预测距离均为 5 米、残差均为 0 米，总体 RMSE 为 0 米；位置落在 PDF 规定的边界内。真实 Python 的坐标、逐信标结果和 RMSE 与独立 Node 基线、人工 `expected.json` 及浏览器持久化原表分别核对。
- 页面产生可读结果表和真实 Matplotlib 图，图中绘出边界、信标和估计位置，并设置 x/y 等比例。零残差来自无噪声合成数据；共线布局无法唯一定位，真实测距噪声或异常值会影响结果，不能外推为实际定位精度。
