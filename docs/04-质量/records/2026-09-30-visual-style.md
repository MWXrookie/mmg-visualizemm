# 视觉风格统一验收

日期：2026-09-30。用户要求优先优化平台美术风格；在现有未提交工作之上完成，未更改存储、Key、模型或 Python 执行逻辑。

## 设计与改动

- 方向：安静、清晰的研究工作台。低饱和靛蓝 + 浅灰背景 + 白色内容面板，深色使用蓝灰层次；延续现有线性 SVG 图标。
- 全局界面标题与正文统一为本地无衬线字体，保留题干文档与代码各自的阅读字体。无需远程字体或新增依赖。
- 减弱主按钮光晕和卡片阴影，统一细边框、导航选中线、输入框、聊天输入区与发送按钮；修复中等宽度品牌图标被长名称挤压的问题。
- 读题空态改为标题引导、带标签的正文输入、两张文件卡片；右侧说明解释选段精读用途。窄屏收紧引导占高，文件卡片单列显示。
- 修正文案：无 Key 可以先导入题目与手工整理，使用 AI 时再配置。
- 配套布局修正：≤1024px 编程区第一行至少 440px，产出区顺序向下滚动，运行日志高度 110px，避免引导展开时编辑区不可见。

本地 ui-ux-pro-max 检索提供了扁平、低装饰风格参考，但自动布局建议偏营销落地页，未采用；当前工作台布局和用户流程作为设计依据。已同步 `design-systems/mmg_visualizemm/DESIGN.md`。

## 验证证据

- `npm run check`：31/31 Node 测试、语法检查、资产生成、生产构建通过。
- `npm run test:browser`：最终 6/6 默认浏览器用例通过，3 项真实 Pyodide 按设计跳过。窄屏回归增加可编辑区域高度、输入代码、滚动到产出区并返回的断言；视口切换断言等待布局更新。
- Chromium 153.0.8010.12，1440×900 / 375×900，浅色/深色，读题/建模/编程/设置/范例共 20 张截图；检查页面无横向溢出，抽查标题层级、输入区、文件卡片、深色拆解块及设置页。另核对 1024px 品牌图标保持 30px。
- 实际操作无 Key 粘贴题干 → 建模页 → 新建拆解块；使用隔离临时数据库，未请求真实模型。
- 色板计算：浅色正文对白底 14.18:1，次要文字对页面背景 4.71:1，白字主按钮 5.89:1；深色正文对面板 13.68:1，次要文字 7.44:1。仅限这些 token 配对，不代表所有历史组件已完成对比度审计。
- `git diff --check` 通过。临时服务与数据库已清理；一次性命令未落为脚本。
