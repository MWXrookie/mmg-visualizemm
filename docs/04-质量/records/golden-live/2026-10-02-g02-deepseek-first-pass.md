# G02 DeepSeek 首次受控全链路评测（形成性）

日期：2026-10-02。正式原创 G02「校园实验耗材供应商综合评价」。本次由用户明确要求自动推进评测；服务商 DeepSeek，模型 `deepseek-flash`，端点 `https://api.deepseek.com`。沿用先前 ¥10 费用上限。**本记录只覆盖单题一次、人工提供拆解、单人复核，不计为 G6 十题三轮和双评完成。**

## 隔离、请求与费用

- 先运行隔离干跑：0 次上游模型转发，题干与两工作表上传、解读替身、人工拆解、代码替身与刷新恢复通过。干跑发现当前编辑界面不能用旧选择器和服务端直接写入代替前端状态，已在忽略目录的本次受控驱动中改为当前界面操作；失败干跑证据保留。
- 正式运行使用独立 `MMG_DATA_DIR`、新 Chromium context、`MMG_FORCE_LOCAL_EMBEDDING=1`，不读取真实工作区。仅导入正式 G02 题干和原创 XLSX。两条真实 `/api/chat/stream` 请求在转发前分别保存脱敏完整消息及 SHA-256；第三条自动「英文批注中文化」尝试返回本地 429，未转发上游。请求体上限每次 100,000 字节，服务器输出上限每次 16,384 tokens，模型和端点固定；没有测试 Key、外部 Embedding 或重试。原始密钥只在仓库外文件和隔离浏览器设置中使用；本轮忽略目录文件精确密钥扫描 0 命中。
- [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)列出该模型高峰价：输入缓存未命中 ¥2/百万 tokens、输出 ¥8/百万 tokens。本次首次运行 2 次请求且原始请求体分别为 7,255 和 8,963 字节；即使用更宽的每次 100,000 输入 tokens 与 16,384 输出 tokens 计算，两次保守估算低于 ¥0.67。**实际账单尚未核实，不能将估算称为扣费记录，也不能据此推算用户账户余额。**

## 内容与数学验收

- 原样模型代码在真实浏览器 Pyodide 读取两张挂载 CSV，分别为 5×6 供应商表和 5×3 指标说明表；已有服务评分中位数为 89，缺失的 D 被填补为 89。基准与敏感性权重和均为 1，其余四项缩放比为 `0.65/0.75`。
- 从真实输出解析两组各 5 个得分并与独立 `tests/fixtures/golden/cases/G02/baseline.mjs` 对照，容差 `1e-6`：基准排名 `E,D,C,A,B`，最大得分差 `3.98e-7`；敏感性排名 `D,E,A,C,B`，最大差 `2.18e-7`。推荐的前两家集合不变，但顺序交换。运行结果含一张图，代码明确绘制两组得分和权重柱形图；本轮未留图像截图，**不声称已目视核对图像细节**。页面刷新后代码与解读仍保存。
- **内容失败**：模型整体解读声称附件「只有 A/B/C 三行、指标说明只列 3 个指标」，并把年供货上限的方向描述为可能未知、要求用户决定。实际 XLSX 有 5 家供应商和 5 项指标，附件的「指标说明」工作表已规定年供货上限为效益型、权重 0.15。请求消息把完整表头与前三行标为「示例数据」，但没有明确总行数，模型将预览错当全部文件。该错误属于来源忠实性和引导判断缺陷：数值代码正确不能抵消误导性解读。M4 的关键事实与来源不符；由于只有单人形成性复核，本轮不出具可比较的正式 M1–M5 分数或 E1–E4 全通过结论。

## 最小修正与验证

- `web/src/api.js` 的多表摘要现在说明**当前保留行数**和「仅前三行预览，不代表完整文件」。特意不写“文件总行数”，因为 XLSX 解析器仍可能只保留前 100 行。`web/src/pages/Workbench.jsx` 的解读提示要求不从预览推断完整行数或未显示字段是否存在，不能判断时明确请用户查看完整附件。
- 新增 `tests/attachment-summary.test.js`，用五家供应商和两工作表验证行数与预览的区别。独立同项目 Luna 测试对话执行：定向 1/1、`npm run check` 35/35、默认 `npm run test:browser` 10/10，另 10 项真实 Pyodide 按设计跳过；`git diff --check` 通过。测试对话未改产品文件。这里的默认测试和提示词修正**不能证明真实模型已改正错误**，需下次受控调用复验。
- 随后只重测一次 G02 解读：新隔离运行 `2026-10-02-g02-live-57fc6d30` 在请求前保存脱敏完整消息、仅放行 1 次上游聊天；请求确含「当前保留 5 行」与「仅展示前 3 行预览」，刷新后解读保留，证据目录精确密钥扫描 0 命中。新解读**不再声称只有 3 家或 3 项指标**，明确预览不能证明完整表内容；但仍向用户询问「年供货上限作为评价指标还是供货约束」，而真实完整附件已规定其效益型方向和 0.15 权重。本产品整体解读只发送表头与预览，模型无法看到未展示的规则行，因此该疑问仍未由产品自动消解。新提示缓解了错误行数推断，**未证明 G02 的来源忠实性整体通过**。此次没有再次生成代码或运行 Pyodide。
