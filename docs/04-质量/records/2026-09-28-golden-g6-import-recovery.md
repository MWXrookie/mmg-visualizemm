## 现场结论与修复

G5 正式集已存在 10 道可独立加载的题，本切片从最早未满足的 G6 浏览器验收开始。首次逐题测试发现：上传题干调用 `normalizeProblemText` 后，只保存展示分段的 `body`，会丢弃被识别为标题、导语和副标题的前段。G02 的“指标方向和初始权重见附件”因此没有进入工作区，影响后续 AI 读题依据。修复后只统一换行并移除 PDF 分页标记，保留题干原有语义内容；展示层仍使用现有分段逻辑。

- Playwright 在隔离服务及临时 SQLite 中逐题创建工作区，上传正式 G01–G10 的题干和全部必要附件。检查页面解析成功、表格或文本非空、expected 中的角色原句与附件证据原句在刷新后仍存在，并核对表格工作表及证据字段或示例值。10/10 通过。
- `npm run check`：30/30 Node 测试、服务端语法检查和前端生产构建通过。单位回归明确验证题干开头条件不再丢失。
- `npm run test:browser`：4/4 Chromium 冒烟通过，其中新增十题导入与恢复用例；测试结束自动停止隔离服务并清理它创建的临时数据目录。
- `git diff --check`：通过。新增用例未调用真实模型、Embedding 或付费服务；仅保留原有的虚构测试 Key，不写入评测夹具或工作区导出。

- 10/10 仅是题干、附件和刷新恢复路径的产品验证，尚未验证各题建模引导、生成代码、实际 Python 运行、图表、数值合理性或真实模型解释质量。确定性基线的数学断言由 G2–G5 原有测试覆盖，不能代替产品输出评分。
