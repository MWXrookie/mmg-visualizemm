## 2. 摘要核心方法（一句话）

**几何建模 + 离散化光线追迹 + 优化搜索的组合**：先用"坐标系变换 + 反射定律 + 镜面/光锥离散化 + 无效点判断"精确计算单镜光学效率与场输出热功率（问题一），再以"吸收塔选址策略 + 分区域同心圆规划策略"生成排布方案，以"单位镜面面积年平均输出热功率最大化"为目标建立优化模型，用**变步长搜索**（问题二）与**二分法 + 变步长搜索**（问题三）求解最优镜场参数。

## 3. 每个问题的解法

### 问题一：给定参数下计算定日镜场年平均光学效率与输出热功率

- **总体思路**：正向计算。确定镜场输出热功率 `E_field = DNI·Σ Ai·ηi`（式 7），关键是确定定日镜姿态与光学效率。
- **坐标建模**：建立镜场坐标系 XYZ 与镜面坐标系 xyz，用坐标转换矩阵 T（俯仰角/方位角函数）及其逆矩阵在两类坐标系间转换点坐标与方向向量（5.1 节，式 1、16–20）。
- **姿态确定（几何/向量法）**：由太阳高度角 αs、太阳方位角 γs 得入射光线向量 Ii（式 2–4，含赤纬角 δ、时角 ω 天文公式）；由镜心指向集热器中心得反射光线向量 Ri（式 5）；依据反射定律（入射角=反射角），镜面法向量 `ni = (Ri − Ii)/|Ri − Ii|`（式 6）——5.2 节。
- **光学效率五因子分解**：`η = ηsb·ηcos·ηat·ηtrunc·ηref`（式 9）——5.3.1 节：
  - 镜面反射率 ηref：取常数（式 10）；
  - 大气透射率 ηat：与"镜心–集热器中心距离"的二次函数（式 11–12）；
  - 余弦效率 ηcos：入射向量与法向量点积的负值，cosθ 数值上等于余弦效率（式 13–14）；
  - 阴影遮挡效率 ηsb：**分解为塔挡损失、阴影损失、挡光损失三类**：
    - 塔挡损失：塔挡区域等效为"圆柱母线×底面直径"矩形，仅判断定日镜中心是否落入塔挡区域，落入则 ηsb=0（利用"完全覆盖镜数远多于边界镜数 + 镜面中心对称"作统计近似，5.3.1(4)）；
    - 阴影/挡光损失：镜面按 0.1m 步长离散为 60×60=3600 点，对每点制定 **"无效点判断策略"**——把目标点及入射/反射光线经坐标变换转到邻镜坐标系，用直线方程与镜面平面 z=0 求交，交点落入镜面矩形内则记为"无效点"，统计无效点占比 ηl = Sl/S（式 15、21–23）；
  - 集热器截断效率 ηtrunc：**锥形光线离散化**（径向 n1=5 等分 + 周向 n2=12 等分 → 60 条等能量光线，最大锥形角 2λ，λ=4.65mrad，式 24–26），用直线与圆柱面方程联立求交、判别式法判断光线能否射到集热器（式 27–29），按能量计数得 ηtrunc（式 30）。
- **求解流程**：Step1 参数设置（h0=80m、hi=4m、r=3.5m、l=8m、N=1745、Wa=Wb=6m、海拔 3km、ϕ=39.4°、ηref=0.92）→ Step2 求 1745 面镜姿态 → Step3 求 ηat、ηcos → Step4 求 ηtrunc、ηsb（5.4 节）。
- **年均口径**：每月 21 日 5 个时刻（9:00、10:30、12:00、13:30、15:00）共 60 个时刻平均。
- **主要结果**：年平均输出热功率 **36.9945MW**，年平均光学效率 **0.6051**，单位镜面面积年平均输出热功率 **0.5888 kW/m²**（表 5）；并给出每月 21 日各效率折线图（图 9），结论"夏季输出功率大于冬季，ηcos 与 η 呈季节性，ηsb、ηtrunc 与日期关系较小"。

### 问题二：等规格（尺寸/安装高度相同）条件下优化设计镜场参数，达到 60MW 并最大化输出功率

- **反问题思路**：先定排布、再优化参数，属于约束优化。
- **吸收塔选址策略（6.1 节）**：由"正午太阳位于正南 + 春分日光学效率云图（图 10）最优区位于正北"，确定吸收塔建在 Y 轴负半轴、镜场内，即 I=(0, −L0, h0)，L0∈[0,350]。
- **分区域同心圆规划策略（6.2 节）**：以吸收塔为圆心画同心圆划分区域与层：
  - 引入**特征直径** ∆D = Wa + 5（把"相邻镜底座中心距 ≥ 镜宽 + 5m"约束几何化，式 33）；
  - 区域一：同层以特征直径为直径的圆**相切紧密排列**，每层镜数 Ni,j = ⌊2πRi,j/∆D⌋（式 34），层间距 = ∆D（式 35）；
  - 区域二至区域 n：同区域每层镜数相同、层间**交错排列**，不同区域第 1 层周向间距相等（式 36），周向间距与层距满足"特征直径圆不相交"约束（式 37–38），用**周向间距极限因子 Ar** 确定区域层数（式 39），区域间隙取 ∆D（式 40）；
  - 结论：给定 Wa、Wb、h0、hi、L0 即可**唯一确定镜数与全部镜坐标**。
- **优化模型（6.3 节）**：决策变量 Wa、Wb、hi、L0；目标函数为 60 时刻平均单位镜面面积年平均输出热功率最大化（式 41）；约束共 8 条：尺寸（Wa≥Wb、2≤Wa,Wb≤8）、安装高度（2≤hi≤6）、塔位（0≤L0≤350）、相邻间距（Li,j−Wa≥5）、镜位置（镜场内且距塔≥100m）、额定功率（年均输出 ≥60MW）、镜面不触地（Wb/2≤hi）（式 42–50）。
- **求解：变步长搜索算法（6.4 节）**：Step1 大步长（Wa、Wb、hi 取 1m，L0 取 10m）→ Step2 全范围粗搜得初步范围 → Step3 步长缩为 1/10（0.1m）→ Step4 小范围精搜。
- **主要结果**：吸收塔位置 (0,−79)（L0=79m），镜尺寸 **5.5×5.5**，安装高度 **2.75m**，总镜数 **3385**，总面积 102396.3 m²；额定功率 **60.1189MW**，单位面积年平均输出热功率 **0.5871 kW/m²**，年平均光学效率 **0.6028**（表 10–11）。
- **结果分析（6.6 节）**：对比"策略一（紧密相切）、策略二（等数交错）、混合策略"的光学效率，验证混合部署策略更优（图 16）。

### 问题三：允许规格不同（分区差异化）条件下优化设计

- **定日镜规格分区域规划策略（7.1 节）**：同一区域内镜规格（宽、高、安装高度）相同，区域间不同；规格向量 Qk=(Wa,k, Wb,k, hi,k)；据文献取**宽高比 Wa/Wb = 1**（文献最佳范围 [1, 1.5]）；排布仍沿用分区域同心圆规划策略。
- **改进优化模型（7.2 节）**：决策变量为 Qk 与 L0，目标函数同问题二（式 51），约束改为分区形式（式 52–55）。
- **求解：二分法 + 变步长搜索（7.3 节）**：因多区域变量维数高，先用**二分法**搜索 L0 最优值（自 L0=175 迭代 n0 次），再以大步长（1m）粗搜 Wa,k、hi,k 得初步范围，步长缩为 1/10（0.1m）精搜至要求精度。
- **主要结果**：镜尺寸 **6.4×6.4**，共 **7 种安装高度（3.2~3.8m）**，吸收塔位置 (0,−79)，总镜数 **2846**，总面积 116572.2 m²；额定功率 **61.8593MW**，单位面积年平均输出热功率 **0.5307 kW/m²**，年平均光学效率 **0.5446**（表 14–15）。

## 5. 亮点与创新

1. **"无效点判断策略"统一处理镜间遮挡**：把复杂的阴影/挡光损失化为"坐标变换 + 直线–平面求交 + 矩形包含判断"的标准化流程，逐点遍历镜面离散点，物理意义清晰、可实现性强（5.3.1(4)）。
2. **塔挡损失的精妙简化**：利用"塔挡区域完全覆盖的镜数远多于边界镜数、镜面中心对称"的统计近似，用镜心是否落入塔挡矩形区域代替逐镜阴影范围计算，大幅降计算量且误差可控（5.3.1(4)、图5）。
3. **分区域同心圆规划 + 混合部署策略**：内区"特征直径相切紧密排列"、外区"等数交错排列"，并以三种策略的光学效率对比（图16）验证混合方案优势，属论文的排布设计加分点（6.2、6.6）。
4. **吸收塔选址策略用光学效率云图支撑**：用春分日平均光学效率分布云图（图10）直观确认正北最优，把"正午太阳在正南"的物理规律转化为量化选址约束（6.1）。
5. **变步长搜索 + 二分法的求解工程化**：纯遍历框架下用"大步长粗搜 → 步长缩 1/10 精搜"（问题二）、"二分定 L0 + 变步长定规格"（问题三）控制计算量，并自评"可较快且精准地找到优质解"（6.4、7.3、9.1）。
6. **高精度光线追迹**：模型优点中明确"对每面定日镜上 40 余万根光线追迹，光学效率求解精度高"（9.1）。
7. **系统的灵敏度分析**：分别对集热器高/直径（[4,10]m、[4,12]m，步长 1m）与吸收塔高度（[50,110]m，步长 5m）做单因素扰动，得出"年均光学效率对集热器尺寸较敏感（−13.9%~2.3%）""各效率对塔高敏感性排序：余弦效率 > 截断效率 > 阴影遮挡效率 > 大气透射率"等定量结论（八）。
