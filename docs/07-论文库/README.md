## 方法地图（从获奖论文中提炼的高频模型，按问题类型）

> 频率标注（★ 高 / ● 中 / ○ 低）依据：4 篇精读获奖论文的实际使用 + 方法地图行业共识。
> 每张卡片的具体来源与"高频/低频"说明已写入《知识卡片产出清单.md》与产品卡片内容。

### 1. 评价类（"选哪个 / 排第几 / 打分"）★ 最高频
| 方法 | 频率 | 卡片状态 |
|---|---|---|
| 层次分析法 **AHP** | ★ 高 | 📌 待做卡片（C283 用熵权法+AHP 组合赋权，一致性检验） |
| **TOPSIS** 优劣解距离法 | ★ 高 | 📌 待做卡片（C066 主方法：熵权法定权 + TOPSIS 排序） |
| 熵权法 | ★ 高 | 📌 待做卡片（C066、C283 均用；客观定权，常与 TOPSIS/AHP 搭配） |
| 多指标评价体系构建 | ★ 高 | 📌 待做卡片（C066 6 指标 / C283 9 指标，系统性·科学性·可比性原则） |
| 模糊综合评价 | ● 中 | 📌 待做卡片 |
| 灰色关联分析 | ● 中 | 📌 待做卡片 |

### 2. 预测类（"未来会怎样"）
| 方法 | 频率 | 卡片状态 |
|---|---|---|
| 回归预测（线性/多元） | ★ 高 | ✅ 已有：线性回归（多项式）；2018C 用回归建模激活率与促销关系 |
| 灰色预测 **GM(1,1)** | ★ 高（小样本场景） | 📌 待做卡片 |
| 时间序列 ARMA/ARIMA | ● 中 | 📌 待做卡片 |
| BP 神经网络 / 机器学习回归 | ● 中 | 📌 待做卡片 |
| Dirichlet 回归（成分数据） | ○ 低（专有场景） | 📌 待做卡片（C229 专用于风化前成分预测） |
| 高斯过程回归 | ○ 低 | 📌 待做卡片（C066 拟合供货偏差） |

### 3. 优化类（"怎么安排最优"）
| 方法 | 频率 | 卡片状态 |
|---|---|---|
| 线性规划 / 整数规划（含 0-1 变量） | ★ 高 | ✅ 已有 |

| 动态规划（逐周决策） | ● 中 | 📌 待做卡片（C066 每周方案受前周库存影响） |
| 贪心算法（双层嵌套） | ● 中 | 📌 待做卡片（C283 外层选供货商+内层选转运商） |

| 排队论 / 图论（Dijkstra·Floyd） | ○ 低 | 📌 待做卡片 |
