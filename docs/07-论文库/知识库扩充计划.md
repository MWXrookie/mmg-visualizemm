## 三、精读制式流程（每篇论文都走这套"流水线"）

```
① 下载入档     → docs/07-论文库/<年份>-<题>-优秀论文-<编号>.md
② 结构化精读   → 提炼报告：赛题/摘要方法/逐问解法/知识点清单/亮点/局限
                 （记录到 docs/07-论文库/_精读中间结果.md）
③ 方法提炼     → 与现有方法库比对：
                 已有方法变体 → 追加"论文实例"到该方法的来源字段
                 全新方法     → 新建方法库条目（制式模板见下）
④ 卡片产出     → 有价值且可交互的 → 制式卡片（模板见下）
⑤ 知识库重建   → 方法库/卡片库 md 更新 → 重启后端 → RAG 自动索引新块
⑥ 验证         → CDP：卡片渲染 + 检索命中新方法 + 无冲突
⑦ 提交         → 本地 commit（用户确认后推送）
```

## 四、制式产出模板

### 模板 A：方法库条目（RAG 用，JSON-like Markdown）
```markdown
### 方法：<方法名>
- 类型：<评价/预测/优化/分类/统计/机理/数据挖掘/图论>
- 频率：<高/中/低>（依据：XX 年 X 题论文使用）
- 适用场景：<什么信号下选它>
- 使用步骤：<1. 2. 3.>
- 失效边界：<什么情况失效/不稳>
- 评委视角：<评分点/易扣分处>
- 来源论文：<年份-题号-编号> §<章节>
```

### 模板 B：知识卡片（产品内交互）
```js
{
  id: 'kebab-case-id',
  title: '中文名',
  tag: '类型 / 细分',
  concept: '概念 + 频率句（含来源论文）',
  demo: <React 交互演示组件（SVG/滑块/步骤条）>,
  try: '引导思考的问题',
  related: ['相关卡片'],
  freq: '★ 高频率', freqLevel: 'high', src: '来源论文+章节',
}
```
配套：`CONCEPT_KEYWORDS` 注册触发词（AI 输出命中→自动嵌卡）。

### 模板 C：深度精读档案（高价值论文）
对方法论有独特贡献的论文（如 2018A RGV 蒙特卡洛调度、2016A 系泊多目标），额外产出
`深度精读档案-<编号>.md`（决策链/公式复现/评委视角/同题对比），并同步进 RAG。

## 七、质量与安全约束

1. **只做方法提炼，不全文转载**：论文只存 OCR 文本镜像用于精读与 RAG，产出的是结构化方法/卡片（符合 README 版权声明）
2. **每批验证**：CDP 冒烟（新卡渲染/交互/检索命中/无冲突）+ 构建通过才 commit
3. **RAG 生效**：方法库/卡片库 md 更新后，知识库缓存指纹变化自动重建（无需手工干预）
4. **资源池筛选**：下载前先验体积（>3KB 才有内容，2019A 等空壳跳过）
5. **敏感文件**：.env.local（key）与缓存不提交
