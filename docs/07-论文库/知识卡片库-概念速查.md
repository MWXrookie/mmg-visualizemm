### 卡片：决策树
- 类型：分类 / 回归
- 概念：按条件逐层划分数据的树形模型——每一步问一个"是否"问题，把数据分到不同分支，最终落在某个类别或数值上。
- 小白批注：比如"判断一个水果是苹果还是梨"：先问"颜色红不红？"再问"形状圆不圆？"，一层层问下去就能分出来。树的每一层就是一道判断题。
- 来源：2022 国赛 C 题一等奖论文（C229 §6.2.1）：用决策树按氧化铅含量阈值把玻璃分成铅钡/高钾两类，测试集正确率 100%

### 卡片：线性回归（多项式）
- 类型：预测 / 拟合
- 概念：用最小二乘估计系数。即使加入 x² 等项，只要系数以线性方式进入，仍可用线性回归。
- 一句话定义：利用观测数据拟合变量的平均关系，并用留出的数据检验预测误差。
- 小白批注：观测噪声是数据围绕规律的波动。曲线在已见数据上很贴合时，也可能在没见过的数据上预测较差。
- 什么时候用：要解释或预测连续数值，且能留出数据比较基线和更复杂的模型时。
- 注意事项：数据有时间顺序时按时间留出验证。用验证误差和残差检查，而不凭训练拟合好坏判断预测能力。
- 演示说明：圆点用于拟合，方块暂时留出。RMSE 与目标值同单位，越小表示这组数据上的误差越小。
- 演示解释：交互演示中的“噪声”是观测值围绕真实规律的随机波动，例如测量误差、个体差异或未纳入模型的因素；它不是图像处理里的颗粒噪声。噪声越大，散点离总体趋势越远，回归线越难稳定地看出规律。
- 来源摘要：多届 C/A 题用回归或多项式拟合做趋势刻画。
- 来源：2017 国赛 C 题一等奖论文（五元线性 + 完全二次回归）、2016 国赛 C 题（二次多项式拟合放电曲线，R²=0.9999）、2018 国赛 C 题（激活率回归）、2015 国赛 A 题（二次拟合定经度）

### 卡片：K-means 聚类
- 类型：聚类 / 分组
- 概念：把数据点分成 K 组，使组内点尽量接近、组间尽量远离——适合"无标签"数据的分群任务。
- 小白批注：想象把班里同学按"身高和体重"分成 3 堆：先随便选 3 个代表，谁离哪个代表近就归谁，再重新算每堆的中心点，再分一次……反复几次就稳定了。"无标签"=事先不知道分几类、每类是谁。
- 来源：2022 国赛 C 题一等奖论文（C229 §6.2.2）：先用 NbClust/肘部法确定最优 K=3，再做 K-means 划分玻璃亚类

### 卡片：线性规划
- 类型：优化 / 决策
- 概念：线性规划是在一组线性约束下优化线性目标，用来安排可以连续取值的资源或产量。
- 一句话定义：在一组线性约束下最大化或最小化线性目标函数。
- 小白批注：把两种产品的产量记为 x、y。原料上限决定哪些组合可行，利润式决定在可行组合里选哪一个。
- 什么时候用：变量可连续取值，且总成本、资源用量等奖惩和限制都可以表示为线性关系时。
- 注意事项：有界多边形至少有一个最优顶点，也可能有整条最优边。只有整数产量可行时，要另表达整数限制。
- 演示说明：移动目标等值线，比较最后接触可行域的位置。切换两种目标可看到最优顶点与最优边。
- 来源摘要：2021 C 题用规划骨架做订购与转运方案。
- 来源：2021 国赛 C 题两篇一等奖论文（C066 §6.1 / C283 §6.1）均以（整数/多目标）规划为方案骨架

### 卡片：整数规划
- 类型：优化 / 整数约束
- 概念：线性规划 + "决策变量必须是整数"的约束——车辆、人员、批次数这类不能取小数的数量问题，必须用整数规划。
- 小白批注：和线性规划唯一的区别：答案必须是整数。比如"派几辆车""招几个人"，总不能派 3.7 辆车。选供应商用 0/1 变量就是"订=1，不订=0"。
- 来源：2021 国赛 C 题一等奖论文（C066 §6.1）：用 0-1 逻辑变量表示"是否向该供货商订货"

### 卡片：随机森林
- 类型：集成学习 / 分类
- 概念：种很多棵"意见不同"的决策树，让它们各自判断后投票——单棵树容易犯错，但很多树商量着来就稳得多。
- 小白批注：就像开评审会：一棵决策树是"一个人的意见"，容易拍脑袋；种几百棵树、每棵只看部分特征，最后投票，少数服从多数，结果就稳了。
- 来源：分类集成高频方法（方法地图）；真实获奖论文以决策树 / PLS-DA 为分类主力，随机森林是其稳健升级版

### 卡片：主成分分析（PCA）
- 类型：降维 / 特征提取
- 概念：数据通常沿某些方向变化最大——PCA 找出这些"主方向"，把高维数据投影到低维，保留最多的差异信息。
- 小白批注：想象把一张人脸照片从"几百万像素"压缩成"几百个关键数字"还不失真——PCA 就是找数据里"差异最大"的方向，把高维信息压到少数几个方向上。
- 来源：高维多变量降维首选（方法地图）；成分数据场景可配 clr 变换（2022 年 C 题一等奖论文 §8.3 展望）

### 卡片：熵权法
- 类型：评价 / 客观定权
- 概念：将指标在各方案中的值转成比例，再用归一化的信息熵衡量比例分布的均匀程度。比例越不均匀，按此方法得到的权重越高。
- 小白批注：为什么"所有值都一样"的指标权重是 0？因为大家都一样就分不出好坏，等于没信息。好比全班都考 100 分，这科成绩就没法帮你排名——这样的科目不该占权重。
- 来源：2021 国赛 C 题一等奖论文 C066 §5.2、C283 §5.1.3（熵权法定 6/9 个指标权重）

---

### 卡片：TOPSIS 优劣解距离法
- 类型：评价 / 排序
- 概念：用各指标的最好值和最差值分别组成理想方案和最劣方案。计算候选方案到两个参照点的距离，再按相对贴近度排序。
- 一句话定义：把方案与理想最优解、最劣解的距离转成相对贴近度来排序。
- 小白批注：就像选手机：先想"完美手机"（什么都最好）和"最差手机"（什么都最差），每款真机都比一比——越像完美的越值得买，越像最差的越别买。
- 什么时候用：多指标评价、需要给候选方案排序，且指标方向和权重已经确定时使用。
- 注意事项：结果对指标选择、标准化方式和权重敏感；贴近度只能表示相对排序，不能当成绝对分数。
- 演示说明：移动理想点可以看到排序会随指标目标和权重设定变化，适合用来理解敏感性。
- 来源摘要：2021 C 题常与熵权法组合评价供应商。
- 来源：2021 国赛 C 题一等奖论文 C066 §5.2-5.3（熵权法确定权重 + TOPSIS 评价 402 家供货商）

### 卡片：层次分析法（AHP）
- 类型：评价 / 主观定权
- 概念：将决策拆成层级，通过两两比较表示各准则的相对重要程度。由比较矩阵推得权重，并检验判断之间的一致性。
- 小白批注：把"选哪家供应商"拆成三层：目标（选最好的）→ 准则（质量/价格/交期）→ 方案（A/B/C 三家），再两两对比打分算出各准则权重。判断矩阵=打分表，一致性检验=检查打分自不自相矛盾（比如 A>B、B>C 却说 C>A 就是矛盾）。
- 来源：2021 国赛 C 题一等奖论文 C283 §5.1.3（AHP 修正熵权权重 + 一致性检验）；2017 国赛 C 题一等奖论文（AHP 量化影响因子）

### 卡片：多目标规划
- 类型：优化 / 多目标
- 概念：加权求和允许目标互相补偿，应先统一方向和尺度。序贯解法（分层序列法）先求第一目标的最优值，保留达到它的方案，再优化第二目标。
- 一句话定义：当成本、质量等目标互相牵制，先明确允许取舍还是存在严格优先级。
- 小白批注：采购时，若愿意多付一些换更少损耗，可以比较加权结果。若成本必须最小，则只在最低成本方案中看损耗。
- 什么时候用：有多个候选方案，且改进某个目标可能牺牲另一个目标时。
- 注意事项：先问清目标优先级。预算红线是约束；严格优先级也不能直接用随意选的权重替代。
- 演示说明：用同一组方案比较按权重取舍和成本优先。A、B 的最低成本相同，可以观察第二级如何选。
- 来源：2021 国赛 C 题一等奖论文 C066 §6.1、C283 §6.1（双目标加权）；2020 国赛 A 题 A147 §5.4（min-max 无量纲化 + 线性加权）；2021 国赛 D 题 D026（序贯解法/分层序列法）

### 卡片：联合优化
- 类型：优化 / 多决策耦合
- 概念：多个**相互耦合的决策变量**一起优化——比如"订多少货"和"怎么运"互相影响，分开定会得到次优解，必须放在同一个模型里同时求解。与"多目标规划"不同：它强调**决策变量耦合**而非**多个目标**。
- 小白批注：关键在"互相影响"：订多少货决定怎么运才划算，怎么运又反过来限制能订多少。分开各算各的，就像"先定菜单再算买多少菜"，可能整体不划算；放一起算才是最优。
- 来源：2021 国赛 C 题一等奖论文 C066（订购方案+转运方案联合优化）；2021 国赛 D 题（连铸切割+调度联合决策）

### 卡片：遗传算法（GA）
- 类型：优化 / 智能算法
- 概念：维护一组候选解，通过选择、交叉和变异产生新的候选解，用目标值比较搜索结果。它可用于组合和非线性优化，但不保证找到全局最优。
- 小白批注：把一堆候选答案当成"生物种群"：每次留下表现好的（选择），让它们"生小孩"（交叉：两个答案拼出新答案），再偶尔"变异"一下，一代代进化，答案越来越好。
- 来源：2021 国赛 C 题一等奖论文 C066 §6.1.4/§6.4（四问全部用遗传算法求解）；2015 国赛 A 题（遗传算法反演参数）

### 卡片：相关性分析
- 类型：统计 / 相关
- 概念：Pearson 衡量数值变量的线性关系；Spearman 是平均秩之间的 Pearson 相关，衡量有序数据的单调关系。两者取值从 −1 到 1，正负表示方向，绝对值表示对应关系的强弱。
- 一句话定义：用系数描述成对观测的变化关系：Pearson 看线性，Spearman 看单调；系数接近 0 不排除其他规律。
- 小白批注：先把同一对象的两个观测配成一行并画散点图。直线上升和一直上升的弯曲都可能相关；U 形先降后升，两种系数都可能接近 0。热力图汇总两两系数，但会隐藏散点形状。
- 什么时候用：想探索成对数值观测的线性关系，或有明确顺序的数据的单调关系时使用。先确认观测配对、缺失值处理和异常点。
- 注意事项：相关不等于因果，接近 0 不等于独立。无序类别不能任意编号后做秩相关；常量列的系数未定义。计算 Pearson 系数不要求正态，但 p 值和区间的推断需另查假设；本演示不做显著性检验。
- 演示说明：依次比较线性关系、单调弯曲、U 形关系与随机样本。32 个点均为教学合成数据；图形、系数和解释同步切换。
- 演示解释：单调弯曲示例 y=2t⁵−1 的 Spearman 为 1；U 形示例不单调，两种系数都接近 0。不能把所有非线性关系解释为高 Spearman。
- 来源摘要：方法依据：SciPy 官方 pearsonr / spearmanr 文档；论文只作应用案例，不作为通用适用条件。
- 来源：SciPy 官方文档：https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.pearsonr.html ；https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.spearmanr.html （2026-10-08 核验）。本地应用案例：C229 §6.1.1 / §6.4.1；其定性变量编码不能推广为无序类别可任意排序。

### 卡片：数据预处理
- 类型：通用 / 第一课
- 概念：先核对数据是否满足当前模型所需的类型、单位和完整性，再决定怎样处理缺失和异常。
- 一句话定义：在计算之前，先弄清每一列记录了什么，哪些值需要核对。
- 小白批注：看见异常值先查原始记录和计量单位。确有录入错误就更正，有依据的极端记录可以保留，无法核实则标记并比较不同处理的影响。
- 什么时候用：刚拿到表格，或发现空值、可疑值、同名列用了不同单位时。
- 注意事项：缺失处理取决于用途，不能把缺失当成 0。z 分数可以为负，与非负归一化、指标同向化用途不同。预测时先划分训练与验证数据。
- 演示说明：切换四个步骤，看 W2 的缺失如何保留，W3 又如何依据原始凭证更正。
- 来源摘要：应用案例的处理规则各有不同，演示使用合成记录。
- 来源：C229 §5.1-5.2（众数/热卡/乘法替换）、C066 §四（低质量剔除）、C283 §5.1.1（阈值筛选）、2018C §5.1（无效剔除）、2016C §5.1（删前 10% + 单位换算）

### 卡片：模拟退火（SA）
- 类型：优化 / 启发式
- 概念：像金属退火一样"先高温乱跳、再慢慢降温收敛"，用 Metropolis 准则（温度高时接受差解的概率大、温度低时几乎只接受更优解）跳出局部最优。
- 小白批注：好比爬山找最高峰却起了雾：先大步乱走（高温），可能走下山坡，但能绕开"假山顶"（局部最优）；雾散了（降温）就小心往高处挪，最后稳稳站上真山顶。Metropolis 准则就是"要不要接受这次乱走"的掷硬币规则。
- 来源：2013 国赛 B 题（碎纸复原 §4.1.6，Metropolis + 冷却进度表）；2015 国赛 A 题（§4.2，初温 8000、退温 0.9）

### 卡片：卡方独立性检验
- 类型：统计 / 显著性
- 概念：卡方独立性检验衡量列联表观测频数与独立假设下期望频数的差异。
- 一句话定义：比较两类分类信息的实际计数与假设独立时的期望计数。
- 小白批注：假设两变量独立，p 值表示在这个假设及检验条件成立时，得到当前这么大或更大的卡方统计量的概率。
- 什么时候用：每个独立观测都被归入两个分类变量，想问两者有无关联证据时。
- 注意事项：p 值不表示假设为真的概率，也不衡量效果大小。这个 2×2 演示要求每格期望频数至少为 5，较小样本可考虑 Fisher 精确检验。
- 演示说明：切换独立示例和风化示例。先看每格实际次数与期望次数差在哪里，再看统计量。
- 来源摘要：应用案例为玻璃类型与风化的列联表；演示采用 Pearson 卡方统计量。
- 来源：2022 国赛 C 题一等奖论文 C229 §6.1.1（卡方检验风化与类型/纹饰/颜色）+ §6.4.2（配对 Wilcoxon）；2021 国赛 C 题 C066 §6.3（K-S 拟合优度）；2023 国赛 C 题（Shapiro-Wilk 正态性）

### 卡片：多指标评价体系
- 类型：评价 / 指标构建
- 概念：把综合判断拆成若干定义清楚的指标。它们应覆盖目标、可比较且尽量避免重复衡量，还要明确每项指标是越大越好还是越小越好。
- 一句话定义：把「哪个好」拆成几项可比较、能解释的指标。
- 小白批注：例如比较食堂供应商，可看总价、准时率和质量。价格越低越好，准时率越高越好。供货波动和供货稳定性若反映同一件事，两项都计分可能重复加权。
- 什么时候用：多个候选方案无法只靠一个量决定，而且每项指标都能给出一致口径。
- 注意事项：先统一指标方向和单位口径，再检查缺失和重复计分。给权重前，说清各指标为何与你的目标有关。
- 来源：2021 国赛 C 题一等奖论文 C066 §5.1（6 指标：供货次数/平均供货量/单次最大供货量/稳定性/连续性/合理比例）；C283 §5.1.2（9 指标）

### 卡片：动态规划（逐阶段决策）
- 类型：优化 / 递推
- 概念：把多阶段决策拆成"每阶段只依赖上一阶段状态"的递推——本周库存=上周库存+收货−消耗。
- 小白批注：核心是"这周的决定只看上周的状态"：本周库存=上周库存+进货−消耗，只要知道上周剩多少，就能算这周怎么订。像下棋只看当前局面，不用重推整盘。
- 来源：2021 国赛 C 题一等奖论文 C066 §6.4（逐周求解订购方案，本周依赖前周库存）；2014 国赛 C 题一等奖论文（逐次决定卖肉猪/猪苗）

### 卡片：存贮模型（EOQ）
- 类型：优化 / 库存
- 概念：库存管理的核心问题——订多少、何时订。用"警戒点"（最低安全库存）触发补货，用经济订货量平衡订货成本与持有成本。
- 小白批注：库存问题就两问：订多少（经济订货量 Q*：订货费 vs 仓储费平衡）、何时订（警戒点：库存低于它就补货）。好比家里米快吃完了（警戒点），一次买几袋最划算（Q*）。
- 来源：2021 国赛 C 题一等奖论文 C283 §6.1.1（经济进货存贮模型，库存警戒点=两周产能 5.64 万）；C066 §6.2（库存维持约束）

### 卡片：贝叶斯模型 + MCMC
- 类型：预测 / 概率
- 概念：先验 + 数据 → 后验：把"经验"和"证据"结合，用 MCMC 采样近似后验分布。
- 小白批注："先验"=你原来的经验，"数据"=新证据，"后验"=两者折中的结论。比如你原先觉得某店销量一般（先验），看了它最近 10 天卖爆的数据，结论就会往"卖得好"偏一点。MCMC 只是算后验的数学工具，不用自己手算。
- 来源：2023 国赛 C 题优秀论文 C126（Bayesian 销量/补货量模型，WinBUGS MCMC，30000 迭代 + 收敛四重诊断）

### 卡片：微分方程建模
- 类型：机理 / 方程
- 概念：用方程描述物理量的变化规律：热传导 ∂u/∂t=a∂²u/∂x² + 边界换热（牛顿冷却），或 F=ma 列运动方程。机理题先推方程再求数值解（Runge-Kutta/差分）。
- 小白批注：用"变化的规律"来建模：比如"温度每秒下降多少，和温差成正比"写成方程，再解出任意时刻的温度。F=ma 也是微分方程——力决定加速度（变化率），加速度再决定位置。
- 来源：2020 国赛 A 题优秀论文 A147 §5.1（一维热传导方程+牛顿冷却定律，有限差分求解，R²=0.9813）；2022 国赛 A 题优秀论文 A171 §5.1-5.2（牛顿第二定律+拉普拉斯变换/Runge-Kutta）

### 卡片：蒙特卡洛方法
- 类型：仿真 / 随机
- 概念：用大量随机采样近似复杂积分/期望——高维积分、随机模拟、风险估计都靠它。
- 小白批注："大量随机试，统计结果"：往一个正方形里随机撒 1 万个点，数多少点在圆里，就能估算圆的面积和 π。点数越多越准。搞不清的复杂期望、积分都能这么"撒点估算"。
- 来源：2021 国赛 A 题优秀论文 A217 §7.2（蒙特卡洛积分：圆形口径分解为三角形投影域+边界修正，接收比 0.811%→1.103%）；2021 国赛 C 题 C283 §6.1（偏差率/损耗率正态随机模拟）

### 卡片：灰色预测 GM(1,1)
- 类型：预测 / 小样本
- 概念：GM(1,1) 用累加减弱短期波动，拟合一阶变化规律，再还原成对原序列的估计。它适合探索近似单调趋势，预测仍需用未参与拟合的数据检验。
- 小白批注：数据少（比如只有 5 个点）也能预测的绝招：先把序列累加起来看趋势（累加生成），趋势顺了再还原成预测。好比只看 4 天的销量也能估下个月——数据越少越显它的价值，数据多时反而不如回归。

### 卡片：粒子群算法（PSO）

- 概念：一群粒子在解空间里飞，每个粒子记住自己的历史最优（pbest）和群体最优（gbest），速度朝这两个方向加权更新——"向最好的学习"。
- 小白批注：一群"粒子"在解空间里飞，每个都记得自己到过的最好位置，也听群体的最好位置，朝这两个方向飞。像一群鸟找食：既记得自己发现过的好地方，又跟着鸟群往大家发现的好地方去。

### 卡片：调度下界与可达性
- 类型：优化 / 组合调度
- 概念：若每轮最多完成 c 项任务，完成 n 项至少要 ⌈n/c⌉ 轮。这只是容量下界，能否达到还取决于依赖和资源限制。
- 一句话定义：下界说明任何可行安排至少需要多少资源。能构造一个达到下界的安排，就能证明它最优。
- 小白批注：轮数、车辆数和机器数都可以用容量下界估计。例如每辆车最多载 30 人，安排 65 人至少需要 3 辆车。再检查站点、班次或时间限制，才能确定三辆是否够用。
- 什么时候用：要证明轮数、设备数或分组数无法更少，并能用容量、总量或时序推出一个理论下限时。
- 注意事项：下界可以算得正确但无法达到。发现一个恰好达到下界的方案前，先核对可行条件。
- 来源：2022 国赛 D 题优秀论文 D999 §5.1（信息传输率最大化原则+对称性调度+构造性证明）

### 卡片：贪心算法

### 卡片：用上下界分析切割损耗
- 类型：优化 / 解析下界
- 概念：对最小化损耗的问题，数学约束给出的下界不超过最优值；任一可行方案的损耗不低于最优值。上下界相等时，就找到了最优值。
- 一句话定义：用下界估计损耗最低能到哪里，用已经可行的切割方案给出实际能做到的上界。
- 小白批注：切木板和裁布都可以先把边角损耗夹在两个数之间。等长切割中可用取整估计单根材料能切几段，混合长度、刀缝或最小余料要求会改变这个估计。
- 什么时候用：直接枚举切割方案较多，且能根据长度、数量或工序建立有用的上下界时。
- 注意事项：先明确损耗是剩余材料、刀缝还是不能再利用的废料。某个板材长度下的余料公式需要重新核对适用条件。

### 卡片：卷积分布离散化
- 类型：仿真 / 概率分布
- 概念：两个变量离散时，将所有加起来等于同一和值的组合概率相加。连续分布可用积分求卷积，也可先划分区间再作数值近似。
- 一句话定义：卷积把两个独立随机变量各自的分布合起来，得到它们的和的分布。
- 小白批注：两次独立掷骰子时，点数和为 7 有多种组合。把这些组合的概率加起来，就得到和为 7 的概率。独立工序的用时也可用类似思路分析。
- 注意事项：变量有关联时要用联合分布。先离散化会产生近似误差，区间宽度要与用途匹配。
- 来源：2023 国赛 D 题优秀论文 D039 §6.3（孕期结束分布离散卷积成 3 分支）

### 卡片：非对称损失期望（蒙特卡洛）
- 类型：仿真 / 风险期望
- 概念：非对称损失让同样大小的正负偏差承担不同的代价。期望损失是不同结果的损失按它们的概率加权求和，或在模拟中取平均。
- 一句话定义：高估与低估的后果不同时，为两种偏差分别定义损失，再按可能性求平均。
- 小白批注：少备货会失去销售，备多了会积压。类似地，高估工期与低估工期可能造成不同的代价。
- 注意事项：损失权重应能解释其业务含义。改变权重或结果分布，最合适的决策可能随之改变。
- 来源：2023 国赛 D 题优秀论文 D039 §6.3（非对称罚分 + 1000 周期蒙特卡洛期望）

### 卡片：投影与重叠率
- 类型：机理 / 几何修正
- 概念：对于同一直线上两个等宽区间，其中心距为 d、区间宽为 W，在 0 ≤ d ≤ W 时，按单个区间宽度定义的重叠比例为 1−d/W。
- 一句话定义：测量两个区域重叠多少时，先明确在哪个方向或平面测量，距离和覆盖宽度应使用同一口径。
- 小白批注：摄影航线的覆盖和斜坡上的测量都可能用到重叠率。在斜面上，要区分沿斜面量得的长度与它的水平投影。
- 什么时候用：需要比较同一平面或方向上的覆盖范围，或检查两个距离是否采用同一投影口径时。
- 注意事项：不同宽的区间、二维面积和交并比对应不同定义。如果使用总覆盖面积作分母，上述比例公式也会改变。
- 来源：2023 国赛 B 题优秀论文 B477 §5.1（η = 1 − d′/W 投影修正重叠率定义）

### 卡片：高斯过程回归（GPR）
- 类型：预测 / 回归
- 概念：数据少且波动带相关性时的回归：假设函数来自高斯过程（任意有限点服从多元正态），用核函数刻画点间相关性，预测值还带置信区间——比"取均值"更贴近真实波动。
- 小白批注：数据少又"波动带规律"时的回归：不只给预测值，还告诉你在每个点"有多不确定"（置信区间），像医生给诊断还带把握程度。10 个数据点也能用。
- 来源：2021 国赛 C 题一等奖论文 C066 §6.2.2（高斯过程回归拟合供货偏差函数）

### 卡片：模糊综合评价
- 类型：评价 / 模糊数学
- 概念：指标边界模糊、打分带主观性时：先定评价等级（优/良/差），算每个指标对各等级的隶属度，再用权重合成综合隶属度，按最大隶属度定级。
- 小白批注："说不清好坏"的评价：比如服务质量，先定"优/良/差"，看每个指标像"优"的程度（隶属度，0~1），再按权重加权，最后看整体最像哪个等级。适合定性指标。
- 来源：国赛评价类公认方法（README 方法地图；适合定性指标 + 等级评价场景）

### 卡片：灰色关联分析
- 类型：统计 / 关联分析
- 概念：数据少、规律不明时衡量"哪个因素影响大"：把各因素序列与参考序列无量纲化，算关联系数再取均值得到灰色关联度，按关联度排序。
- 小白批注："哪个因素影响最大"：把每个因素的变化曲线和结果曲线放在一起比"形状像不像"，越像关联度越高。数据少、规律不明时特别管用。
- 来源：2022 国赛 C 题一等奖论文 C229 §8.3 展望（考虑灰色关联分析作为改进方向）

### 卡片：支持向量机（SVM）
- 类型：分类 / 机器学习
- 概念：找一个间隔最大的超平面把两类分开——间隔最大让泛化更好；线性不可分时用核函数（RBF 等）映射到高维再分。
- 小白批注：在两类数据中间"画一条最宽的马路"把它们隔开，马路越宽，新数据越不容易分错（泛化越好）。分不开时用核函数把数据"抖到高维"再画——像把揉乱的毛线团拎起来抖开。
- 来源：国赛分类方法地图；2023 国赛 B 题优秀论文 B477（尝试线性回归/SVM/随机森林多种模型对比）

### 卡片：因子分析
- 类型：统计 / 降维
- 概念：从多个相关变量中提取少数"公共因子"解释大部分方差——与 PCA 不同，因子分析假设变量背后有潜在因子结构，可旋转使因子可解释（如"经营规模"因子）。
- 小白批注：把一堆相关变量"归并成几个看不见的原因"：比如收入、存款、消费三个指标其实都受"经济实力"这个因子驱动。因子=幕后黑手，变量=它的表现。
- 来源：国赛统计方法地图（因子分析 / 方差分析 / 典型相关同属多元统计）

---

### 卡片：方差分析（ANOVA）
- 类型：统计 / 假设检验
- 概念：判断多组数据均值是否有显著差异：把总方差分解成组间方差与组内方差，F=组间/组内，F 大说明组间差异超过随机波动。
- 小白批注："三组数据有没有真差异"：比如 A/B/C 三种施肥方案产量不同，是方案真有用还是随机波动？F=组间差异÷组内差异，F 够大就说明方案有效。
- 来源：国赛统计方法地图（多元统计组：因子分析 / 方差分析 / 典型相关）

### 卡片：排队论
- 类型：机理 / 运筹
- 概念：服务台数量与服务效率的权衡：到达率 λ、服务率 μ，M/M/1 等模型给出队长、等待时间、忙期占比——用"队长/等待时间"评价系统配置。
- 小白批注：研究"排队"的数学：顾客到达率 λ、服务速度 μ，算平均队长、等多久。M/M/1 就是"最简单的排队模型"——比如收费站开几个窗口，用排队论算最优。
- 来源：国赛运筹方法地图（排队论 / 图论 Dijkstra·Floyd 同属）

### 卡片：图论最短路（Dijkstra / Floyd）
- 类型：图论 / 路径规划
- 概念：Dijkstra 求非负边权的单源最短路；Floyd 可算所有点对的距离，有限最短路要求不存在相关负权环。A* 用到终点的启发式估计引导搜索，最优性依赖启发式和实现条件。
- 一句话定义：先给每段路设定代价，再找总代价最小的路线。
- 小白批注：路段少的路径不一定总距离短。代价也可表示时间等可加量。
- 什么时候用：已经能列出节点、可走的边和路段代价，想比较如何从一点到另一点时。
- 来源：国赛图论方法地图（排队论 / 图论 Dijkstra·Floyd）

### 卡片：元胞自动机
- 类型：机理 / 仿真
- 概念：把空间离散成格子（元胞），每个元胞按局部规则随时间更新（如交通流：看前车距离决定走不走）——用简单规则涌现复杂宏观行为。
- 小白批注：把空间切成格子，每个格子按"邻居情况"和简单规则决定下一步：比如交通流仿真里"前车太近就减速"。成千上万个格子按规则自己动，宏观上就涌现出堵车等现象。
- 来源：国赛仿真方法地图（元胞自动机 / 马尔科夫 / 博弈论同属）

### 卡片：马尔科夫链
- 类型：预测 / 随机过程
- 概念：在模型假设下，给定当前状态后，下一状态的条件分布不再依赖更早历史。齐次有限链可用固定转移矩阵推算分布，并非所有链的分布都会收敛。
- 一句话定义：用当前状态与转移概率，推算下一步有哪些可能。
- 小白批注：用晴、雨两个状态建模时，先用前一天种类分别估计下一天下雨的比例。
- 什么时候用：状态可以清楚划分，并有理由认为当前状态足够描述下一步时。
- 注意事项：检查固定转移概率是否合理。周期性转移可能交替，即使存在稳态分布，也未必从某个起点收敛到它。
- 来源：国赛随机过程方法地图；2013 国赛 B 题优秀论文 §4.1.6（马尔可夫链长度控制收敛）

### 卡片：博弈论
- 类型：决策 / 博弈
- 概念：多个决策者互相影响的决策：纳什均衡（谁也不愿单方改变策略）、纯/混合策略、零和博弈——定价/竞争/资源争夺类题目用均衡分析"对方也会最优应对"。
- 小白批注："对方也会动脑子"的决策：比如两家店竞争，你降价对方也降，大家都不赚钱——纳什均衡就是"谁都不愿单方改变策略"的稳定状态。定价、竞争题用它分析。
- 来源：国赛决策方法地图（元胞自动机 / 马尔科夫 / 博弈论同属）

### 卡片：力电比拟法
- 类型：机理 / 对偶建模
- 概念：电学与力学方程形式同构（质量↔电感、阻尼↔电阻、弹簧↔电容、力↔电压），把难解的力学微分方程映射成 RLC 电路，用电路理论（相量法/阻抗匹配）求解析解。
- 小白批注：力学和电学的方程长得一模一样：质量像电感、弹簧像电容、阻尼像电阻。把难解的力学问题"翻译"成电路问题，用电学公式直接解——2022 年 A 题就这么算出精确最优解。
- 来源：2022 国赛 A 题优秀论文 A171 §5.3.1（力电比拟 RLC 等效电路，dP/dR=0 解析最优阻尼）
