### 卡片：决策树
- 类型：分类 / 回归
- 概念：按条件逐层划分数据的树形模型——每一步问一个"是否"问题，把数据分到不同分支，最终落在某个类别或数值上。
- 试一试：想一想：为什么"车辆更新方案"这类带明确条件的问题适合用决策树理解？
- 频率：★ 高频率
- 来源：2022 国赛 C 题一等奖论文（C229 §6.2.1）：用决策树按氧化铅含量阈值把玻璃分成铅钡/高钾两类，测试集正确率 100%

---

### 卡片：线性回归（多项式）
- 类型：预测 / 拟合
- 概念：用一条（或多项式）曲线描述变量之间的关系，使曲线尽可能贴近数据点——是数模里最常用的"找规律"工具。
- 试一试：调高多项式次数，曲线更贴合数据了，但你想过"过拟合"的风险吗？
- 频率：★ 高频率
- 来源：2017 国赛 C 题一等奖论文（五元线性 + 完全二次回归）、2016 国赛 C 题（二次多项式拟合放电曲线，R²=0.9999）、2018 国赛 C 题（激活率回归）、2015 国赛 A 题（二次拟合定经度）

---

### 卡片：K-means 聚类
- 类型：聚类 / 分组
- 概念：把数据点分成 K 组，使组内点尽量接近、组间尽量远离——适合"无标签"数据的分群任务。
- 试一试：把 K 从 3 调到 4，观察分组变化——K 值应该怎么选？
- 频率：★ 高频率
- 来源：2022 国赛 C 题一等奖论文（C229 §6.2.2）：先用 NbClust/肘部法确定最优 K=3，再做 K-means 划分玻璃亚类

---

### 卡片：线性规划
- 类型：优化 / 决策
- 概念：在一组线性约束下，求目标函数的最大/最小值——资源分配、更新替换、运输调度等"怎么安排最优"的问题首选。
- 试一试：拖动目标值滑块，观察等值线离开可行域的瞬间——为什么最优解总在顶点？
- 频率：★ 高频率
- 来源：2021 国赛 C 题两篇一等奖论文（C066 §6.1 / C283 §6.1）均以（整数/多目标）规划为方案骨架

---

### 卡片：整数规划
- 类型：优化 / 整数约束
- 概念：线性规划 + "决策变量必须是整数"的约束——车辆、人员、批次数这类不能取小数的数量问题，必须用整数规划。
- 试一试：对比连续最优（顶点）和整数最优（圆点）的位置——为什么它们常常不一样？
- 频率：★ 高频率
- 来源：2021 国赛 C 题一等奖论文（C066 §6.1）：用 0-1 逻辑变量表示"是否向该供货商订货"

### 卡片：随机森林
- 类型：集成学习 / 分类
- 概念：种很多棵"意见不同"的决策树，让它们各自判断后投票——单棵树容易犯错，但很多树商量着来就稳得多。
- 试一试：换几个样本观察：为什么单棵树会判错，投票却能纠正？
- 频率：★ 高频率
- 来源：分类集成高频方法（方法地图）；真实获奖论文以决策树 / PLS-DA 为分类主力，随机森林是其稳健升级版

### 卡片：主成分分析（PCA）
- 类型：降维 / 特征提取
- 概念：数据通常沿某些方向变化最大——PCA 找出这些"主方向"，把高维数据投影到低维，保留最多的差异信息。
- 试一试：拖动投影位置，想想：为什么沿蓝色主轴投影信息损失最少？
- 频率：★ 高频率
- 来源：高维多变量降维首选（方法地图）；成分数据场景可配 clr 变换（2022 年 C 题一等奖论文 §8.3 展望）

---

### 卡片：熵权法
- 类型：评价 / 客观定权
- 概念：指标的信息熵越小 → 数据区分度越大 → 该指标权重越大。"熵"衡量的是信息量，不是"混乱程度"的贬义词。客观定权方法，国赛评价题高频使用（2021 年 C 题两篇一等奖论文均使用，常与 TOPSIS/AHP 组合）。
- 试一试：把某一列指标改成全部相同，观察它的权重变成多少（应为 0）——为什么？
- 频率：★ 高频率
- 来源：2021 国赛 C 题一等奖论文 C066 §5.2、C283 §5.1.3（熵权法定 6/9 个指标权重）

---

### 卡片：TOPSIS 优劣解距离法
- 类型：评价 / 排序
- 概念：构造理想最优解与最劣解，看每个方案"离最优多近、离最劣多远"，用相对贴近度排序。评价排序高频方法，常与熵权法组合（2021 年 C 题一等奖论文主方法）。
- 试一试：把理想点往角落拖，观察排序如何变化——贴近度排序对理想点位置敏感吗？
- 频率：★ 高频率
- 来源：2021 国赛 C 题一等奖论文 C066 §5.2-5.3（熵权法确定权重 + TOPSIS 评价 402 家供货商）

---

### 卡片：层次分析法（AHP）
- 类型：评价 / 主观定权
- 概念：把复杂决策拆成"目标—准则—方案"三层，两两比较打分构造判断矩阵，算权重 + 一致性检验（CR<0.1）。评价类高频经典方法；真实获奖论文中与熵权法组合使用（熵权定客观初权 + AHP 引入专家经验修正）。
- 试一试：构造矛盾比较（如 A>B、B>C、C>A），看一致性比率如何报警——为什么 CR≥0.1 说明判断有问题？
- 频率：★ 高频率
- 来源：2021 国赛 C 题一等奖论文 C283 §5.1.3（AHP 修正熵权权重 + 一致性检验）；2017 国赛 C 题一等奖论文（AHP 量化影响因子）

---

### 卡片：多目标规划
- 类型：优化 / 多目标
- 概念：多个目标同时最优很难，常用两种办法转单目标：①加权求和（权重代表重要程度）；②序贯解法/分层序列法（按优先级依次求解，前一目标的最优值作为后一目标的约束）。优化类高频率框架：2021 年 C 题两篇一等奖论文与 2020 年 A 题用加权单目标化，2021 年 D 题用序贯解法。
- 试一试：把权重拉到极端（0.95/0.05），最优解跑到哪里？如果想"先保最重要的目标、再优化次要目标"，该用哪种转法？
- 频率：★ 高频率
- 来源：2021 国赛 C 题一等奖论文 C066 §6.1、C283 §6.1（双目标加权）；2020 国赛 A 题 A147 §5.4（min-max 无量纲化 + 线性加权）；2021 国赛 D 题 D026（序贯解法/分层序列法）

---

### 卡片：联合优化
- 类型：优化 / 多决策耦合
- 概念：多个**相互耦合的决策变量**一起优化——比如"订多少货"和"怎么运"互相影响，分开定会得到次优解，必须放在同一个模型里同时求解。与"多目标规划"不同：它强调**决策变量耦合**而非**多个目标**。中频率：耦合决策场景（2021 年 C 题把订购方案+转运方案联合建模，2021 年 D 题切割+调度联合决策）。
- 试一试：切到"分开优化"再拖 Q——为什么局部最优 T 和联合最优 T 不一样？现实里哪些决策是耦合的、不能分开定？
- 频率：● 中频率
- 来源：2021 国赛 C 题一等奖论文 C066（订购方案+转运方案联合优化）；2021 国赛 D 题（连铸切割+调度联合决策）

### 卡片：遗传算法（GA）
- 类型：优化 / 智能算法
- 概念：模拟"物竞天择"：一组候选解（种群）通过选择、交叉、变异一代代进化，逼近最优解——适合非线性/组合优化。组合/非线性优化高频率求解器（2021 年 C 题一等奖论文的主求解算法，四问全部使用）。
- 试一试：连续进化几代观察种群向峰顶聚拢；多峰函数下它能跳出局部最优吗？
- 频率：★ 高频率
- 来源：2021 国赛 C 题一等奖论文 C066 §6.1.4/§6.4（四问全部用遗传算法求解）；2015 国赛 A 题（遗传算法反演参数）

### 卡片：相关性分析
- 类型：统计 / 相关
- 概念：两个变量一起变吗？Pearson 看线性相关（连续数据），Spearman 看秩相关（定性/非正态也行）；热力图一眼看全矩阵。数据分析高频率第一步：找哪些变量相关、相关多强。
- 试一试：切到"非线性关系"：为什么 Pearson 接近 0 而 Spearman 仍然很大？
- 频率：★ 高频率
- 来源：2022 国赛 C 题一等奖论文 C229 §6.1.1（Spearman 检验风化与类型关系）+ §6.4.1（Pearson 热力图）；2017 国赛 C 题（相关性初判）

---

### 卡片：数据预处理
- 类型：通用 / 第一课
- 概念：建模前必须做的三件事：填缺失（众数/热卡/均值）、剔异常（阈值/业务规则）、标准化（极大型/极小型归一化）——不做预处理，模型结果不可信。高频率：15 篇获奖论文全部以数据预处理开篇。
- 试一试：为什么"供货量方差"这类极小型指标要反向归一化？金额列 999 为什么该剔除？
- 频率：★ 高频率
- 来源：C229 §5.1-5.2（众数/热卡/乘法替换）、C066 §四（低质量剔除）、C283 §5.1.1（阈值筛选）、2018C §5.1（无效剔除）、2016C §5.1（删前 10% + 单位换算）

### 卡片：模拟退火（SA）
- 类型：优化 / 启发式
- 概念：像金属退火一样"先高温乱跳、再慢慢降温收敛"，用 Metropolis 准则接受劣解以跳出局部最优。中频率启发式优化：2013 年 B 题（碎纸复原 TSP）与 2015 年 A 题（太阳影子反演）都使用，适合组合优化/高维反问题。
- 试一试：把温度拖到很低再点"退火一步"——为什么几乎只接受更优解？温度高时为何敢接受差解？
- 频率：● 中频率
- 来源：2013 国赛 B 题（碎纸复原 §4.1.6，Metropolis + 冷却进度表）；2015 国赛 A 题（§4.2，初温 8000、退温 0.9）

---

### 卡片：假设检验（卡方检验）
- 类型：统计 / 显著性
- 概念：差异是"真的"还是"随机波动"？给结论一个概率背书：p<0.05 才说"显著"。卡方检验查分类变量关联、Wilcoxon 查配对差异、K-S 查分布拟合。中频率标准工具：2022 年 C 题用卡方+Wilcoxon，2021 年 C 题用 K-S 选分布，2023 年 C 题用 Shapiro-Wilk 查正态性。
- 试一试：把"铅钡有风化"一格的数字改大，观察 p 值如何骤降——为什么格子差异越大越显著？
- 频率：● 中频率
- 来源：2022 国赛 C 题一等奖论文 C229 §6.1.1（卡方检验风化与类型/纹饰/颜色）+ §6.4.2（配对 Wilcoxon）；2021 国赛 C 题 C066 §6.3（K-S 拟合优度）；2023 国赛 C 题（Shapiro-Wilk 正态性）

### 卡片：多指标评价体系
- 类型：评价 / 指标构建
- 概念：评价的第一步不是算分，而是"选哪些指标"——指标要系统、科学、可比、可测、独立，且区分效益型（越大越好）与成本型（越小越好）。评价类高频率第一步：2021 年 C 题两篇一等奖论文分别构建 6/9 个指标，2018 年 C 题构建 FMS 指标。
- 试一试：为什么"供货量方差"是成本型指标（要反向标准化）？如果两个指标高度相关，保留它们合理吗？
- 频率：★ 高频率
- 来源：2021 国赛 C 题一等奖论文 C066 §5.1（6 指标：供货次数/平均供货量/单次最大供货量/稳定性/连续性/合理比例）；C283 §5.1.2（9 指标）

---

### 卡片：动态规划（逐阶段决策）
- 类型：优化 / 递推
- 概念：把多阶段决策拆成"每阶段只依赖上一阶段状态"的递推——本周库存=上周库存+收货−消耗。中频率：带时间先后依赖的多阶段决策（2021 年 C 题逐周订购、2014 年 C 题逐次售猪）用逐周/逐阶段递推。
- 试一试：连续两周把订货量调到 10（低于消耗 24），观察库存跌破警戒线后系统如何被迫补货——为什么"上周状态"决定了"本周选择"？
- 频率：● 中频率
- 来源：2021 国赛 C 题一等奖论文 C066 §6.4（逐周求解订购方案，本周依赖前周库存）；2014 国赛 C 题一等奖论文（逐次决定卖肉猪/猪苗）

### 卡片：存贮模型（EOQ）
- 类型：优化 / 库存
- 概念：库存管理的核心问题——订多少、何时订。用"警戒点"（最低安全库存）触发补货，用经济订货量平衡订货成本与持有成本。中频率：带库存约束的供应链/生产问题标配（2021 年 C 题两篇一等奖论文都建模"至少两周库存"约束）。
- 试一试：把订货成本 K 调大，Q* 怎么变？把持有成本 h 调大呢？——为什么"一次多订 vs 频繁小订"要权衡？
- 频率：● 中频率
- 来源：2021 国赛 C 题一等奖论文 C283 §6.1.1（经济进货存贮模型，库存警戒点=两周产能 5.64 万）；C066 §6.2（库存维持约束）

### 卡片：贝叶斯模型 + MCMC
- 类型：预测 / 概率
- 概念：先验 + 数据 → 后验：把"经验"和"证据"结合，用 MCMC 采样近似后验分布。中频率（近年获奖论文新趋势）：2023 年 C 题优秀论文用贝叶斯模型（WinBUGS+MCMC）做销量/补货量建模。
- 试一试：把先验强度调到 30，后验还信数据吗？把先验均值拖到 1.1（远离数据），观察后验如何被"拉回"——为什么先验和证据要折中？
- 频率：● 中频率
- 来源：2023 国赛 C 题优秀论文 C126（Bayesian 销量/补货量模型，WinBUGS MCMC，30000 迭代 + 收敛四重诊断）

---

### 卡片：微分方程建模
- 类型：机理 / 方程
- 概念：用方程描述物理量的变化规律：热传导 ∂u/∂t=a∂²u/∂x² + 边界换热（牛顿冷却），或 F=ma 列运动方程。机理题先推方程再求数值解（Runge-Kutta/差分）。中频率机理题标配：2020 年 A 题用热传导方程建模炉温（R²=0.9813），2022 年 A 题用牛顿第二定律+Runge-Kutta 求解波浪能装置。
- 试一试：把冷却系数 k 调大，曲线变陡还是变缓？k 在物理上代表什么？（散热能力）——为什么机理题要先写方程再算数？
- 频率：● 中频率
- 来源：2020 国赛 A 题优秀论文 A147 §5.1（一维热传导方程+牛顿冷却定律，有限差分求解，R²=0.9813）；2022 国赛 A 题优秀论文 A171 §5.1-5.2（牛顿第二定律+拉普拉斯变换/Runge-Kutta）

---

### 卡片：蒙特卡洛方法
- 类型：仿真 / 随机
- 概念：用大量随机采样近似复杂积分/期望——高维积分、随机模拟、风险估计都靠它。中频率：高维积分（2021 年 A 题接收比计算）与随机模拟（2021 年 C 题偏差率损耗率正态随机化）都使用。
- 试一试：把撒点数从 50 拖到 4000，π 的估计如何收敛？——为什么"随机"反而能算"精确"的东西？
- 频率：● 中频率
- 来源：2021 国赛 A 题优秀论文 A217 §7.2（蒙特卡洛积分：圆形口径分解为三角形投影域+边界修正，接收比 0.811%→1.103%）；2021 国赛 C 题 C283 §6.1（偏差率/损耗率正态随机模拟）

### 卡片：灰色预测 GM(1,1)
- 类型：预测 / 小样本
- 概念：数据少（4-10 个点）也能预测——对原始序列做累加生成（AGO），发现指数规律，用一阶微分方程拟合后累减还原。小样本预测高频率方法（数据点少时首选，国赛预测类常见）。
- 试一试：把点数从 10 减到 4，预测还稳吗？把数据改成先降后升（无趋势），GM(1,1) 还适用吗——它适合什么样的序列？
- 频率：★ 高频率
- 来源：国赛预测类公认高频（README 方法地图）；2022 国赛 C 题一等奖论文 C229 §8.3 展望提及灰色关联分析作为改进方向

### 卡片：粒子群算法（PSO）
- 类型：优化 / 群体智能

- 概念：找一个间隔最大的超平面把两类分开——间隔最大让泛化更好；线性不可分时用核函数（RBF 等）映射到高维再分。中频率：小样本分类的经典备选（2023 年 B 题优秀论文尝试 SVM 与线性回归/随机森林对比）。
- 频率：● 中频率
- 来源：国赛分类方法地图；2023 国赛 B 题优秀论文 B477（尝试线性回归/SVM/随机森林多种模型对比）

### 卡片：因子分析
- 类型：统计 / 降维
- 概念：从多个相关变量中提取少数"公共因子"解释大部分方差——与 PCA 不同，因子分析假设变量背后有潜在因子结构，可旋转使因子可解释（如"经营规模"因子）。中频率：变量分组解释/问卷类数据（与 PCA 互补，侧重解释性）。
- 频率：● 中频率
- 来源：国赛统计方法地图（因子分析 / 方差分析 / 典型相关同属多元统计）

---

### 卡片：方差分析（ANOVA）
- 类型：统计 / 假设检验
- 概念：判断多组数据均值是否有显著差异：把总方差分解成组间方差与组内方差，F=组间/组内，F 大说明组间差异超过随机波动。中频率：多组比较的标准工具（单因素/双因素）。
- 频率：● 中频率
- 来源：国赛统计方法地图（多元统计组：因子分析 / 方差分析 / 典型相关）

### 卡片：排队论
- 类型：机理 / 运筹
- 概念：服务台数量与服务效率的权衡：到达率 λ、服务率 μ，M/M/1 等模型给出队长、等待时间、忙期占比——用"队长/等待时间"评价系统配置。低频率：服务系统/窗口设置类题目（如银行窗口、收费站）。
- 频率：○ 低频率
- 来源：国赛运筹方法地图（排队论 / 图论 Dijkstra·Floyd 同属）

### 卡片：图论最短路（Dijkstra / Floyd）
- 类型：图论 / 路径规划
- 概念：在带权图上找两点间最短路径：Dijkstra 单源（非负权，贪心+优先队列），Floyd 全源（动态规划，O(n³) 可处理负权）。低频率：物流/网络/规划类题目的基础工具。
- 频率：○ 低频率
- 来源：国赛图论方法地图（排队论 / 图论 Dijkstra·Floyd）

### 卡片：元胞自动机
- 类型：机理 / 仿真
- 概念：把空间离散成格子（元胞），每个元胞按局部规则随时间更新（如交通流：看前车距离决定走不走）——用简单规则涌现复杂宏观行为。低频率：交通流/疏散/扩散类仿真（规则设定是关键创新点）。
- 频率：○ 低频率
- 来源：国赛仿真方法地图（元胞自动机 / 马尔科夫 / 博弈论同属）

### 卡片：马尔科夫链
- 类型：预测 / 随机过程
- 概念：系统下一状态只依赖当前状态（无后效性）——用状态转移矩阵反复乘，收敛到稳态分布；适合状态转移/趋势预测。低频率：状态转移类预测（2013 年 B 题模拟退火中的"马尔可夫链长度"是同一概念）。
- 频率：○ 低频率
- 来源：国赛随机过程方法地图；2013 国赛 B 题优秀论文 §4.1.6（马尔可夫链长度控制收敛）

### 卡片：博弈论
- 类型：决策 / 博弈
- 概念：多个决策者互相影响的决策：纳什均衡（谁也不愿单方改变策略）、纯/混合策略、零和博弈——定价/竞争/资源争夺类题目用均衡分析"对方也会最优应对"。低频率：竞争/合作决策场景。
- 频率：○ 低频率
- 来源：国赛决策方法地图（元胞自动机 / 马尔科夫 / 博弈论同属）

### 卡片：力电比拟法
- 类型：机理 / 对偶建模
- 概念：电学与力学方程形式同构（质量↔电感、阻尼↔电阻、弹簧↔电容、力↔电压），把难解的力学微分方程映射成 RLC 电路，用电路理论（相量法/阻抗匹配）求解析解。低频率但专有场景高效：2022 年 A 题用 RLC 等效求最大功率精确解。
- 频率：○ 低频率
- 来源：2022 国赛 A 题优秀论文 A171 §5.3.1（力电比拟 RLC 等效电路，dP/dR=0 解析最优阻尼）
