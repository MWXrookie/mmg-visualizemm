## 评价类

### 方法：熵权法
- 类型：评价 / 客观定权
- 频率：高（2021 国赛 C 题两篇一等奖论文均使用）
- 适用场景：需要给多个指标定权重且想避免主观偏差；指标间区分度不同时
- 使用步骤：①指标标准化（效益型 x/max，成本型 min/x）②计算各指标熵值 e_j=-1/ln(n)·Σp·ln(p) ③差异系数 d=1-e ④权重 w=d/Σd
- 失效边界：某指标所有方案取值几乎相同（熵≈1→权重≈0，指标形同虚设，如"合理供货比例"仅 0.9% 权重）；指标间强相关时权重会失真
- 评委视角：客观可复现是加分点；但"权重由数据分布决定、换数据结论就变"易被质疑，建议搭配敏感性分析
- 来源论文：2021-C题-优秀论文-C066 §5.2；2021-C题-优秀论文-C283 §5.1.3

### 方法：TOPSIS 优劣解距离法
- 类型：评价 / 排序
- 频率：高（2021 国赛 C 题一等奖论文主方法）
- 适用场景：多指标评价后的方案排序；指标已标准化、需比较"离理想解/最劣解"距离
- 使用步骤：①指标同向化+归一化 ②确定正/负理想解 ③算各方案到两解距离 ④贴近度 C=d⁻/(d⁺+d⁻) ⑤按 C 排序
- 失效边界：指标过多且高度相关时距离度量失真；对归一化方式敏感
- 评委视角：不假设数据分布、稳健是优点；需配合熵权/AHP 定权才有完整评价链
- 来源论文：2021-C题-优秀论文-C066 §5.2-5.3

### 方法：层次分析法 AHP
- 类型：评价 / 主观定权
- 频率：高（评价类经典；2021 C 题 C283 用于修正熵权权重）
- 适用场景：准则较少（≤9）、需要引入专家经验判断；评价体系分层（目标-准则-方案）
- 使用步骤：①构造判断矩阵（1-9 标度两两比较）②算权重（列归一化平均）③一致性检验 CR=CI/RI<0.1
- 失效边界：准则多时判断矩阵一致性难达标；主观性受质疑；与熵权法组合可互补（熵权定客观初权+AHP 修正）
- 评委视角：组合赋权（熵权+AHP）是近年获奖论文常见加分结构；CR 通过是硬性要求
- 来源论文：2021-C题-优秀论文-C283 §5.1.3；2017-C题-优秀论文-一等奖1（量化影响因子）

### 方法：多指标评价体系构建
- 类型：评价 / 指标设计
- 频率：高（2021 C 题两篇一等奖论文分别构建 6/9 指标）
- 适用场景：评价类题目第一步——"选哪些指标"
- 使用步骤：①遵循系统性/科学性/可比性/可测性/独立性原则 ②区分效益型（越大越好）与成本型（越小越好）③标准化统一量纲
- 失效边界：指标冗余（强相关）会稀释熵权区分度；指标过少覆盖不全
- 评委视角：指标体系设计本身是评分点——是否系统、是否区分方向、是否可测
- 来源论文：2021-C题-优秀论文-C066 §5.1；2021-C题-优秀论文-C283 §5.1.2

## 预测类

### 方法：线性/多元回归（含二次）
- 类型：预测 / 拟合
- 频率：高（2017 C 五元线性+完全二次、2016 C 多项式、2018 C 回归）
- 适用场景：找变量间数量关系；预测连续目标；数据量适中且关系近似线性/多项式
- 使用步骤：①散点图判断形态 ②线性回归打底（最小二乘）③残差分析+异常点剔除 ④不足则升二次（加交叉项/平方项）⑤R²/F/p 检验
- 失效边界：强非线性关系线性拟合失真；过拟合（次数过高）；残差非随机说明漏变量
- 评委视角：残差图与显著性检验是评分点；线性→非线性递进建模是加分叙事
- 来源论文：2017-C题-优秀论文-一等奖1（问题一/二）；2016-C题-优秀论文-电池放电时间预测 §5.1；2018-C题-优秀论文-RFMS会员画像 §5.5

### 方法：灰色预测 GM(1,1)
- 类型：预测 / 小样本
- 频率：高（小样本场景首选，国赛预测类常见）
- 适用场景：只有 4-10 个历史点；序列呈近似指数增长/衰减
- 使用步骤：①累加生成(AGO) ②对累加序列拟合一阶微分方程（最小二乘求 a,b）③累减还原得预测
- 失效边界：数据波动大/非单调时精度差；不适合长周期预测（预测步数>5 误差累积）
- 评委视角：小样本场景选它合理；需报告后验差比/级比检验证明适用性
- 来源论文：国赛预测类公认高频（方法地图）；2022-C题-优秀论文-C229 §8.3 展望提及灰色关联

### 方法：贝叶斯模型 + MCMC
- 类型：预测 / 概率
- 频率：中（2023 国赛 C 题优秀论文主方法，近年趋势）
- 适用场景：需结合先验经验与数据；数据量不大但需不确定性量化；销量/补货类
- 使用步骤：①设先验分布 ②构造似然 ③MCMC 采样后验（WinBUGS/Stan）④收敛诊断（轨迹图/自相关/MC误差）
- 失效边界：先验设置不当会主导结果；MCMC 未收敛结果不可信
- 评委视角：收敛性四重诊断是加分点；先验选择要说明依据
- 来源论文：2023-C题-优秀论文-C126（Bayesian 销量/补货量模型，WinBUGS MCMC）

## 优化类

### 方法：多目标规划（加权单目标化）
- 类型：优化 / 多目标
- 频率：高（2021 C 题两篇一等奖论文、2020 A 题均使用）
- 适用场景：多个目标冲突（成本最小+稳定性最高、损耗最少等）；需要权衡
- 使用步骤：①列出各目标函数 ②min-max 无量纲化 ③线性加权 w₁f₁+w₂f₂ 转单目标 ④求解（遗传算法/规划器）
- 失效边界：权重选择影响结果；量纲不一致需先无量纲化
- 评委视角：Pareto 前沿可视化+权重敏感性是加分点；无量纲化处理要规范
- 来源论文：2021-C题-优秀论文-C066 §6.1；2021-C题-优秀论文-C283 §6.1；2020-A题-优秀论文-A147 §5.4

### 方法：遗传算法 GA
- 类型：优化 / 智能算法
- 频率：高（2021 C 题一等奖论文四问全用、2015 A 题反演参数）
- 适用场景：组合优化/非线性优化/大规模搜索；目标函数不连续不可导；多变量
- 使用步骤：①编码种群 ②适应度评估 ③选择（轮盘赌/锦标赛）④交叉 ⑤变异 ⑥迭代至收敛
- 失效边界：参数（种群/交叉率/变异率）敏感；早熟收敛（局部最优）；无收敛性证明易被质疑
- 评委视角：需展示收敛曲线证明找到最优；多随机种子稳健性分析是加分点
- 来源论文：2021-C题-优秀论文-C066 §6.1.4/§6.4；2015-A题-优秀论文-太阳影子定位 §2.2.2

### 方法：模拟退火 SA
- 类型：优化 / 启发式
- 频率：中（2013 B 题 TSP、2015 A 题多变量反演）
- 适用场景：组合优化（TSP/排序）；高维多变量反问题；遗传算法失效时
- 使用步骤：①初始解+高温 ②邻域扰动 ③Metropolis 准则接受/拒绝 ④降温 ⑤重复至低温
- 失效边界：初温过低困在局部最优；退温太快收敛差；对参数敏感
- 评委视角：温度调度表与接受率曲线是加分点
- 来源论文：2013-B题-优秀论文-碎纸片拼接复原 §4.1.6；2015-A题-优秀论文-太阳影子定位 §4.2

### 方法：动态规划（逐阶段决策）
- 类型：优化 / 递推
- 频率：中（2021 C 题逐周订购、2014 C 题逐次售猪）
- 适用场景：多阶段决策、每阶段依赖上一阶段状态（库存/生产计划）
- 使用步骤：①定义状态（本周库存=上周+收货-消耗）②递推关系 ③逐阶段求解
- 失效边界：状态爆炸（维度高时）；阶段间耦合复杂时递推难
- 评委视角：状态定义清晰+逐周可视化是加分点
- 来源论文：2021-C题-优秀论文-C066 §6.4；2014-C题-优秀论文-生猪养殖场经营管理 §6.3

### 方法：存贮模型 EOQ
- 类型：优化 / 库存
- 频率：中（2021 C 题两篇一等奖论文均有库存约束）
- 适用场景：库存管理：订多少、何时订；平衡订货成本与持有成本
- 使用步骤：①确认年需求 D、订货成本 K、持有成本 h ②Q*=√(2DK/h) ③警戒点=安全库存
- 失效边界：需求恒定假设；缺货成本未计入时失真
- 评委视角：库存警戒点显式建模+两周库存约束是贴合题意的加分点
- 来源论文：2021-C题-优秀论文-C283 §6.1.1；2021-C题-优秀论文-C066 §6.2

### 方法：贪心算法
- 类型：优化 / 启发式
- 频率：中（2021 C 题双层贪心、2022 B 题贪心三步调整）
- 适用场景：候选可严格排序、局部最优能推出全局最优（供应商按可靠性排序）
- 使用步骤：①定义排序准则 ②每次选当前最优 ③直到满足终止条件
- 失效边界：局部最优≠全局最优的问题（如 0-1 背包）不能直接用
- 评委视角：需论证贪心合理性（为什么局部最优=全局最优）
- 来源论文：2021-C题-优秀论文-C283 §6.2；2022-B题-优秀论文-B086 §5.4

## 分类/聚类类

### 方法：决策树
- 类型：分类 / 规则
- 频率：高（2022 国赛 C 题一等奖论文主方法）
- 适用场景：分类任务且需可解释规则；特征可二分（如含量阈值）
- 使用步骤：①特征选择（信息增益/基尼）②递归划分 ③剪枝防过拟合 ④测试集验证
- 失效边界：特征强相关时不稳定；小样本易过拟合
- 评委视角：单一特征阈值分类（如氧化铅>X 判铅钡）简单可解释是加分点
- 来源论文：2022-C题-优秀论文-C229 §6.2.1/§6.3

### 方法：K-means 聚类
- 类型：聚类 / 无监督
- 频率：高（2022 国赛 C 题一等奖论文）
- 适用场景：无标签数据分群；亚类划分
- 使用步骤：①确定 K（肘部法/NbClust）②随机初始化质心 ③迭代：分配+更新质心
- 失效边界：K 选择主观；非球形簇/离群点敏感
- 评委视角：K 值确定方法（NbClust/肘部）要交代；聚类结果可视化
- 来源论文：2022-C题-优秀论文-C229 §6.2.2

### 方法：偏最小二乘判别分析 PLS-DA
- 类型：分类 / 降维判别
- 频率：中（2022 国赛 C 题一等奖论文）
- 适用场景：样本少、变量多且强相关（成分/光谱数据）的分类
- 使用步骤：①clr/标准化 ②提取主成分判别 ③VIP 值筛选重要变量（>1）
- 失效边界：变量数远大于样本数时需先降维；两类样本量不均衡
- 评委视角：VIP 特征筛选+两方法结果一致（如与决策树互证）是加分点
- 来源论文：2022-C题-优秀论文-C229 §6.2.1/§6.2.2

## 统计/相关性类

### 方法：相关性分析（Pearson/Spearman）+ 热力图
- 类型：统计 / 相关
- 频率：高（2022 C 题两处使用、2017 C 题初判）
- 适用场景：探索变量间关系；定性变量用 Spearman、连续用 Pearson；全矩阵用热力图
- 使用步骤：①选对系数（线性/单调）②算 r/ρ ③热力图可视化 ④显著性检验
- 失效边界：非线性关系 Pearson 失效；异常值影响大
- 评委视角：先看散点形状再选系数是专业体现；热力图是常用可视化
- 来源论文：2022-C题-优秀论文-C229 §6.1.1/§6.4.1；2017-C题-优秀论文-一等奖1

### 方法：假设检验（卡方/Wilcoxon/K-S）
- 类型：统计 / 显著性
- 频率：中（2022 C 题卡方+Wilcoxon、2021 C 题 K-S、2023 C 题 Shapiro-Wilk）
- 适用场景：判断差异/关联是否显著；分类关联用卡方、配对差异用 Wilcoxon、分布拟合用 K-S、正态性用 Shapiro-Wilk
- 使用步骤：①设 H0/H1 ②算统计量 ③p<0.05 判显著
- 失效边界：样本过小（期望频数<5）卡方失真；多重比较需校正
- 评委视角：p 值与结论对应清晰；检验选择正确是专业加分点
- 来源论文：2022-C题-优秀论文-C229 §6.1.1/§6.4.2；2021-C题-优秀论文-C066 §6.3；2023-C题-优秀论文-C126

### 方法：数据预处理（缺失/异常/标准化）
- 类型：统计 / 通用
- 频率：高（15 篇获奖论文全部以预处理开篇）
- 适用场景：任何建模第一步
- 使用步骤：①填缺失（众数/热卡/均值）②剔异常（阈值/业务规则/3σ）③标准化（效益型 x/max、成本型 min/x）
- 失效边界：填充方式影响分布；剔除阈值主观需敏感性分析
- 评委视角：预处理流程交代清楚是可信度地基；异常剔除阈值要说明
- 来源论文：2022-C题-优秀论文-C229 §5.1-5.2；2021-C题-优秀论文-C066 §四；2016-C题-优秀论文-电池放电时间预测 §5.1

## 机理/几何类

### 方法：微分方程建模 + 数值解（RK4/差分）
- 类型：机理 / 方程
- 频率：中（2020 A 题热传导、2022 A 题动力学）
- 适用场景：物理机理清楚（热传导/运动/波动）；需由方程推演化
- 使用步骤：①能量守恒/F=ma 列方程 ②定初边值 ③解析解（拉普拉斯）或数值解（RK4/有限差分）
- 失效边界：机理假设不成立则模型失真；数值方法需稳定性条件
- 评委视角：机理推导完整+数值验证（解析vs数值对比）是高分结构
- 来源论文：2020-A题-优秀论文-A147 §5.1；2022-A题-优秀论文-A171 §5.1-5.2

### 方法：几何建模 + 坐标变换（旋转矩阵/相似变换）
- 类型：机理 / 几何
- 频率：高（2021 A/2022 B/2023 A/2015 A 四篇使用）
- 适用场景：几何关系题（抛物线/定位/反射面）；需要坐标变换简化
- 使用步骤：①建坐标系 ②找几何关系（相似/正弦定理/旋转矩阵）③变换到可算坐标系 ④求解
- 失效边界：坐标系选择不当导致计算复杂；变换矩阵正交性
- 评委视角："一次建模多问复用"的坐标变换是高分亮点
- 来源论文：2021-A题-优秀论文-A217 §6.1.1；2022-B题-优秀论文-B086 §5.1；2023-A题-优秀论文-A127 §5.1；2015-A题-优秀论文-太阳影子定位 §4.1.2

### 方法：蒙特卡洛方法
- 类型：仿真 / 随机
- 频率：中（2021 A 题积分、2021 C 题随机模拟）
- 适用场景：高维积分无解析解；随机性系统模拟；风险估计
- 使用步骤：①构造随机采样 ②多次采样 ③统计近似（均值/频率）
- 失效边界：收敛慢（精度∝1/√N）；样本量小时方差大
- 评委视角：采样策略（区域分解/边界修正）与稳定性检验（重复多次看波动）是加分点
- 来源论文：2021-A题-优秀论文-A217 §7.2；2021-C题-优秀论文-C283 §6.1

### 方法：光线追迹（射线-面求交）
- 类型：机理 / 光学模拟
- 频率：中（2023 A 题定日镜、2021 A 题 FAST）
- 适用场景：光学/反射/接收类题目；需模拟光线路径
- 使用步骤：①离散化光源/镜面 ②反射定律求方向 ③射线-面求交 ④统计接收
- 失效边界：离散化精度影响结果；计算量大
- 评委视角：离散化策略（网格密度/锥形光线）与效率权衡是评分点
- 来源论文：2023-A题-优秀论文-A127 §5.3；2021-A题-优秀论文-A217 §7.1

## 图论/算法类

### 方法：图论 TSP（最短哈密顿回路）
- 类型：图论 / 组合优化
- 频率：中（2013 国赛 B 题碎纸复原）
- 适用场景：排序/拼接类问题化归 TSP（找最优顺序）
- 使用步骤：①对象为顶点、代价为边权 ②求最短哈密顿回路 ③启发式求解（模拟退火/GA）
- 失效边界：顶点多时精确解不可行；边权定义不当
- 评委视角："化归为 TSP"的建模洞察是加分点；求解方法交代清楚
- 来源论文：2013-B题-优秀论文-碎纸片拼接复原 §4.1.5

### 方法：图像处理（二值化/特征提取）
- 类型：算法 / 图像
- 频率：中（2013 B 题碎纸、2015 A 题视频）
- 适用场景：图像/视频类题目的数据提取入口
- 使用步骤：①灰度化/二值化 ②特征提取（宽度/边缘/坐标）③结构化供建模
- 失效边界：阈值选择影响分割质量；噪声干扰
- 评委视角：预处理流程与特殊情形修正（如镂空字符）是加分点
- 来源论文：2013-B题-优秀论文-碎纸片拼接复原 §4.1.1-4.1.2；2015-A题-优秀论文-太阳影子定位 §4.1.1

### 方法：爬山算法 + A* 搜索
- 类型：优化 / 启发式搜索
- 频率：中（2020 国赛 A 题，7×10⁶ 状态空间）
- 适用场景：离散搜索空间过大无法穷举；需要全局寻优但爬山易困局部最优
- 使用步骤：①爬山（多次随机起点，贪心跳邻域）得局部最优 ②注入 A* 优先队列（frontier+explored）继续全局搜索 ③有限时间提前返回
- 失效边界：爬山对初始点敏感；A* 启发式设计不当会退化；大规模状态空间计算量大
- 评委视角：混合策略（爬山局部 + A* 全局）是加分点；搜索空间规模估计（21⁴×36≈7×10⁶）体现工程意识
- 来源论文：2020-A题-优秀论文-A147 §5.3.3

### 方法：有限差分法
- 类型：机理 / 数值解
- 频率：中（2020 国赛 A 题显式差分求解炉温）
- 适用场景：偏微分方程无解析解（热传导、扩散等）需数值求解
- 使用步骤：①空间离散为网格 ②差分近似导数（显式/隐式格式）③逐时间步迭代 ④检查稳定性条件
- 失效边界：显式格式有稳定性条件（α·Δt/Δx² ≤ 0.5），步长不当数值爆炸
- 评委视角：与解析解对比验证精度（2020A R²=0.9813）是高分结构
- 来源论文：2020-A题-优秀论文-A147 §5.1.7

### 方法：Dirichlet 回归（成分数据）
- 类型：预测 / 专有场景
- 频率：低（2022 国赛 C 题，成分数据专有）
- 适用场景：因变量是组成成分（各项和=100%，如化学成分占比）时替代普通回归
- 使用步骤：①数据转为成分数据（闭合）②构造 Dirichlet 分布似然 ③回归拟合 ④预测保证在单纯形内
- 失效边界：仅适用于成分数据；普通回归预测成分会产生负值/和≠1
- 评委视角：成分数据用专用模型体现专业性（2022C Q1 预测风化前成分）
- 来源论文：2022-C题-优秀论文-C229 §6.1.3

### 方法：时间序列 VAR
- 类型：预测 / 时序
- 频率：中（2023 国赛 C 题预测蔬菜销量）
- 适用场景：多变量互相影响的时间序列预测；需描述变量间滞后依赖
- 使用步骤：①平稳性检验 ②定阶（AIC/SC/显著性）③估计 VAR(p) ④外推预测 + 脉冲响应
- 失效边界：阶数选择不当；非平稳序列需先差分；样本量要求较高
- 评委视角：与单变量 ARIMA 对比说明为何用 VAR 是加分点（多变量互影响）
- 来源论文：2023-C题-优秀论文-C126（VAR(2)，EViews 实现）

### 方法：平衡方程组（稳态建模）
- 类型：数据挖掘 / 守恒
- 频率：低（2014 国赛 C 题猪群结构）
- 适用场景：稳态/饱和状态下各数量满足的总量守恒关系（猪群、人口、库存）
- 使用步骤：①识别各群体与转换关系 ②列平衡方程（存量=增量-消耗-淘汰）③求解稳态量 ④周期/参数修正
- 失效边界：周期设置错误（年 vs 半年）导致量级错误；假设线性
- 评委视角：模型递进修正（Ⅳ→Ⅴ 修正周期）是规范加分结构
- 来源论文：2014-C题-优秀论文-生猪养殖场经营管理 §6.21-6.22
