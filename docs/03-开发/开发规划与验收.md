# MMG_VisualizeMM 开发规划与验收（三台架构 v2）

> **版本**：v2.0 ｜ 日期：2026-08-29 ｜ 状态：执行稿
> **定位**：全新「三台流水线」架构的开发执行规划。旧 v1（M0-M6，旧 UI 架构）已废弃覆盖，git 历史可恢复。
> **工作方式**：任务化推进 —— **每完成一个任务 → 提交 + 自测 → 作者审核 → 通过后进入下一任务**（见 §3）。
> **前置**：UI 高保真原型已验收（`docs/prototypes/byok/` 4 页），实现以其为视觉基准、以 `design-systems/mmg_visualizemm/DESIGN.md` 为最终裁判。

---

## 0. 架构与范围

```
统一壳：左功能栏(20%, 可折叠成图标栏) + 右内容区(80%)
功能(MVP 3 项)：读题工作台 → 建模思路梳理台 → 编程工作台
底部：模型设置 / 主题切换

三台数据流：读题(要素) → 梳理(拆解块) → 编程(代码+可视化)
共享：资料抽屉(题干+附件) / 工作区存储(后端 SQLite)
```

**产品定位**：帮助新手入门理解（不代做）；AI 走 BYOK（Key 只存本地）。

**明确不做（本期）**：对话式主流程（待测试验证）、账号体系、云端托管、移动端深度适配。

## 3. 审核机制（每任务必走）

```
┌──────────────┐  ┌──────────────┐  ┌──────────────────┐  ┌──────────────┐
│ ① 实现任务     │→│ ② 提交 + 自测  │→│ ③ 作者审核         │→│ ④ 通过/驳回   │
│ (写代码)       │  │ (build/接口/  │  │ (浏览器操作/接口/   │  │ ✅→下一任务   │
│               │  │  截图证据)    │  │  截图核对原型)     │  │ ❌→返回①修改  │
└──────────────┘  └──────────────┘  └──────────────────┘  └──────────────┘
```

- 每个任务完成即**提交一次**（小步提交，可回滚）
- 审核由**作者**执行：打开浏览器按验收标准操作（或看接口/截图证据）
- 审核记录写入本文件任务状态列（⬜→🔄→✅）

## 4. 完成标准（产品可用定义）

**核心场景走通**：
1. 新建工作区 → 上传 2022 C 题 + Excel 附件（空状态引导）
2. **读题台**：✦AI 整体解读（流式）→ 划词 → 角色判定卡（引用定位）
3. **梳理台**：问题 1/2 选择 → 建拆解块 → AI 对话指挥编辑（预览确认）→ 知识卡片辅助
4. **编程台**：✨AI 生成（选拆解块+自然语言）→ 代码草稿 → 运行 → 图表 → 调参实时刷新
5. 任一时刻刷新/重开 → 三台数据完整恢复（工作区存储）
6. 导出思路 Markdown；设置页 Key 可配可测可存

**以上 6 步全部走通 = 产品可用**，进入 H 发布组。
