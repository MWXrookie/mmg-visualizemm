# 窄屏导航与工作区入口

日期：2026-09-30。范围：App 全局壳，不涉及数据存储、模型请求或 Python 执行。

## 交互决定

1. ≤768px 使用两行紧凑导航：第一行「工作区与设置」和当前题名；第二行保留「1 读题 / 2 建模 / 3 编程 / 范例」。数字表示流程顺序，不代表完成状态。当前页面使用 `aria-current=page`。
2. 工作区与设置按需在导航下方展开，最大占用 65dvh，可纵向滚动。使用非模态展开区域，主内容仍可访问；不引入焦点锁定或遮罩。
3. Enter/Space 操作原生按钮，Tab 顺序与视觉一致；导航区域内 Esc 收起并回焦点到展开按钮。切换工作区、新建工作区和菜单内跳转后收起。视口恢复桌面时重置窄屏展开状态。
4. 展开区复用工作区列表、新建、重命名、删除、备份导入导出、设置与主题操作；不实现第二份数据逻辑。
5. 桌面保留现有侧栏与工作区布局；设置页的完整侧栏 CSS 不得覆盖窄屏单列规则。控制点为 768/769px。

## 验收条件

- 375px 首次进入设置页，内容宽度为 375px；Key 输入框完整位于视口内。
- 菜单收起时四个功能标签常显，菜单按钮有可感知的展开状态；所有主入口高度至少 44px。
- 无 Key 时可选择工作区并执行备份导出/导入，导入仍创建新工作区。
- Esc 后焦点返回触发按钮；桌面与窄屏之间切换不会遗留展开状态。
- 深浅主题沿用现有 token；375、768、844（横屏）、1024、1440px 全局壳无横向溢出。
