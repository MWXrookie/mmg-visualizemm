## 1. 设计方向

### 1.1 设计关键词

> **现代 SaaS 可信感（Professional Trust）+ 学习友好（Learning Friendly）+ 内容专注（Content-first）**

产品是"AI 辅导工具"，不是游戏也不是论文网站：要让学生觉得**可信**（AI 输出严谨、可溯源），**不吓人**（新手友好、引导清晰），**能专注**（读题工作区无干扰）。

| 来源 | 借鉴 |
|------|------|
| 配色方向 | SaaS Trust Blue（专业可信） |
| 风格 | Flat 为主 + 卡片轻阴影（非 Claymorphism，避免玩具感） |
| 字体 | 现代无衬线（Plus Jakarta Sans / Noto Sans SC），代码用等宽字体 |
| 交互标杆 | NotebookLM（引用溯源）、通义智文（划词工具栏）、Kimi（反问引导）、Brilliant（卡片节奏） |

### 1.2 设计原则（6 条）

1. **读题为王**：核心工作区是"题目 + AI 解读"双栏，任何功能不喧宾夺主
2. **AI 输出可溯源**：每条 AI 断言可回跳原文高亮（双向引用），角色判定带置信度
3. **划词即问**：选中文字 → 浮动工具栏 → 一步解读，零学习成本
4. **引导而非代笔**：对话区有"引导模式"视觉提示（AI 是教练），防代做开关可见
5. **本地优先**：无外网字体/图标依赖（自托管可离线），Key 页面强调隐私
6. **新生可用**：所有设置项带说明文字，错误信息说人话

### 2.2 排版系统（Typography Scale）★

**字体族（中文本地化，不依赖 Google Fonts）**

| 场景 | 字体栈 |
|------|--------|
| 标题/UI | `"Plus Jakarta Sans", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`（西文 webfont 本地打包，中文走系统字体） |
| 正文（题干等长文） | `-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif` |
| 代码/公式 | `"JetBrains Mono", Consolas, "Courier New", monospace`；公式 KaTeX（自带字体） |
| 数字表格 | 同正文 + `font-variant-numeric: tabular-nums`（等宽数字，对齐列） |

**字阶表（Modular Scale）**——基准 14px，比例 1.15 起：

| Token | 字号 | 字重 | 行高 | 字距 | 用途 |
|-------|------|------|------|------|------|
| `--text-display` | 30px | 700 | 1.3 | -0.01em | 启动页大标题（极少用） |
| `--text-h1` | 24px | 700 | 1.35 | -0.01em | 页面标题（设置/卡片库） |
| `--text-h2` | 20px | 600 | 1.4 | -0.005em | 区块标题 |
| `--text-h3` | 18px | 600 | 1.45 | 0 | 卡片标题 |
| `--text-h4` | 16px | 600 | 1.5 | 0 | 小节标题/面板标题 |
| `--text-body-lg` | 16px | 400 | 1.8 | 0 | **题干长文**、对话正文 |
| `--text-body` | 14px | 400 | 1.6 | 0 | 默认正文、表单、表格 |
| `--text-body-sm` | 13px | 400 | 1.5 | 0 | 辅助说明、次要内容 |
| `--text-caption` | 12px | 400 | 1.4 | 0 | 标注、时间戳、元信息 |
| `--text-label` | 12px | 600 | 1.4 | 0.02em | 标签/徽标/表头（加字距提升可读性） |
| `--text-code` | 13px | 400 | 1.6 | 0 | 代码/日志 |

**排版规则**：
- 标题用字重而非更大字号制造层级（H4=16px/600 与 Body-L=16px/400 区分）
- 正文≥14px、行高≥1.6（中文长文 1.8）；正文对比度≥4.5:1
- 数字：表格内一律 `tabular-nums`；金额/百分比保留单位
- 中英文混排：中文与英文/数字之间加半角空格（如"共 120 个样本"）；标点用中文全角

**文字层级配色**（与字号搭配的 4 级文字体系）：

| 层级 | Token | 色值 | 对比度(白底) | 用途 |
|------|-------|------|-------------|------|
| 主文字 | `--text-primary` | `#1E293B` | 14.4:1 | 正文、标题、题干 |
| 次文字 | `--text-secondary` | `#475569` | 7.4:1 | 辅助说明、表单 label |
| 三级文字 | `--text-tertiary` | `#64748B` | 4.8:1 | 元信息、时间戳（仍达标） |
| 占位/禁用 | `--text-disabled` | `#94A3B8` | 2.9:1 | **仅**占位符与禁用态（禁止用于正文） |

### 2.3 间距系统（Spacing System）★

**间距刻度（4px 节奏）**：`--space-1:4px / 2:8 / 3:12 / 4:16 / 5:20 / 6:24 / 8:32 / 10:40 / 12:48 / 16:64`

**三级间距用法（组件内 → 组件间 → 区块间）**：

| 层级 | 刻度 | 规范 |
|------|------|------|
| 组件内边距 | 4 / 8 / 12 / 16 | 按钮内 8×16；输入框内 8×12；卡片内 16-24；气泡内 12×14 |
| 组件间距 | 8 / 12 / 16 | 图标↔文字 8；相邻控件 12；表单字段纵向 16；对话气泡间 12 |
| 区块间距 | 24 / 32 / 48 | 卡片与卡片 24；分区 32；页面大区块 48 |

**页面边距**：桌面 24px（宽屏可增至 32）；移动端 16px；工作台全宽模式 0（双栏贴边）。

### 2.4 布局网格（Layout Grid）★

| 项 | 规范 |
|----|------|
| 栅格 | 12 列（桌面）；列间距 gutter 24px；移动端 4 列 gutter 16px |
| 内容宽度 | 常规页面最大 1280px 居中；读题工作台允许全宽（1440） |
| 双栏比例 | 题目区 60% / AI 区 40%（工作台）；可折叠全宽 |
| 断点 | `375 / 768 / 1024 / 1280 / 1440`（px） |
| 断点行为 | <1280：双栏堆叠为上下（题目区在上）；<768：单栏+抽屉 |
| 行高节奏 | 区块垂直间距按 8px 倍数（24/32/48），避免任意值 |

### 2.5 圆角 / 阴影 / 动效 / z-index

| Token | 值 |
|-------|-----|
| 圆角 | `--radius-sm: 6px`（输入框/小件）/ `--radius-md: 10px`（卡片/按钮）/ `--radius-lg: 14px`（大面板/弹层）/ `--radius-full: 999px`（标签/头像） |
| 阴影 | 卡片：`0 1px 2px rgba(15,23,42,.06)`；浮层（工具栏/弹层）：`0 4px 16px rgba(15,23,42,.12)`；不用重阴影 |
| 动效 | 150-200ms ease-out（hover/过渡）；流式文字打字机逐 token；`prefers-reduced-motion` 关闭打字机与动画 |
| z-index | `10 底部栏 / 20 头部 / 30 浮动工具栏 / 40 弹层 / 50 遮罩`（禁止 9999 魔法值） |

## 3. 信息架构（页面地图）

```
┌─────────────────────────────────────────────────────┐
│ 顶部导航（全局）                                       │
│  Logo │ 会话标题(可切换) │ 卡片库 │ 编程工作台 │ 设置   │
├─────────────────────────────────────────────────────┤
│                                                      │
│  ① 启动页/会话列表      ← 空态：新建会话（上传/粘贴题目） │
│  ② 读题工作台 ★核心      ← 双栏：题目区 + AI 解读/对话区 │
│  ③ 深挖模式（独立页）     ← 步骤②进入：对话+过程面板     │
│  ④ 知识卡片库           ← 收藏卡片、按模型分类           │
│  ⑤ 编程工作台           ← 代码编辑 + 运行 + 可视化      │
│  ⑥ 设置页              ← BYOK / 模型 / 主题 / 关于     │
│                                                      │
└─────────────────────────────────────────────────────┘
```

- **主流程**：启动页 → 上传题目+附件 → 自动进入读题工作台 →（划词/轻量问答/卡片）→ 步骤②可进入**深挖模式独立页** → 可选进入编程工作台
- **对话双形态（决策已确认 2026-08-29）**：
  - **工作台右栏对话 tab**：轻量问答，读题+问答同屏不打断心流
  - **深挖模式独立页**（guided-chat 形态）：步骤②进入，空间大，右侧带「当前追问/上下文判定/相关概念」过程面板，用于深度建模引导
- **导航原则**：核心流程单页完成；深挖模式是唯一"跳页"场景（有明确语义：进入建模思考阶段）

### 4.2 划词精读交互（核心差异化，细节规范）

| 步骤 | 交互 | 视觉 |
|------|------|------|
| 1 选中 | 用户在题干拖选任意文字 | 系统默认选区高亮 |
| 2 浮动工具栏 | 松手后出现在选区上方 | 圆角小卡片：PAI 解读] P提问] P复制]，带主色描边 |
| 3 解读请求 | 点「AI 解读」 | 右侧出现**角色判定卡**：角色标签（彩色圆点+文字）+ 置信度 + 解释 + 影响 |
| 4 双向引用 | 卡片内脚注①② 可点击 | 点击后题目区对应句**闪烁高亮**并滚动到视口 |
| 5 连续深挖 | 卡片底部「继续追问这段」 | 自动把选区作为锚点带入对话区 |
| 6 质疑 | 点「质疑」 | AI 重新论证并给出置信度变化 |

**约束**：选区上限 500 字；浮动工具栏不遮挡选区；键盘可达（Enter 触发解读）。

### 4.6 组件规格（Component Specs）★

> 所有组件遵循：图标 SVG（Phosphor）、hover 150-200ms、焦点环 `--color-ring`、禁用态 40% 不透明度。

### 4.6.1 按钮 Button

| 项 | 规范 |
|----|------|
| 尺寸 | S：高 32 / 内边距 8×12 / 字号 13；**M（默认）：高 36 / 内边距 8×16 / 字号 14**；L：高 40 / 内边距 10×20 / 字号 14 |
| 圆角 | 8px |
| 类型 | 主（primary 底白字）/ 次（白底主色描边主色字）/ Ghost（无底描边）/ 危险（destructive 底白字） |
| 状态 | 默认 → hover（主色加深 10%）→ active（下压 1px）→ focus（ring 2px）→ disabled（40% 透明+禁点） |
| 图标 | 左侧 16px 图标，图标与文字间距 8px |
| 触点 | 最小触点 32×32（纯图标按钮） |

### 4.6.2 输入框 Input / 文本域 Textarea

| 项 | 规范 |
|----|------|
| 尺寸 | 输入框高 36 / 内边距 8×12 / 字号 14；文本域最小高 72 / 行高 1.6 |

## 5. 关键交互规范

### 5.1 AI 输出（流式 + 反馈）

- **一律流式**：SSE 打字机逐 token 输出（不做 10s+ spinner）；首字 <3s
- **反馈组件**：每条 AI 回复尾部 👍/👎 + P重新生成]（调研 UX 指南：AI 需要反馈闭环）
- **防代做提示**：引导模式下 AI 回复带「💡 提示」样式（非成品答案），与直接答案视觉区分

### 5.2 三步引导漏斗（读题流程步骤指示器）

顶部细进度条：`① 读题理解 → ② 精读深挖 → ③ 建模方向`（PRD F-402 问题链）——步骤指示器让新手知道"我在哪一步"（调研 UX 指南：多步流程必须显示进度）。

### 5.3 空态与新手引导

- 启动页空态：大按钮「新建会话」+ 三步说明（上传→读题→建模）+「第一次用？看 3 分钟教程」
- 无 Key 时：拦截在设置页，引导申请（不进入读题流程报错）

### 5.4 状态与错误

- 上传解析中：文件卡片进度条；失败给出可操作原因（"表格格式不支持，请转 xlsx"）
- AI 调用失败：区分「网络/Key 失效/模型繁忙」，分别给行动建议
- 全部错误信息用「人话」+ 可操作的下一步
