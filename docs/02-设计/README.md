# 设计文档入口

> 状态：当前索引
> 更新日期：2026-09-27

本目录用于保存稳定的交互说明、用户流程和设计决策。当前视觉规范的唯一来源仍是项目根目录的：

- `design-systems/mmg_visualizemm/DESIGN.md`

`docs/prototypes/` 中的 HTML 和生成记录属于设计探索与参考，不代表当前实现，也不能覆盖运行时架构或代码事实。

后续新增设计文档时按以下方式组织：

- `flows/`：读题、建模、编程、设置等关键用户流程；
- `decisions/`：重要交互取舍和无障碍决定；
- `research/`：可用性测试与访谈结论；
- `archive/`：不再采用但需要保留的历史设计。

用户可见交互发生变化时，应同时更新对应流程、开发验收用例和必要的 README 截图。
