## 1. 建议项目名称

**面向数学建模新手的可解释 AI 辅导与交互式验证平台研究**

备选：**基于大语言模型、检索增强与浏览器计算的数学建模学习辅助系统**

## 2. 项目摘要底稿

数学建模新手常在题意理解、目标与约束识别、附件数据解释和模型选择环节遇到困难。通用大模型能够快速生成答案，但容易越过学习过程，且输出缺少可追溯证据。本项目拟研发一套本地优先、用户主导的数学建模 AI 辅导平台 MMG_VisualizeMM。系统以“读题—建模—编程验证”为主线，结合数模语境角色判定、题干与结构化附件联动、苏格拉底式引导、本地知识库检索、交互知识卡片和浏览器内 Python 执行，帮助用户从理解问题逐步形成并验证自己的方案。项目将建立角色判定、检索和引导策略评测集，通过真实任务、前后测和可用性研究评价系统对新手理解准确率、任务完成率和自主建模表达的影响。预期形成可公开部署的软件、评测数据、技术文档、用户研究报告和演示成果，为低成本、可解释、隐私友好的 AI 教学工具提供可复现实践。

## 3. 拟解决的问题

1. 如何把数学建模题目中的目标、约束、已知、假设和背景转化为可核验的结构化理解？
2. 如何把题干自然语言与 Excel/PDF 附件中的字段、工作表和数据关系联系起来？
3. 如何让大模型通过提问和反馈促进用户思考，而不是直接代做？
4. 如何在单机、BYOK、浏览器执行的低成本架构下兼顾隐私、可用性和可重复部署？
5. 如何用可量化评测证明系统的学习价值，而不只展示功能演示？

## 4. 研究与开发内容

- 数模语境文本角色体系、标注指南和评测集；
- 题干—附件字段联动与人工确认机制；
- 可测量的苏格拉底式引导状态与负向约束；
- 方法库、卡片库、获奖论文组成的 RAG；
- 浏览器 Pyodide 代码验证与可视化结果反馈；
- 本地优先工作区、备份恢复、隐私和安全边界；
- 用户任务实验、可用性量表和学习效果分析。

## 5. 创新点候选

| 创新点 | 需要的证明材料 |
|---|---|
| 数模语境角色判定 + 双向引用 | 竞品对比、标注指南、F1 和失败分析 |
| 题干与附件字段联动 | 映射数据集、人工确认准确率、错误减少情况 |
| 用户决策驱动的苏格拉底引导 | 策略遵循率、对照任务、用户方案表达评分 |
| RAG + 卡片 + 浏览器计算的学习闭环 | 完整任务录像、来源追溯、运行结果 |
| 本地优先低成本架构 | 部署时间、数据边界、资源与隐私分析 |

所有创新表述都应使用“相对现有方案的组合创新/场景创新/方法改进”，避免未经系统检索与证据支持的“全球首创”。

## 6. 技术路线

1. 需求与竞品调研，明确新手任务和评价指标；
2. 建立当前 React + Express + SQLite + Pyodide + RAG 技术基线；
3. 构建角色判定、RAG、引导策略和金标准题评测集；
4. 迭代题干—附件联动、证据链和错误恢复；
5. 通过自动化测试与真实用户试用收集定量、定性证据；
6. 分析结果、收敛 v1.0、形成报告和演示。

当前运行时组件和数据边界见 [技术框架与运行时架构](../01-产品/技术框架与架构.md)。
