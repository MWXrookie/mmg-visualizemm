# docs · 文档地图

> 本项目全部文档与素材按类别归档。**新文档请放入对应分类，不要摆在 docs/ 根目录。**

## 分类目录

| 目录 | 内容 |
|---|---|
| **01-产品/** | 产品定义与调研：`PRD.md` / `竞品调研报告.md` / `技术框架与架构.md` / `research/`（5 份原始调研）|
| **02-设计/** | 全新 UI 设计文档（建设中；旧 UI 设计稿已清理）|
| **03-开发/** | 开发与验收：`开发规划与验收.md` / `验收报告.md` / `评测集-角色判定.md` |
| **prototypes/** | OpenDesign 工作流 + 原型落盘区：`generated/`（自动写入）/ `.od-prompts/` / 工作流文档——详见其 `README.md` |
| **06-素材/** | 真题与附件：2022 C 题 PDF / Excel / Markdown |

## 常用入口

- 产品全景 → `01-产品/PRD.md`
- 设计规范（最终裁判）→ `design-systems/mmg_visualizemm/DESIGN.md`（项目根，工具绑定）
- 开发任务 → `03-开发/开发规划与验收.md`
- 原型工作流 → `prototypes/README.md`

## 规则

1. 文档按主题放入对应分类目录，根目录只留目录本身
2. 相对引用用 `../` 保持可跳转；移动文件后必须同步修引用
3. `design-systems/` 与 `prototypes/generated/` 为工具绑定路径，**不可移动**
