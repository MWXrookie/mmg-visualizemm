# Design System: MMG_VisualizeMM

> Category: Education & AI Productivity Tool
> 面向数学建模新手的「AI 辅助读题 + 自主建模」辅导工具：现代 SaaS 可信感 + 学习友好 + 内容专注。AI 帮你看懂题，建模由你主导。

## 1. Visual Theme & Atmosphere

- 风格：Flat 为主 + 卡片轻阴影（**不要** Claymorphism/玩具感，**不要**重阴影/玻璃拟态）
- 气质：专业可信（AI 输出严谨可溯源）+ 学习友好（新手不吓人）+ 内容专注（读题工作区无干扰）
- 布局基调：桌面优先双栏工作台（题目区 60% + AI 解读区 40%），白色卡片 + 浅灰背景

## 2. Color Palette & Roles

| Role | Hex | 用途 |
|------|-----|------|
| Primary | `#2563EB` | 主操作、链接、选中高亮 |
| On Primary | `#FFFFFF` | 主按钮文字 |
| Secondary | `#3B82F6` | 次级强调 hover |
| Accent | `#EA580C` | **最高优先级引导**（"开始读题"等页面级大 CTA）；主按钮保持主色蓝，橙色不滥用 |
| Background | `#F8FAFC` | 页面背景 |
| Foreground | `#1E293B` | 主文字 |
| Card | `#FFFFFF` | 卡片/面板 |
| Muted | `#E9EFF8` | 输入框/代码区背景 |
| Muted Foreground | `#475569` | 次要文字 |
| Border | `#E2E8F0` | 分隔线 |
| Destructive | `#DC2626` | 错误、删除 |
| Ring | `#2563EB` | 焦点环 |

**段落角色判定语义色**（划词精读核心视觉，颜色+图标双通道）：
- 约束条件 `#2563EB` 蓝 / 目标 `#16A34A` 绿 / 已知条件 `#D97706` 琥珀 / 假设 `#7C3AED` 紫 / 背景信息 `#64748B` 灰
- 用法：正文高亮 15% 透明度底色 + 胶囊标签（语义色圆点 + 文字）

**文字 4 级**：主 `#1E293B`(14.4:1) / 次 `#475569`(7.4:1) / 三级 `#64748B`(4.8:1) / 占位禁用 `#94A3B8`(2.9:1，仅占位与禁用)

## 3. Typography

- 字体族：标题 `"Plus Jakarta Sans", "PingFang SC", "Microsoft YaHei", sans-serif`；正文系统栈（PingFang SC / Microsoft YaHei）；代码 `"JetBrains Mono", Consolas, monospace`；公式 KaTeX
- 字阶：display 30/700 / h1 24/700 / h2 20/600 / h3 18/600 / h4 16/600 / 题干正文 16/400 行高1.8 / 正文 14/400 行高1.6 / 辅助 13 / caption 12 / label 12/600 字距0.02em / code 13
- 标题靠字重分层（H4=16/600 vs Body-L=16/400），正文 ≥14px、行高 ≥1.6，对比度 ≥4.5:1
- 数字表格用 `tabular-nums`；中英混排加半角空格；题干长文行宽 40-60em

## 4. Layout & Spacing

- 12 列栅格，gutter 24px；常规页最大宽 1280 居中，工作台全宽 1440
- 断点：375 / 768 / 1024 / 1280 / 1440；<1280 双栏堆叠（题目在上），<768 单栏+抽屉
- 间距刻度（4px 节奏）：4/8/12/16/20/24/32/40/48/64
  - 组件内：按钮 8×16、输入框 8×12、卡片 16-24、气泡 12×14
  - 组件间：图标↔文字 8、相邻控件 12、表单字段 16、气泡间 12
  - 区块间：卡片组 24、分区 32、大区块 48
- 页面边距：桌面 24（宽屏 32）/ 移动 16
- 圆角：sm 6 / md 10 / lg 14 / full 999；阴影：卡片 `0 1px 2px rgba(15,23,42,.06)`、浮层 `0 4px 16px rgba(15,23,42,.12)`

## 5. Components

- **按钮**：S 32 / M 36 / L 40 高，圆角 8，M 字号 14；主(primary)/次(白底描边)/Ghost/危险；hover 加深 10%、active 下压 1px、focus ring 2px、disabled 40%
- **输入框**：高 36 圆角 6 内边距 8×12 字号 14；label 上方 13/500；错误=红描边+下方红字提示；Key 输入带显示/隐藏切换
- **角色判定标签**：胶囊高 22，圆点 6px + 12/600 文字，语义色
- **对话气泡**：用户右（primary 底白字）/ AI 左（card 底），最大宽 85%，圆角 10（AI 左上 4px 折角），间距 12；AI 消息带 👍/👎/重新生成；引导模式=左 3px 主色边
- **浮动工具栏**（划词）：高 36 圆角 8，选区上方 8px，主按钮「AI 解读」+ ghost「提问」「复制」，150ms 淡入
- **提示条**：左边框 3px 语义色 + 图标 16 + 13px 文字，info/success/error 三态
- **数据表格**（Excel 预览核心）：表头 13/600 粘性冻结，单元格 13/400 行高 40，数字右对齐 tabular-nums，水平细线分隔，空值 `—`，>50 列横向滚动冻结首列
- **代码块**：背景 muted，圆角 8，内边距 16，13/1.6，行号列宽 32，错误行红色波浪线
- **步骤指示器**：`①读题理解 → ②精读深挖 → ③建模方向`，圆点 8 + 连接线，完成=绿勾/当前=主色实心
- **导航项**：高 40 圆角 8，图标 20 + 文字 14，激活=主色 10% 底

## 6. Motion & Interaction

- 过渡 150-200ms ease-out；流式 AI 输出打字机逐 token（首字 <3s）；`prefers-reduced-motion` 关闭动画
- z-index 体系：10 底部 / 20 头部 / 30 浮动工具栏 / 40 弹层 / 50 遮罩（禁 9999）
- 划词交互：选区<500 字 → 浮动工具栏 → 角色判定卡（置信度+可质疑）→ 双向引用（脚注↔原文高亮跳转）→ 连续深挖
- 主流程单页完成（读题工作台内切 tab），不跳页打断
- **对话双形态**：① 工作台右栏对话 tab=轻量问答（读题+问答同屏）；② 深挖模式独立页（步骤②进入）=深度建模引导，右侧带「当前追问/上下文判定/相关概念」过程面板

## 7. Iconography & Imagery

- 图标：Phosphor 风格线性 SVG（stroke 1.5-2px 统一），大小 token 化（16/20/24）
- 装饰性图标 `aria-hidden`；有意义图标带文字替代
- 图片：题目/附件缩略图用真实截图或中性占位（灰底+图标）

## 8. Voice & Tone

- 中文界面，第二人称「你」，亲切不卖萌，避免术语堆砌（首次出现给解释）
- 错误文案模板：「出错了 + 为什么 + 怎么办」（人话+行动建议）
- 按钮动词开头 ≤4 字（上传题目 / 开始读题 / 测试连接）；全站同动作同文案
- 关键信任文案：「🔒 Key 只存本浏览器，不会上传服务器」「代码由 AI 生成请核对后运行」

## 9. Edge Cases & Variations

- 空态：启动页大按钮「新建会话」+ 三步说明 +「第一次用？看 3 分钟教程」；无 Key 拦截到设置页引导
- 加载：上传解析进度条；AI 流式打字机；沙箱运行中显示「运行中…」
- 错误分级：网络 / Key 失效 / 模型繁忙 / 余额不足，分别给行动建议
- 无障碍：正文对比度 ≥4.5:1；键盘全可达（Enter 触发划词解读）；焦点环可见；角色判定不单靠颜色
- 响应式：375/768/1024/1280/1440 断点；移动端双栏堆叠为上下
