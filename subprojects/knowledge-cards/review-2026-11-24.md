# 建模知识卡复核与分学段设计

2026-11-24 · 覆盖原库 59 张的文字、来源字段、共用阅读界面和演示设计。逐卡条目记录学习用途与发现的问题。数值验收集中在本轮修改的演示与主要使用路径。

## 两套卡库

- **大学自学**从读题台、建模台查阅，默认显示 7 张入门卡。正文讲概念、适用情形和边界，原理和来源可以展开。互动示例用于观察规律，加入拆解是可选的工作台操作。
- **中学学习**从首页进入。初中卡讲变量和单位、一次函数和交点、估计与误差；高中卡讲约束与可行性、周期性、误差与阈值判断。两学段用贴近先备知识的多个情境解释概念，用独立标明的例子做互动。
- **教案专用卡**随具体课堂任务组织，可以引用通用卡。用于某题的数据说明、逐步提示和课堂提问留在教案案例中。
- 共用现有主题、交互控件和图表样式。移动端大学卡库使用横向入口，保留题目和建模区的工作空间。
- 原「序贯解法」并入「多目标规划」。原收藏与召回词指向合并卡。爬山卡删除只换选中样式的 A* 按钮，将 A* 的检索入口转到最短路卡。大学库为 58 张，其中 43 张有演示。中学库的 6 张均可操作。

## 逐卡记录

| 线性回归（多项式） | 改。训练和验证分别画成圆点与方块，比较两组误差。 |

| 层次分析法 | 改。将不可操作的循环比较练习改为滑块能构造的不一致判断。 |
| 多目标规划 | 改。用同一组方案比较加权取舍与严格优先级。 |
| 联合优化 | 保留。适合展示订购和运输互相限制，需说明分开求解是否有影响取决于问题。 |
| 遗传算法 | 保留。适合观察种群变化，代数增加不证明找到全局最优。 |
| 相关性分析 | 保留四种可视对照，移到更靠前的位置。 |
| 数据预处理 | 改。原表、缺失、凭证更正与尺度变换均可切换，保留缺失记录和更正依据。 |
| 模拟退火 | 保留。温度改变接受概率可观察，旧比喻仍需补充降温计划与随机结果的边界。 |
| 假设检验（卡方检验） | 改为卡方独立性检验。比较观测与期望，修正尾概率和无效输入反馈。 |
| 多指标评价体系 | 改。用三项有明确单位和方向的采购指标替代重复衡量波动的例子，条形图显示同向示例分。 |
| 动态规划 | 保留。库存演示主要展示状态转移，完整动态规划还需明确目标、状态价值与回溯。 |
| 存贮模型（EOQ） | 保留。条目可解释成本权衡，需区分订货点和安全库存。 |
| 贝叶斯模型 + MCMC | 保留。图能讲先验、证据和后验，现有演示的分布运算不同于实际 MCMC 采样。 |
| 微分方程建模 | 保留。冷却图能观察参数改变曲线，先用变化率和单位理解公式。 |
| 蒙特卡洛方法 | 保留。撒点示例直观，单次估计误差可上下波动。 |
| 灰色预测 GM(1,1) | 保留为专题查阅。少量数据也需检查趋势与留出误差。 |
| 粒子群算法 | 保留为专题查阅。轨迹适合解释个体和群体历史，不能单凭示意图断言求得全局峰。 |
| 飞蛾火焰算法 | 保留为专题查阅，删除以「写论文显新意」作为理由的文字。螺旋演示仍属于简化模型。 |
| 调度下界模型 | 保留。能区分「至少几轮」与构造可行方案，需按具体通信规则论证公式。 |
| 贪心算法 | 保留。局部选择有视觉顺序，可继续用反例检验何时不能推出全局最优。 |
| 爬山算法 + A* | 改。保留可换起点的爬山图，移除虚假的 A* 切换。 |
| PLS-DA 判别分析 | 保留为专题查阅。当前图演示成分和 VIP 的含义，不能用示意阈值替代留出验证。 |
| 几何建模 + 坐标变换 | 保留。二维旋转展示距离不变，图便于迁移到较熟悉的几何基础。 |
| 有限差分法 | 改。用现有滑块可观察的稳定扩散替换超出滑块范围的练习。 |
| 光线追迹 | 保留。反射路径图有帮助，需区分入射角与镜面方向角。 |
| RFM / FMS 用户价值 | 保留为专题查阅。不同维度可解释样本，合成权重取决于目标。 |
| 连带率 / 关联挖掘 | 保留为专题查阅。每单件数与两商品共现属于不同指标，促销效果需另验证。 |
| 图论 TSP | 保留。路径图能展示回路，回路条件应与题目吻合。 |
| 图像处理（二值化） | 保留。阈值前后对照能直接呈现分割错误。 |
| Dirichlet 回归 | 保留为专题查阅。三元图展示组成约束，完整回归还需检查零值等边界。 |
| 时间序列 VAR | 保留为专题查阅。多变量滞后示意需与实际估计及预测验证区分。 |
| 盈亏平衡分析 | 保留。收入线与成本线有明确交点，单价不高于单位成本时应解释无正保本量。 |
| 平衡方程组 | 保留。流入流出表达清楚，等式依赖稳态假设。 |
| 序贯解法 | 合并到多目标规划，保留检索词和来源并加入可操作对照。 |
| 对称性调度设计 | 保留为专题查阅。关注轮转构造与覆盖，和下界论证用途不同。 |
| 损失区间分析法 | 保留为专题查阅。依赖切割规则，不宜从一篇案例推广为通用公式。 |
| 卷积分布离散化 | 保留为专题查阅。关键前提是各事件的合并方式与独立性。 |
| 非对称损失期望 | 保留。库存多一点和少一点代价不同，可与一般蒙特卡洛的采样步骤区分。 |
| 重叠率投影修正 | 保留为专题查阅。价值在于识别定义失效，投影式依赖特定几何设置。 |
| 高斯过程回归 | 保留为专题查阅。关键在预测不确定性，不宜把样本少直接当成选型理由。 |
| 模糊综合评价 | 保留为专题查阅。定性等级的隶属度需给出可解释的来源。 |
| 灰色关联分析 | 保留为专题查阅。序列形态相似无法直接说明谁造成了结果。 |
| 支持向量机 | 保留为专题查阅。间隔类比有用，泛化效果取决于数据与验证。 |
| 因子分析 | 保留为专题查阅。与 PCA 的问题不同，统计因子不等同于已证实的因果机制。 |
| 方差分析 | 保留为专题查阅。比较组间与组内变化有价值，判为显著仍要说明假设和研究设计。 |

| 元胞自动机 | 保留为专题查阅。局部规则与系统行为应配合验证。 |
| 马尔科夫链 | 改。加一般转移与晴雨交替对照，区分有稳态和从给定起点收敛。 |
| 博弈论 | 保留为专题查阅。先确认参与者、策略和收益，均衡取决于模型设定。 |
| 力电比拟法 | 保留为专题查阅。对应关系适合懂基本力学、电路的学生按题查阅。 |

这轮工程检查覆盖主要入口和代表性互动。仍需课堂试用评估中学内容难度，并对大学库其余专题做逐个数值验收。
