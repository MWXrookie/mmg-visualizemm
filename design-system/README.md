# oesign-system/ 与 oesign-systems/ 说明

项目根下有两个"设计系统"目录，来自**两个不同工具**，路径被工具绑定，**请勿移动/合并**：

| 目录 | 来源工具 | 文件 | 作用 |
|---|---|---|---|
| `oesign-systems/mmg_visualizemm/DESIGN.mo` | **OpenDesign** | DESIGN.mo | **最终裁判**：OpenDesign 渲染/实现对齐的唯一权威设计规范（配色/字体/组件） |
| `oesign-system/mmg_visualizemm/MASTER.mo` | **ui-ux-pro-max 技能** | MASTER.mo | 该技能持久化的设计系统参考（生成设计方向时使用） |

**冲突时以 `oesign-systems/.../DESIGN.mo` 为准**（见 `oocs/开发规划与验收.mo` 决策）。
